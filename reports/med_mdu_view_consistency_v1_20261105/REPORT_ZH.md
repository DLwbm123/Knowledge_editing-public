# MDU 训练视图一致性局部诊断

固定25个既有 MDU 专家、100个 native/FIT 配对，预登记的可区分信号为 **0/100**：没有配对的两次重复同时满足 JS、JS 梯度范数和梯度余弦三个条件。100对均有非零且可计算的两类梯度；重复计算的 JS 与梯度在记录精度下完全一致。

| 预登记条件 | 两次重复均满足的配对 |
|---|---:|
| JS > 1e-6 | 0/100 |
| JS 梯度范数 > 1e-8 | 100/100 |
| 两梯度余弦绝对值 < 0.999 | 100/100 |
| 三项同时满足 | 0/100 |

200次计算的平均 JS 为 7.08445e-9，范围约 4.29e-10 至 4.28e-8；平均 JS 梯度范数为 2.35124e-7，平均 MDU 梯度范数为 5.77682e-6，平均梯度余弦为 0.27756。JS 数值十分接近本次 FP32 计算的数值精度范围，因此按预登记将方法是否存在真实分布差异的判断记为 **INCONCLUSIVE_NUMERICAL_FLOOR**；不能把未触发阈值解释为所有视图在数学上完全相同。梯度余弦仅是当前参数点和固定训练视图上的局部测量。

实验使用与既有 MDU 训练逐项绑定的25组 source/FIT 及对应已训练状态；每组4对，每对重复两次。实际记录1200次前向、600次反向，0次参数更新、回答生成和新增评分。程序核对训练来源及答案锁、专家训练回执和状态摘要；执行期间逐专家检查状态摘要，完成时检查骨干参数版本。两类梯度最大重复差均为0。工作进程和独立守卫均退出0；实际资源峰值未测量。

这是已曝光训练数据上的局部机制诊断，不提供 T2G/T2L 改善证据，也不能据此自动加入一致性损失。继续研究需要有清晰依据、另行预登记同状态同数据的训练对照，并在适合的数据角色与固定预算下评估。此前边界平均等负结果及原模型均保留。
