# MED 第二方向：排除保留来源的配对开发方案

状态 PREPARATION；本方案独立于不能满足数据角色约束的原四编辑草案。先完成角色、比较和运行准入，再启动。研究问题：在两臂保护来源、训练配置和评测支持相同的情况下，加入第二曲率响应方向能否改善单专家 T2G 而不新增原知识损伤？这是已曝光 DEV，不是独立患者或临床确认。

## 固定来源与方法

- 延续原 V132 散列预选的全部四个编辑（47、117、93、87），不按成败选择。只用身份字段构造角色清单，V95 全部24个保留来源组和 V111 全部15组均排除；任何无法确定来源身份的项停止，不以未知视为合格。原31映射、30 fallback 中，身份审计已发现 V95 组分别重叠1条：两臂均排除这些来源组上的全部保护项，预计30映射、29 fallback，实际完整索引必须核实；不读取这些组的问题、答案或标签，不补位，不访问原资格文件其余封存问答。
- 对照 `CLEAN_MED1` 与候选 `CLEAN_MED2` 从同样的原零初始化、种子、编辑 native/FIT、TT88、160步、优化/生成合同重训，保护项、共同 fallback、FULL_CTX计算、原R0、每编辑 source-only 目标与校准方法完全相同；唯一干预是每映射源原命题方向与正交主特征方向按各半 trace 分配。对退化或首特征值重根，两臂均在该源使用完整原单方向；非有限、显著非PSD、绑定错误停止。新模型不能覆盖原MED或M13P。
- 为避免因删除保护项而隐式改变其余项尺度，两臂原探针分母固定为原 `sqrt(61*32*n)`，不对剩余59项补权；共享FULL_CTX及共同fallback上按原V133公式为每编辑重新计算同一个lambda，两臂一致。此调整意味着 CLEAN_MED1 是新开发对照，不是原 V133；旧 MED 只作标注清楚的历史参考，不能与候选直接作唯一归因比较。
- 固定原四编辑的69个 single 消费者，再在任何答案解码、生成或评分之前以来源组身份排除 V95/V111，未知身份停机；两臂及 Base 完全使用同一剩余集合和原资格掩码，锁定数量，空支持为 NA，禁止补位或按结果筛选。两臂各真实执行自然R0，核验路由/完整输入/精度/生成合同；同一精确载荷可复用同合同历史有效评分，已尝试载荷不重试。

## 指标与硬规则

主比较 CLEAN_MED2 对 CLEAN_MED1 的 T2G CORE 配对净改善至少1题，T2G FULL 不降，native/FIT CORE与FULL不降，同时固定 Base 和 CLEAN_MED1 共同正确的去重非native支持上 CORE/FULL 新损伤均为0。任何所需支持为空为 NA、缺失为 UNKNOWN，不可标通过；同时逐编辑报告 T1G/T1L/T2L 和所有分母、修复、截断及费用。正信号仅作开发决策，负结果完整保留，不扫描权重、阈值或种子。

两臂总训练最多 8×160=1280 更新；固定69原消费者上限，两个候选最多138生成、最多138个新评分，Base与历史已有评分仅在完整载荷和协议相等时复用。精确角色剔除数量须先验身份索引并冻结、不得读答案再改变。墙钟从首次实际运行起至多24小时，远程GPU守卫和本地评分守卫共享原钟；每服务器新增实际存储严格小于50GB，47GB预停、至少8GiB空闲。完整的合法输入切片、两臂状态与评测消费者、分项评分/报告、角色和状态绑定、GPU/挂载探针、独立守卫及资源计数均为启动前准入，未实现不得启动。原模型库和原始数据不修改，活跃中间状态在末消费者完成前保留，后续清理由明确清单和句柄检查决定。
