# TT-U continuation v1

User-authorized no-H TT88 development campaign: common real edited W0,
CE-only versus CE+0.01 full-vocabulary Base||student KL, all fixed nodes,
a frozen common continuation length, deterministic transfer-development blocks,
and budget-admitted real incremental expert banks.

Caps are 24 cumulative GPU hours, 24 wall hours from first launch, 6000 new
unique Judge payloads, 2GiB generated TT/optimizer/teacher artifacts and an
8GiB disk reserve. At most two idle authorized training GPUs run concurrently.
PR27/PR30 and their retained assets remain read-only. No recurring monitor,
H construction/loss, projection, rank search or full-146 extension is authorized.

The finite controller performs CPU and one-editor GPU admission before P1,
then scores P1 and freezes `t_star` using CAL only. CHECK remains unavailable
to selection. Every P2 block needs enough remaining budget for its paired
conditions. A real bank has its own consumer and admission.

Runtime and private source overlays must be provided by an authorized operator;
this public code does not contain medical inputs, raw answers, source IDs,
weights, Judge keys or private path mappings. The runtime loader, original TT
shapes and fixed Qwen protocol are reused from the audited reference assets.
Final result audit and public draft PR delivery occur after actual completion.
