## 2. 原N的单标签翻转界不能在mu=0处连续延拓

令p=(1/2,1/2)，以固定规则令Base argmax选第1类，q_e=(1/2-e,1/2+e)，0<e<1/2。q_e的argmax必为第2类，而

KL(p||q_e)=-1/2 log(1-4e²)=2e²+O(e⁴) -> 0。

因此任意在0附近有限、连续且在0为0的KL/Fisher损伤上界，都不能上界这个0/1“保持原tie-break标签”事件。把1/mu²在mu=0改成1/floor²，会声称一个本来不存在的统一翻转保证。删token/删源会改变保护总体，不能保留原命题。正但很小的mu也会使原N近似Fisher的谱随1/mu²放大，严格限制可写方向；这是目标本身的条件数问题，不能统称为数值包络过保守。

本轮实际日志仅证明第二源严格正准入失败；具体不合格token数量、间隔、是否精确并列未落盘，不能把反例当成这些值的实测。上述是原命题的数学障碍，不是对失败比例的估计。

## 3. 可定义的两个命题，均不是原N的等价修补

### 3.1 连续的Base概率后悔值（所有位置均保留）

每个固定前缀i，令a_i为p_i的某个最大概率类，b_i为q_i的最大概率类，定义

r_i(q)=p_i(a_i)-p_i(b_i) >= 0。

因为q_i(b_i)>=q_i(a_i)，有

r_i <= |p_i(a_i)-q_i(a_i)|+|p_i(b_i)-q_i(b_i)|
     <= ||p_i-q_i||_1 <= sqrt(2 KL(p_i||q_i))。

固定非负w_i且sum w_i=1，由Jensen，R=sum w_i r_i <= sqrt(2 sum w_i KL_i)。所有原8源、所有token的权重均保留；无1/mu，无floor，也没有删除不合格来源。并列最大类之间切换的r_i自然为0，而不是伪称单标签没有切换。

这把命题改成“Base认为的概率决策后悔值”，无法保证原tie-break标签、完整答案或医学正确。它的局部二阶度量就是plain Fisher；因此单独采用它并没有超越B的机制创新。epsilon=.01只给R<=sqrt(.02)约.1414的条件性上界，不能承诺零损伤。要比B改善，需要额外的可识别保护对象和覆盖证据，不能把改名当算法提升。本次不启动这个替代N。

### 3.2 最大概率集合的保留（显式承认歧义）

令A_i={a:p_i(a)=max p_i}，保留完全相同的原始精度并列集合，不人为引入近似并列阈值。如果A_i不覆盖整个词表，定义nu_i=max p_i-max_{b不在A_i}p_i(b)>0。若当前argmax落到A_i之外，则nu_i<=||p_i-q_i||_1，故

1{argmax q_i不在A_i} <= 2 KL_i/nu_i²。

若A_i是整个词表，集合外事件恒为0，这是无法识别更细决策的退化位置，应在覆盖报告里明确，不从总体删除其权重。A_i为单例时该式退化成原正间隔界；A_i多元素时保护的是集合，不再保护原始任意tie-break标签。这仍是新命题，不能称原门槛不变下恢复了原单标签保证；极小nu仍可能冻结。临床诊断的允许答案集合不能由模型token并列替代，现有粗框/源答案没有医生核实的替代诊断标注。本次不启动该方案。

## 4. 累计近似与原生量化：哪些成立

令出生点s的真实KL为K_s，精确局部Fisher为F_s，已保存完整因子对应Fhat_s，D_s=theta_t-theta_s为实际原生参数位移。假设在整个实际路径邻域有可信三阶界L_s，且采样算子误差E_s=F_s-Fhat_s，则

K_s(theta_t) <= .5 D_s^T Fhat_s D_s
             +.5 ||E_s||op ||D_s||² + L_s||D_s||³/6。

对冻结权重求和后加FP64算术包络即累计条件界。q/v/B完整旋转与实际native位移可以精确递推“已采样二次代理”及其算术误差；不能据此证明E_s或L_s足够小。独立出生块相加时必须保留原权重；不能把历史求和偷换为均值来放宽预算。plain Base的8源权重本来sum1，以上后悔值界才可直接使用Jensen。
