已确认正确的主链

  1. 目标与因果对齐：官方图文展开保留答案token，问题/视觉token为-100；logits[:-1]对应labels[1:]，仅有效答案位参与CE。真实完整模型前向反传到已有W，而非隐藏目标近似。
  2. 保护KL：参考logits在原Base状态重新计算并detach，实际损失为KL(Base‖current)，在合法61条BASIS的原Base响应前缀上计算全词表分布；不是用HELDOUT标签训练。它是软约束，不保证未训练输入函数不变。
  3. 右零空间：W为4096×14336，Q由W边界转置的thin QR得到。P=I−QQᵀ；梯度使用G−GQQᵀ，投影侧与维度正确，单次编辑内固定P。当前采用完整10240维零空间；这与作者1000维截取不同。
  4. 投影与计算图：固定P、纯SGD下，参数化W=W边界+A P的梯度为G P；本轮CPU检查验证两者相同。故不能仅因投影位于backward之后就断言出现DOW-KE式闭合错误；真正差异是未使用DOW-KE的保护基、输出投影、位置路由和多层联合优化。
  5. 输入缓存：缓存的是冻结图文前端产生的FP32嵌入，完整语言模型每步重新前向。只改下游第21层W时缓存成立；若以后编辑嵌入/视觉前端则需重新审查。初始两次dtype准入故障均在正式更新和生成前修复，历史失败保留。
  6. 连续写入与部署：8次编辑沿同一W串行累积；每条训练只用当前源/FIT/GFIT与固定BASIS KL，不回放旧编辑目标。两臂各1280次正式更新。实际总参数7,566,219,264，新增0；唯一可训练原W为58,720,256参数。新进程仅写回该矩阵，原生生成与末次prefix源/锚点token一致，推理没有编辑分支。

权重零空间不等于临床范围：ΔW·W边界ᵀ≈0并不推出对真实旧特征x有ΔW·x=0。每次编辑刷新当前W几何也不提供对最初Base的全轨迹函数不变保证。真实VLM回执证明非零写入、恢复和原生重载；本次CPU检查证明数学小例，并未复核已删除矩阵的每步FP32投影残差。

原文与作者代码也有版本差异：LOKI正文伪代码投影/裁剪梯度，而当前作者实现投影并限制Adam产生的累计位移。ScopeEdit作者代码还把证据gate按模态范数拆分，并归一化混合key；其递归更新没有逐字照搬正文的√γ加权key表达。本次只确认这些静态差异，不未经等价推导或运行检查就判定作者算法有错；后续复现必须明确以正文公式还是固定作者提交为参照。

必要适配与主动简化

有依据的适配：接入医学图文输入、合法数据角色与跨图作用域监督；使用本模型原生因果标签及一致的FP32前向；将最终变化写入已有W并验证原生部署。

不由“新增参数为0”强制要求的选择：固定一层、删除HSIC、从Adam改SGD、用全零空间、去掉ScopeEdit的写入门控/双空间/递归几何，以及删除DOW-KE多层保护参数化。这些是本轮简化或设计取舍，不能统一解释为必要适配。

ScopeEdit门控作用于写入，作者forward并无按推理请求再乘证据gate；去掉门控不是“没有推理分支”的必要条件。作者LLaVA配置的无非线性/无LayerNorm分支在eval关闭dropout时，可代数折叠为W部署=W原+s(B局部A局部+B共享A共享)；这仅说明纯W部署可行性，不代表作者已验证该导出。DOW-KE的ΔW同样定义为最终权重更新。若坚持训练期只优化原W，需要设计等价写入规则，并另行验证，不能直接省略核心机制。

发现的问题与处理边界

M1 · ScopeEdit scope-control algorithm is absent

mechanism omission, not a violation of the frozen adaptation protocol

Current run.py:275-288 uses fixed source/FIT/GFIT CE and global Base KL; no modality evidence gate, local/shared orthogonal spaces or branch-wise recursive preconditioners. Author lora_layers.py:1063-1128,1234-1269 implements gate and distinct updates.

影响：Trained anchors constrain sampled behavior, but do not implement evidence-dependent propagation boundaries.

最小处理：Describe this as scope-supervised direct-W editing. A faithful scope mechanism requires a separate frozen design and parity validation; do not modify this completed round.

M2 · LOKI author implementation differs from its algorithm sketch and from this prototype

deliberate optimizer/search-space adaptation

Author loki_main.py:396 uses Adam;525-538 projects cumulative displacement from edit-boundary weights;549-556 bounds cumulative Frobenius displacement by eps times boundary-weight norm. Current purew_math.py:25-27 uses projected SGD with per-step cap0.05; no cumulative radius. Author null_dim1000 versus this full right nullspace10240; dynamic HSIC selection and HSIC loss omitted.

影响：Cannot attribute the behavior to the original LOKI optimizer or trust constraint. Norm0.05 in this protocol is an absolute per-step bound, not a5percent cumulative weight-relative bound.

最小处理：State all differences explicitly; if comparing original LOKI later, preserve its parameterization/optimizer/constraint and use a separately registered comparison.

M3 · DOW-KE final-forward principle retained; preservation parameterization absent

partial principle transfer and missing author-code verification

Paper equations9-10 use multiple layers, Delta=P_out A B with fixed edit-key/preservation basis and subject-position backward routing. This prototype has one dense W, a weight-derived right projector and response-prefix KL. Author code not located.

影响：End-to-end CE alone does not implement DOW-KE input/output protection or cross-layer coupling. Post-backward projection itself is consistent with fixed-subspace plain SGD; it is not an observed closure bug.

最小处理：Label DOW-KE-inspired final-output objective only; do not claim author-code audit or full reproduction.

E1 · Top-level controller is not stage-aware on reentry

P2 future engineering recovery defect

run.py:361-370 launches smoke/Base/train/eval unconditionally; base:154 emits every output and emit:87 rejects existing outputs; train:219 rejects completed candidate. Controller assertions375-376 do not distinguish failed/replayed work from committed formal work.

影响：A restart after Base completion stops at existing output instead of resuming remaining stages; replayed partial steps can invalidate exact cost-count assertions. No such formal training interruption is documented in this completed run.

最小处理：Gate stages by binding-validated completion receipts, skip completed Base consumers, dispatch only unfinished arms and separate spent attempts from committed updates; preserve old failures/costs.

E2 · Per-step loss/gradient trace was retired with matrices

P2 historical diagnostic retention defect, future logging added after completion

Executed c5aa524 stored trace only in active/candidate matrices; controller later deleted all4 matrices. Latest run.py:319 adds a separate JSON write, the only algorithm-driver difference between c5aa524 and058f904.

影响：Cannot now reconstruct per-step KL, update magnitudes, accumulated displacement or actual FP32 projection residuals from full traces. Terminal receipts, periodic logs and generated outputs remain.

最小处理：Keep the new diagnostic logging for future runs; retain small summaries before cleanup. Do not rebuild weights or rerun the completed experiment to fill missing history.

结果解释

旧RESULTS和冻结阈值保持不变。投影臂完成108/108源/锚点prefix观测；未投影臂一个GFIT问题在prefix3–7丢失后恢复。最终T2G投影25/32，未投影28/32；两臂均保留62/62当前Base正确保护题。因此仅能报告这一开发顺序中的连续保持收益与泛化代价，不能声称投影全面优于对照。两臂共用GFIT和KL，不能独立归因它们的贡献。
