# 完整 MED＋D 的同事件权衡诊断

在固定、已曝光的九编辑开发面板上，完整 MED＋D 相对无曲率 D 保留了更好的 T2L，但 T2G 的4项原本正确回答转为错误，反向修复为0；这4项分属4个编辑。T2L 的17项中则有2项由 D 的错误变为完整 MED＋D 的正确，反向损伤为0，分属2个编辑。两臂同时改变了更新规则和保护约束，因此这只是配对关联，不能将差异单独归因于曲率。

T2G CORE 的36个合格事件中，按 MED、D、完整 MED＋D 的对错排列：26项三者均正确、3项三者均错误、3项仅 MED 错、2项仅 D 正确、2项仅完整 MED＋D 错。相对原MED，D修复5项、损失0项；完整 MED＋D 修复3项、损失2项。这个具体权衡比两种宏平均的差异更能说明改进目标：希望保留 D 的泛化修复，同时避免其新增局部性损伤，而不能事后围绕这些事件构造规则。

T2L CORE 的17项中14项三者均正确、1项三者均错误、2项仅 D 错；T0、FIT、T1G 的合格项三臂 CORE/FULL 均正确。T1L没有合格支持。FULL 的配对模式以及所有角色分母见 RESULTS.json。

下一步方法设计应把稳健写入目标和保护约束作为可分离的机制，在不使用被保护来源内容的前提下检验二者的梯度冲突和编辑泛化；须通过独立对照区分写入目标、约束和优化器的作用，而不能把本次差值称为曲率的因果贡献。完整 MED＋D 所用 V95/V106 衍生曲率仅获本次实验授权，不能自动用于新的实验。不存在独立测试、T1L支持或可验证新保护训练来源时，应明确保留未知，不重新打开已停止的路线。

本分析仅使用已有面板身份和判断，流式跳过问答内容，0模型调用、0新评分；无事件身份公开。首次入口因缺少导入路径在读取输入前失败，修复后在60秒超时和10MB单文件限制内完成；该失败不涉及模型或评分。历史评分快照未知，补评载荷可能有未留存历史尝试；此前无曲率D的DEV_FAIL和完整MED＋D的T1L UNKNOWN均不变。
