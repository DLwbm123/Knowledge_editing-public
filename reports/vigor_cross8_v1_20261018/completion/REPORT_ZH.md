## 主更新、补偿和交互的可检验效应

以G为共同探针的native原图降损，四臂G00=0.280967951、G10=0.138303041、G01=0.285134554、G11=0.134571552：

| 条件比较 | 降损差值 |
|---|---:|
| 主更新切F1，补偿保留F0：G10−G00 | −0.142664909 |
| 主更新切F1，补偿为F1：G11−G01 | −0.150563002 |
| 补偿切F1，主更新保留F0：G01−G00 | +0.004166603 |
| 补偿切F1，主更新为F1：G11−G10 | −0.003731489 |
| 交互：G11−G10−G01+G00 | −0.007898092 |
| 两项同时切F1：G11−G00 | −0.146396399 |

在两种补偿背景下，主更新因素都使探针降损减少约0.143—0.151；补偿因素对降损只有约±0.004，交互额外−0.00790。因而本轮支持**主更新路径是S03该探针收益下降的主要来源**，不支持“主要是secant补偿范数累计造成收益下降”。该因素包括主更新方向、物理幅度及后续重新求解状态，尚不能区分它们；不计算所谓因果百分比。

null保护要分开判断。以探针累计Δnull为读数，主更新条件效应为−0.061554432/−0.072988033，补偿条件效应为−0.002743721/−0.014177322，交互−0.011433601。主更新使后续null漂移显著变坏；新补偿在新主更新路径上又进一步放大。只换补偿的01探针也从通过变为轻微拒绝，因此不能说补偿无关。

8步终点自身的余量也体现耦合：10保留旧补偿时余量0.008001575，明显大于11的0.000498066；旧主更新下00→01只从0.009174118降至0.007694969。新补偿对终点余量的条件影响为−0.001479149/−0.007503510，交互−0.006024361。另一方面，01和10整个接受前缀的最差余量分别0.003955612、0.002523193，比00/11的0.000509033/0.000498066更大。因此“补偿全程单调伤害保护”也不成立；应报告终点、前缀最差、后续探针三个不同读数。

路径长度是每个实际native增量L2的和，不是终点相对基座的净位移，也不是贡献占比。新主更新两臂的主路径均约0.567，旧主更新两臂约0.288；补偿改回F0并未消除新主更新的探针收益下降。新补偿会增加补偿路径长度，且改变自然触发和后续梯度：00/01均在2、3、6、8修正，10在2、3、4、6、7、8，11在2、3、4、6、7。因子检验识别的是“选择哪个补偿度量及其闭环反馈”的总效应，不能将触发次数和单次方向的影响再拆开。

据此应把S03收益退化与null余量问题分别处理：前者优先检查主更新的实际幅度/方向，后者同时保留补偿交互解释。本轮没有证明“主更新F1+补偿F0”可安全继续：10虽然8步余量宽，固定无补偿探针仍明显违反null门。也没有证据支持立即替换默认配置或重跑16步。若后续另行授权，需要把主更新幅度与方向分开才可做更细归因；本轮到此停止，不增加候选或样本。
