# MED 第二响应方向：四编辑开发实验准备

状态：PREPARATION；本文件固定研究设计，不是运行准入或实验结果。目标是在已曝光 DEV 上检验第二曲率方向能否改善单专家 T2G，同时保留原知识。无独立患者或临床验证，不更改原 MED R0 和权重。

## 固定研究设计

- 固定沿用 V132 预先通过散列选择的全部四个编辑（47、117、93、87），不按历史结果、错误或新增输出筛选；V132 和后续146使用过这些编辑，结论仅为开发探索。
- 原 V133 的31个保护源及每源四路径各8个固定探针为保护曲率构造角色；30项共同 fallback 不变。保护源不作为新的编辑监督，也不读取 V95/V111 封存问答。原 native/FIT、原单专家消费者及其资格掩码保持；同一问题、图像、参考、模型、精度、解码、随机状态、路由和 Judge 合同逐项核验后，才可复用已接受的 MED 和 Base 输出及分数。
- 候选：对每个原 FULL_CTX 探针向量在原 MED 命题方向的正交补取最大特征方向；新方向和原方向各分配该锚点原 trace 一半。第二方向有效秩不足、首两特征值不可分辨时该锚点**回退完整原 MED 单方向**，记录原因；计算非有限或显著非 PSD 则停止，不用回退掩盖实现错误。原 TT88、160步、各编辑初始状态/种子、来源和学习规则、C 端校准及 source-only target 保持，训练新候选四次。不得重建或覆盖原 MED 正式权重。
- 原保护与目标共享同一 trace 预算不代表相同轨迹。该候选可能损伤 T2G 或知识保护，不能把合成算子通过当作效果。

## 对照和停止

以同合同 V133 MED 单专家为主对照，Base 用于固定原资格掩码；逐题比较 T2G CORE/FULL、native/FIT、T1G、T1L/T2L，以及 Base 和 MED 均正确的非 native CORE/FULL 新伤害。原掩码、NA、UNKNOWN、全体四编辑与每编辑分母必须保留。开发信号要求 T2G CORE 净改善至少1题、FULL不降，native/FIT 不退化，且固定 Base+MED 均正确的保护支持上 CORE/FULL 新伤均为0；空支持记 NA，不能以空集通过保护条件。上述为方向性 DEV 信号，不是统计显著或临床结论；负结果同样交付，不追加阈值扫描或筛选种子/样本。

先实现并验证投影最大特征方向、原 V133 因子梯度/序列化、实际输入与保护源身份、原 MED 对照及评分消费者，随后通过 GPU/存储/独立守卫准入后再启动。任何绑定、计数、数据边界或机械失败即停止并保留回执；不重新评分已尝试载荷。所有候选冻结后才生成固定评测，评分使用原 Astra medium 合同，一次尝试、缺失记 UNKNOWN。不得将开发数据当独立确认。

资源上限：每服务器新增严格小于50,000,000,000字节，预计自身<4GB，47GB保守预停，至少8GiB空闲；一次独立实验首次实际执行起≤24小时，远程GPU与本地评分各有独立硬守卫，所有阶段同一原钟。四编辑640更新、原重建最多1116次曲率反传另计，生成消费者和评分尝试上限须在入口映射后固定并在准入前写入锁；评分/报告消费者未完成不得启动。必要临时状态保留至最后消费者结束，删除仅按清单和占用检查，原 MED 和 M13P 完整保留。
