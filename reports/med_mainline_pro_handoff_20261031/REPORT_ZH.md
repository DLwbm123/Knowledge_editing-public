# MED 方法研究：结果与后续设计交接

更新时间：2026-10-31。目的：请根据已有实验结果，帮助判断 MED 方法瓶颈并设计有论文贡献的新方法。当前研究目标是提升多模态知识编辑的 T2G 泛化，同时控制 T0、FIT、T1G、T1L 和 T2L 的退化。下文均是参考答案一致性评测；CORE 为核心回答正确性，FULL 为包含完整性等约束的更严格判定。除明确标注外，百分比均是**按编辑等权的宏平均**，不是把所有查询合并后的准确率。

## 用户要求和当前结论

- 以当前 MED 为对照，新实验优先提高 T2G；T2L CORE 最多下降 5 个百分点，T0、FIT、T1G、T1L 不下降。T1L 若无合格支持必须记为 NA/UNKNOWN，不得称通过。此要求适用于后续新实验，不改变先前冻结实验的结论。
- 已完成的固定层位实验表明深层位置有明显的 T2G 开发信号，但同步损害局部性及部分原始编辑表现，当前没有达到上述要求的候选方法。
- 面向高水平论文，需要围绕明确问题提出有动机、结构完整且相对相关工作的实质创新。简单变体可作诊断或消融，不自动构成最终方法。
- 本文所有结果均来自已曝光开发数据，不能作为未曝光测试集上的性能。原146和新增4条的混合150队列与原146队列不同，不能直接将两者百分比差解释为性能提升。

## MED150 和真实对比结果

MED150 是原146专家加4个新增专家的开发扩展。最终150库评测包含2,148个 bank 查询；原146的2,093个共同查询重新计算后选中专家和评分载荷全部不变。原146 T2G CORE 为 **77.5114%**、FULL 为 **74.6575%**；混合150队列 T2G CORE 为 **78.1111%**、FULL 为 **75.3333%**。新增4条的T1G语义资格未确定，T2L无合格支持。新增4条的14个合格T2G查询，MED均通过CORE/FULL；这些查询属于构造开发数据。

|---|---:|---:|---:|---|
| T2G：BalancEdit | 150编辑 / 571查询 | 78.1111% | **94.8333%** | 项目固定适配；MED−BalancEdit = −16.7222 pp |
| T2L：BalancEdit | 31编辑 / 54查询 | **98.3871%** | 63.4409% | 局部性支持稀疏；原146非native、Base正确83项，MED损伤3、BalancEdit损伤24 |
| T2G：AlphaEdit | 150编辑 / 571查询 | **78.1111%** | 28.6667% | 多层多模态固定适配；具体精度和输入差异见原报告 |

| T2G：GRACE | 150编辑 / 571查询 | 78.1111% | 1.6667%–2.1667% | 40个评分载荷UNKNOWN；2,148项bank中1,200项达到生成上限，范围并非置信区间 |

MEMIT-MM 的 single T2G CORE 为68.1667%，MED为79.5%；single与最终bank不能混为一谈。上述对照均按各自原项目固定配置或必要适配实际运行；方法的运行精度、编辑状态、训练信息与计算量不同，不能把表中差异直接当作完全受控的机制因果结论。原146的single结果并非所有对比方法都在150扩展阶段重新生成。完整对照：[BalancEdit](../med150_balancedit_v1_20261028/REPORT_ZH.md)、[AlphaEdit](../med150_alphaedit_v1_20261028/REPORT_ZH.md)、[GRACE](../med150_grace_v1_20261028/REPORT_ZH.md)、[MEMIT-MM](../med150_memit_extension_v1_20261028/REPORT_ZH.md)、[MED150](../med150_v1_20261027/REPORT_150_ZH.md)。

## 瓶颈诊断：单专家和最终库

原146的557个合格T2G编辑—查询事件，single与最终bank逐项绑定输入、模型、运行配置和随机状态：430项双对、115项双错、10项single对/bank错、2项single错/bank对。最终bank有540项选择目标专家、17项选择其他专家、0项OFF；115项双错中112项最终选择目标专家且评分载荷相同。

因此，这个固定支持上的主要T2G缺口已经存在于单专家阶段；仍有少量变化与不同专家选择同时出现。这是配对观察，不能仅凭数据断言具体的写入、表征或路由因果。见[原146 T2G分解](../med146_t2g_decomposition_v1_20261029/REPORT_ZH.md)。

## 固定层位实验：泛化与保护的权衡

原146中按既有资格和固定顺序选16编辑，508个single事件；T2G合格64项、T2L合格30项。C21在第21层、CDEEP在第30层，均使用相同source/FIT、初始状态和固定160步，但两个新臂**均没有原MED保护曲率**，所以不能将相对MED的全部差异归因于层位。

| 面板 | 原MED CORE | C21 CORE | CDEEP CORE |
|---|---:|---:|---:|
| T0 | 100% | 100% | 93.75% |
| FIT | 100% | 100% | 93.75% |
| T1G | 100% | 100% | 93.75% |
| T2G | 75% | 85.9375% | **92.1875%** |
| T1L | NA | NA | NA |
| T2L | **96.875%** | 83.3333% | 75% |

T2L的30项 Base CORE 正确查询中，MED/C21/CDEEP分别损伤1/6/10项；CDEEP相对MED在T0损失1/16、FIT损失4/64。C21相对MED的T2L宏下降13.5417 pp，CDEEP下降21.875 pp，均超出用户后续允许的5 pp。原实验保护门槛 **FAIL**。

逐项比较C21→CDEEP：T2G 64项中修复5、损伤1；T2L 30项中损伤6、修复2。16编辑中仅1个同时出现至少一次T2G修复和T2L损伤；该结果不能证明两种变化独立，也不能用来挑选编辑。见[固定层位报告](../med_fixed_depth_v1_20261030/REPORT_ZH.md)和[逐项诊断](../med_depth_pairwise_v1_20261031/REPORT_ZH.md)。

## 路由和保护尝试

1. **模态分差0.02路由：FAIL。** 原146 T1G CORE从86.6438%增至99.6575%，T2G从77.5114%增至77.6826%；但原146 Base和R0共同正确的80个去重非native查询新增CORE损伤4，T2L CORE从98.3871%降至91.9355%。全部2,148查询原R0均为ON，OFF没有实证支持。不能替换原R0。见[报告](../med150_modal_margin_v1_20261028/REPORT_ZH.md)。
2. **文本弱优势约束：FAIL。** 2148个选择与上述模态方案完全相同，未触发回退，损伤也相同。该DEV上不再扫描相关文本分差或围绕已见个案补丁。
3. **来源问句精确切换：开发门槛PASS，但不提高T2G。** 原146 T1G CORE从86.6438%到99.3151%，T2G保持77.5114%，80项共同正确保护支持新增损伤0。T1G包含原生相同问句，任务构造有利于精确匹配；OFF无支持，不能自动替换原R0。原始执行在决策冻结前整体反序列化评价计划，参考与Base资格字段进入进程内存；代码决策未使用这些字段，访问边界已在[报告更正](../med150_exact_switch_v1_20261028/REPORT_ZH.md)中披露。
4. **Base/MED一致性保护回放：FAIL。** 深层候选在T2G达92.1875%，但相对MED仍有6/29个共同正确T2L项新增CORE损伤，T0损失1/16、FIT损失4/64。仅复用既有预测和评分，真实多分支推理另有成本。见[报告](../med_agreement_guard_v1_20261031/REPORT_ZH.md)。

## 失败、未知和停止条件

- Cross-FIT 单步局部诊断未见预登记信号，且梯度余弦等部分预登记审计缺失；不能称完整机械审计通过或据此扫描参数。新增4个编辑的FIT训练轨迹分析同样未触发预设差异。两个负/不完整结果保留。
- 深层来源回放：因无法证明历史来源与全部保留角色完全隔离，已停止在准备阶段；无模型训练、生成或评分，不是方法效果失败。
- 来源教师：原MED教师与16编辑身份绑定已核验，但部分历史评分尝试账本未闭合，无法确保后续不重复已评分载荷；已停止在准备阶段，无真实教师缓存、训练、生成或评分。仅出现可追溯缺失证据并完成全链核验后才重新评估。[准备报告](../med_source_teacher_v1_20261031/PREPARATION_ZH.md)。
- 用户明确停止第二方向及57/59源方案的数据准入与实验准备，不得恢复或通过改名绕过。MED R0、150专家及备份、M13P原始资产的保护要求保持不变。
- 新增4条的T2L无合格支持；上述16编辑面板的T1L支持0。不能以空支持宣称保护通过。原150 bank实际OFF支持为0。

## 相关工作与创新边界

[ScopeEdit](https://arxiv.org/abs/2607.01978) 已提出局部分支、证据门控的共享分支，并研究深层跨模态响应；[M2Edit](https://aclanthology.org/2025.emnlp-main.1478/)研究多粒度知识和多组件编辑；[DiKE](https://proceedings.iclr.cc/paper_files/paper/2026/hash/835ced593e668e39f19c9ad2f4ee5683-Abstract-Conference.html)研究同主体不同关系的无关知识保护。不能仅用浅深双分支、相似度门控或关系拆分的重新命名作为独有创新。见[相关工作核查](../med_scope_prior_art_v1_20261031/REPORT_ZH.md)。
