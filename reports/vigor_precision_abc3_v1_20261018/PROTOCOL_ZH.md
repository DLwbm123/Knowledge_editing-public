# 三个失败点 A/B/C 精度归因（冻结）

用户授权仅 S01/4、S03/3、S06/3，沿用八样本冻结数据、层0、原 Fisher、d/16 主更新与每步最多一次原修正。不得补后续步骤、增加修正、调参、替换、生成或 Judge。

先重建三个点的所有必要接受前缀与目标主更新。每阶段原生/FP32 NLL绝对误差≤1e-5，E相对误差≤1e-5，门决策必须相同；三点全部复核通过后才启动 A/B/C。任一异常停止全任务，不自动重跑。临时状态仅内存保留，每点恢复基础权重，不写模型checkpoint。

- A：原一次修正后的未舍入 FP32 权重，原 editable_fp32 计算（该 Linear 输入转 FP32、输出转回原 dtype）。
- B：同一 A 权重舍入 FP16 再转回 FP32，保持与 A 相同计算；无梯度、无更新。
- C：与 B 数值完全相同的原生 FP16 权重及计算。只有 C 代表原方案。

A/B使用同一 FP32 初始基线和该步 FP32 起点；C使用原生初始基线和原生步起点。null门仍 |累计Δnull|≤.01；原图必须比相应步起点下降。三者报告原整步实际native Fisher cost及≤.001门，A/B仅诊断，不视为可提交的新方案。C及A重新对照原已保存修正结果，保持原容差。

归因同时公开原始NLL和基线调整后的漂移。A→B漂移差单独隔离权重舍入；B→C原始NLL差表示该权重上的计算精度效应，累计漂移差还减去初始FP32/native偏置。报告两者，不混用。正的margin consumed表示绝对漂移增加。

A过B不过：舍入足以致失败；A/B过C不过：计算精度是关键；A不过：修正本身不足。两段均消耗余量则保留混合归因。所有逐点数值、重建回执、失败、时间/显存及报告公开推送。完成后停止，无新监测或自动下一轮。
