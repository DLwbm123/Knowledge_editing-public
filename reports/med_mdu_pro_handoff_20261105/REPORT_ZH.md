# MED / MDU 研究交接：请 Pro 审阅

截至 2026-11-05。本报告面向论文方法研究，目的是请你审阅现有证据、判断完整 150 专家实验的最小可行启动路径，并提出有依据的后续方法方向。本文只含脱敏汇总，不包含原始问答、图像、权重或访问凭据。

## 目标与当前状态

目标是在多模态知识编辑中提升 T2G 泛化，同时保持编辑效果及局部性。当前用户指定 **MDU 是方法主线**，MCE 是同起点、同训练数据和预算的重要对照。期望 T2G、T2L 的绝对水平分别接近 89%、90%，这是参考目标，不是已经达到的结果，也不是两个新硬门槛。用户允许 T2L 相对 MED 下降 6 或 7 个百分点，不将 5 或 7 个百分点设为新实验的硬上限；T0、FIT、T1G、T1L 仍要求不下降，缺少支持时记为 NA，不能当作通过。历史实验保留原预登记判定。

**完整 150 专家 MDU 尚未启动，也没有完整 150 MDU 结果。** 现有最佳可用的全库 MDU 结果是 **101 个 MDU 专家 + 49 个原 MED 专家回退**。此前没有及时启动，除数据保护证据未闭合外，训练、生成、评分和守卫的完整新执行链也尚未接通；这是工程交付尚未完成，不能仅归因于数据问题。

## 方法和评测口径

- MED 是原方法的 150 专家库，使用既定 R0 路由。MED 原终态反映历史保护训练；后续 MCE / MDU 从该终态初始化，但本次继续训练不读取或重建历史保护曲率。
- MCE 对每个专家使用原 native / FIT 训练输入及普通交叉熵；MDU 使用同样输入、初始化、优化器和训练预算，并在答案 token 的固定两个连续片段上加入跨 native / FIT 视图的稳健项。单 token 时使用一个片段；温度和系数均为 1。固定中点切分是位置规则，**不代表事实或医学关系边界**。
- 101+49 实验中 MCE 和 MDU 各有 101 位真实训练的候选专家，原有 25 位依绑定复用，新增 76 位各继续训练 160 步；其余 49 位沿用原 MED。固定 2,148 个 bank 事件，各臂实际新生成 1,121 项、复用既有 25 位候选预测 392 项、复用原 MED 回退 635 项。全部是在原 R0 下的同事件开发比较。
- CORE 是核心回答一致性，FULL 是更严格的完整回答一致性。下表百分比是**编辑等权宏平均**，并非事件总数的简单准确率；支持量应同时报告。整个面板已曝光，不能当作独立确认。

## 主要结果：101 MDU + 49 MED 回退

下表为用户授权补评后的裁决口径；保守冲突敏感性见下。原 MED、MCE、MDU 使用同一 2,148 事件和支持口径。

| 指标 | 支持事件 / 编辑 | 原 MED | MCE + MED 回退 | MDU + MED 回退 | BalancEdit |
|---|---:|---:|---:|---:|---:|
| T0 CORE | 150 / 150 | 100% | 100% | 100% | 100% |
| FIT CORE | 600 / 150 | 100% | 100% | 100% | 100% |
| T1G CORE | 578 / 146 | 86.6438% | 86.8151% | 86.8151% | 86.9863% |
| T2G CORE | 571 / 150 | 78.1111% | 83.5000% | 83.5000% | 94.8333% |
| T1L CORE | 2 / 1 | 100% | 100% | 100% | 100% |
| T2L CORE | 54 / 31 | 98.3871% | 96.7742% | 96.7742% | 63.4409% |
| T2G FULL | 571 / 150 | 75.3333% | 80.7222% | 80.8889% | 94.8333% |
| T2L FULL | 54 / 31 | 0% | 0% | 0% | 6.4516% |

T1L 只有 2 个事件、T2L 只有 54 个事件和 31 个编辑，不能把数值当作充分的保护证据；新增 4 个编辑没有合格 T2L 支持。BalancEdit 是真实 150 专家对照，但其骨干/写入器精度及训练计算与 MED 系列不同；此表不证明纯粹由算法造成的因果差异。

MDU 相对原 MED 的 T2G CORE 在事件级修复 33、损失 2；T2L CORE 修复 1、损失 2。MCE 与 MDU 的 T2G CORE 虽同为 83.5%，逐事件比较仍为 MCE→MDU 修复 1、损失 1；T2G FULL 修复 2、损失 1。不能由宏平均相同断言模型权重或完整回答相同，也不能据此认定 MDU 优于同条件 MCE。

补评后的裁决口径未知为 0；但 4 个历史冲突的原始判定没有消失，若保守将冲突保持未知，T2G CORE 原 MED 为 78.1111–78.6111%，两候选各为 83.5000–83.6667%，T2L不变。评分历史账本不完整，不能排除更早没有留存的重复请求。

## 两个重要消融和限制

**共同 25 专家比较。** 在原 R0 实际选择这 25 位专家的 392 个共同事件上，T2G CORE：MED 75.6667%，MCE 和 MDU 均为 82.6667%；T2L CORE：MED 97.5%，MCE 和 MDU 均为 100%。T2G 支持 99 事件 / 25 编辑；T2L 支持 32 事件 / 20 编辑；T1L 无支持。该子面板与上面的全库面板不同，百分比不能跨面板直接相减。

**全合法二分边界平均。** 同一个 25 专家面板上，以全部合法二分边界平均替代原 MDU 固定中点：T2G CORE 原 MDU / 边界平均均 82.6667%，逐事件 CORE / FULL 判断相同；T2L CORE 从 100% 降至 97.5%，相对原 MDU 损失 1 项。原预登记要求两项同时改善，未见该开发信号。25 个答案长度均大于 2，因而都有多个可选边界，但这不证明边界对应事实、梯度有效差异或语义变化。不得围绕该面板继续扫描分段或修补个案。

**单专家瓶颈。** 原 146 的 557 个合格 T2G 事件中，single 和最终 bank 同对 430、同错 115，single 对而 bank 错 10，反向修复 2。这支持主要缺口已在 single 阶段出现，但不能据此确定写入、表征或路由的单一因果。

**历史深层诊断。** 固定 16 编辑开发面板中，深层臂 T2G 高于浅层臂，但伴随 T2L 和部分原编辑指标损伤；两臂均未使用原 MED 保护曲率，不能把相对 MED 的所有差异归因于层位。该项及其他旧实验均保留其原有失败结论。

## 完整 150 MDU：冻结计划与具体阻塞

用户明确授权使用此前角色未核实的 49 位训练来源；这个授权**允许历史角色或图像组重叠**，但明确封存的问答（包括 V95 / V106 / V111 及其他明确保留记录）仍不可读取或用于训练。不能把“角色未知获授权”解释为“封存内容获授权”。

已冻结的计划是在逐项验证原 MED 初态及已有 101 位 MDU 终态后，给 49 位新训练各 160 步，共 7,840 次更新；原 R0 的 2,148 事件预计对这 49 位路由对应的 635 个事件实际生成，另外 1,513 个已有 MDU 预测在完成输入、状态和路由绑定后复用。预计值须以正式冻结及回执核验，不能用原 MED 输出冒充新增 MDU。最终同支持比较原 MED、101+49 混合 MDU 和 BalancEdit，报告全部角色的 CORE / FULL、分母、配对增损、UNKNOWN 与冲突敏感性。

当前只读身份证据如下：

1. 49 位对应 245 条 native / FIT 训练记录；其项目内 `query_id` 由编辑序号和位置生成，不是可直接与上游封存题号比较的身份，不能用不同 ID 字符串的零交集宣称安全。
2. 源代码显示 `edit_id` 来自上游编辑查询，4 条 FIT 为该原题的派生问句。49 个原编辑身份均能映射到历史静态候选；候选超集不是实际封存清单，不能把组重叠或候选身份直接当作封存证据。
3. 经上游身份桥接，49 个原题与一份实际 16 题封存原题清单交集为 0。另一份局部性清单的 `probe_id` 身份体系尚未证明与该上游题号可比；历史 Stage17 治理记录说明原队列当时曾排除这两类保留身份，但不能单独证明之后所有封存集均已排除。FIT 派生题与其他封存清单的逐题关系也没有完全解决。
4. 已有 101 位 MDU 的新增 76 份训练回执与权重存在，原 25 位有复用记录，旧训练及生成守卫退出为 0；完整新实验仍需逐专家复核初态、输入、终态、配置和预测绑定。文件存在不等于新实验已准入。
5. 49 位训练入口、635 项实际生成、完整评分与报告消费者及独立守卫链尚未全部实现和真实准入。因此目前没有 49 位新训练、没有新生成或评分，也没有新实验时钟。身份审计只读身份字段，未为本次提取 49 位训练问答。

原预登记要求无法通过题目身份排除明确封存记录时停止相关内容提取和实验；不能通过换名、遗漏失败或降低这个承诺来启动。历史 16 题的已排除结果只是部分证据，不等于全部封存身份已排除。

## 请 Pro 重点回答

1. 在允许来源组重叠、但禁止读取明确封存问答的前提下，如何用上游题号、题目派生关系、已有角色锁和可验证回执建立**最小但充分**的逐题排除？请区分精确身份、组级重叠、候选超集和未知，说明哪些情况必须停止，避免要求无界的历史全盘清查。
2. 对 4 条由同一原题生成的 FIT，如何用已存在的派生回执证明边界？若某封存清单使用不同身份体系且无法可靠桥接，有哪些不读取封存问答的可核验方案；若没有，请明确指出而不是假设零重叠。
3. 在保持上述边界前提下，给出可直接执行的完整 49 位训练、已有 101 位预测复用、635 项新生成和统一评分的依赖顺序、最小真实准入、失败处理和资源预算。每台新增存储严格小于 50 GB、实验最长 23 小时、总并发最多两张 GPU；已有实验及其原时钟不得重启。
4. 如何判断 MDU 稳健项是否比相同 MED 起点下的 CE 真有价值？请结合已有事件配对、相同宏平均与不同 FULL、稀疏 T2L 支持提出可证伪的后续消融，说明哪些结论现在不能成立；不能按已曝光题目挑样本或扫参数。
5. 如果目标是完整且有实质论文贡献的方法，请基于 MDU 提出机制与对照，解释训练视图一致性、事实边界和局部性各自如何获得可靠信号；现有锁只有同答案 token 和位置，不能将弱词面或中点假装为事实关系。请比较 [ASAM](https://arxiv.org/abs/2605.23780) 已提出的潜空间对抗扰动、低秩对齐与非对称梯度，说明建议与其差异，以及缺少可追溯事实对应时如何如实处理。
6. 请给出近期最值得执行的次序，并将“可立即执行”“需要补充证据”“无法证明时停止”分开。完整 150 结果和可发表方法是不同问题，不要以新方法方案替代用户要求的完整 150 实验。

既定停止路线保持停止：第二方向 57/59 来源准入、深层来源回放和来源教师实验不能改名恢复。历史有效评分复用；已知失败不自动重试，历史无法核实者依本实验预登记保留 UNKNOWN；若未来另行获得明确补评授权，应另记尝试和可能的历史重复。
