# MED、D 与 D-U：共同路由专家配对归因预登记

目的：判断已有 D 与 D-U 比较中，专家覆盖差异与 T2G/T2L 变化的关系，为同支持普通 CE、均匀跨度和 D-U 训练消融确定对照；本分析不证明医学关系或因果。

固定面板为既有 MED150 原 R0 的 2148 个已曝光 DEV 事件；仅选 R0 实际选中原 D 已训练的 25 个专家的事件，25 个专家从既有训练完成的身份回执读取，不按 owner、表现、分数或问答选择，不补位。输出冻结前已有原 MED、D 与 D-U 三臂，不重新训练、生成或请求评分。先用仅身份字段建立并核验 2148 事件三臂的 query、路由及 25 专家集合绑定；任一不符、缺失或身份无法确定即停止，不靠 owner 推断路由。然后仅为入选事件选择性读取 opaque key 和已获准历史有效 CORE/FULL 判断以及冻结角色身份；跳过问答、图像、token、答案和其他事件判断；已知失败、历史冲突、不可核实保留 UNKNOWN，不重试。已授权 D-U 补评可仅在同合同精确绑定可验证时单独使用，否则保留原口径并说明。

对六种资格角色分别报告事件数、支持编辑数、原 MED/D/D-U 的 CORE 与 FULL 正确数、未知数、编辑等权宏平均及最坏/最好未知赋值边界，以及 D→D-U 和 MED→各候选的已知修复、损伤、未知配对。报告空支持 NA；总体及固定事件选择解释为按路由子集的事后 DEV 描述，不用于训练样本选择、门槛微调或声称独立验证。不能将 D 与 D-U 的差异归因于跨度或取消保护；同一编辑可能贡献多个事件。

资源预算：本机只读 CPU，最多 60 秒，从首次实际分析起计；输出至新报告目录，不超过 10 MB；0 GPU、训练、生成、Judge，不修改旧产物。独立进程使用硬超时及单文件限制；保留失败回执，不重跑已尝试科学分析。成功后仅公开脱敏汇总及代码，通过代理推送并核验远端与匿名访问。若不能验证身份、完整边界或旧评分快照，记录失败并停止，不能伪造准入。后续训练是独立协议，需另行冻结角色、初始化、对照、指标、预算及守卫后才启动。
