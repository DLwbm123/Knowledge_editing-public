# MedTRACE 实验阶段总结

截至 2026-09-29，本报告汇总已完成并交付的父实验、E1/E2 REG24 和 E1+E2 DEV24。E3 仍在运行，E4 未启动；本文不是全部追加计划的最终报告。最近现场检查 E3 为 17/52 组完成、3 组运行、32 组待执行，评分无积压；该进度是快照。

## 主要结论

1. **尚无证据证明某个配置同时稳健提高泛化和保持。** 父实验有部分有利点估计，但部分核心指标缺评分，且没有独立 CONFIRM，不能据此宣布胜出。
2. **给 Direct-LR4 补齐 S+G+D 监督，收益没有跨面板稳定复现。** REG24 的 M7 相对同 W0 的 M6，single T2G 从 95.83% 提高到 97.92%，压力保持均为 59.72%；DEV24 T2G 两者均为 93.40%，压力保持从 64.58% 降至 62.50%。DEV bank24 压力保持两者均为 27.78%。因此仅能报告 REG 上的泛化点估计改善，不能称为联合提升。
3. **保持 CP/Tucker 结构约束并未消除泛化—保持冲突。** KEEP_STRUCT 的 T2G 通常略高，但压力保持显著更低，尤其在真实 bank24；这一方向在 REG/DEV 均出现。部分 FREE4 指标缺评分，须保留 null 和上下界，不把成功子集当作全体。
4. **机械检查支持配对有效性，但不等于效果提升。** E2 REG 与 DEV 共 192 份展开校验，规定 native 生成均未出现 token 差异；并非所有输入都已证明逐 token 等价。全部新增核心 continuation 已核实 80 步，同 W0 配对已核实。
5. **坐标表示与 rank 容量的归因尚未完成。** E3 RAW/SVDGAUGE 正在按预注册队列执行，E4 等待其收口后的资源审计，当前不能回答这两项机制问题。

## 父实验的证据边界

父实验完成了预注册队列，包括相应三种子 REG/DEV 及固定四编辑结构/rank 消融。不是所有方法都设计了三种子：M2、M6 和固定四编辑消融主要为首种子；缺失或未设计的种子不能补成完整三种子结论。父 DEV M3 压力保持三种子点估计 84.72%，M0 为 67.36%，但 M3 T2G 缺评分，不能据此证明联合改善。父比较的监督配方也不完全相同，结构贡献不能从不匹配的监督对照中单独归因。

编辑35的支持/正式问题碰撞已经按授权修正，受影响旧结果隔离；修正版角色审计通过。父历史原件及已发布结果不改写。正式保持面板部分分母很小，例如 REG T1L 只有 2 个合格输入、标准 T2L 只有 9 个，不能外推为广泛保持能力。

M7 仍依赖 CP-M0 教师，因此检验的是 student 的结构初始化需求，不是证明整个流程无需 CP。辅助 G_check 仅有原定少量诊断覆盖，尚不能称为全编辑辅助验证。没有新增独立确认集；重复 seed、前缀和 QA 都不增加独立病例数。
