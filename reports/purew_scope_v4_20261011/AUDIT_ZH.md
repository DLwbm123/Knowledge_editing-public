## 已准备的 C/U/H 方法

三臂均只写已有 `model.layers.21.mlp.down_proj.weight`，冷启动同一 Base；视觉与其他参数冻结，部署无新增参数或编辑分支。C 使用原 Base 的完整固定右零空间，U 直接使用完整梯度，H 在 U 上追加合法历史源题/GFIT 回放。没有 448/64 限制、RLS 或门控。

U/H 使用 C 每个已提交步骤的**实际 FP32 写入范数**；不再各自按当前状态计算参考范数。每步检查实际写入误差（相对 0.0005、绝对 0.000001）。共同目标为正而方向为零、或实际范数不合格时，保留失败并停止，不悄悄跳步。C 的轨迹决定共同范数，结论限于这一登记参照，不能外推为所有范数日程的普遍效果。

合成 CPU 检查通过：投影、三臂共同范数、实际写入误差、历史完整循环、评价角色排除、未准入历史拒绝、零方向停止。真实 VLM 准入尚未运行；训练/续跑/评分控制器也尚未完成本轮适配。方法草案见 METHOD_DRAFT.json，不冒充完整冻结协议。

## 2026-10-11 作者定义核对后的更正

M3Bench 原文和当前作者代码均将 T2G 定义为同图的语义改写；同图本身不是构造错误。真正的患者/病例图像泛化属于论文 T1G，而当前 release 的 T1G 实现使用 blur/crop/contrast/noise，不能把增强图当作独立患者证据。旧八编辑中 owner8 的 T2G 使用补充图像，是本研究适配差异，仍按原冻结绑定保留。
