# 完整源层作用与null层完全不变：三例均有严格矛盾证书

三例固定成功教师完整源输出精确复现；在“保留教师完整源层作用Delta KS=DeltaT KS，并令完整原null层作用Delta KN=0”的强子问题中，三例均找到完全相同的原生源/null输入，但教师在该输入上的更新作用非零。用FP16精确二进制整数点积确认非零，形成 **3/3严格作用矛盾证书**；两种固定阈值数值一致性检查也均拒绝。没有新增候选、无关题生成或Judge。

**这不是原abs null NLL漂移≤.01不可行的证明。** Delta KN=0比原标量NLL要求强，完整源层作用也比源语义正确强；原null标量可能通过其他位置/下游作用补偿保持。本轮只排除该强层作用子族，不排除原标量保护可行点、整个语义等价集合或Pure-W方法。没有性能提升或新locality结论，旧NA不回填。
