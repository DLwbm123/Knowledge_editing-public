# V100：两个候选 Base 均未形成可迁移的纠错与保护任务集

固定对照已完成：旧 LLaVA-Med 90 个输出只读复用，Qwen2.5-VL-7B-Instruct 和 Lingshu-7B 各新增 90 个输出。**两个候选的较强纠错与保护组合均为 0，未达到预注册的至少 8 个及类别覆盖门槛，因此本轮不迁移、也不训练 TT/CR-TTI。** 不能据此说所有更强 Base 都无效，或 TT 方法失败。

Lingshu 确实在少量肺实变阳性病例上给出正确答案，但还没有解决当前任务瓶颈：正反问的一致性不稳定，部分阴性出现假阳性，而且仅有的两个“核心正负辨别均正确”配对，其侧别目标原本就答对，不具备本轮定义的持续纠错需求。这个结论即使忽略所有额外扩写也不变，并非单纯由严格措辞评分造成。

Qwen 有 12 个 UNKNOWN：阴性正向 5、阴性反向 1、阳性正向 6，均为仅称“可能提示”、同时保留不同解释而没有确定存在性结论的回答。其余回答和 Lingshu 回答无 UNKNOWN。不能将这 6 个阳性“可能”当成已经正确识别，也不能把不确定阴性当成明确假阳性。

存在性核心平衡准确率（UNKNOWN 计入完整分母且不得分）：旧 Base 正向/反向均 50%；Qwen 为 33.3%/46.7%；Lingshu 为 50%/53.3%。两候选均未达到预先冻结的“两种问法至少 75% 且多发现类别”的辨别改善信号标准。

Qwen 15 个原侧别问题全部回答右侧，7/15 与本队列右侧频数相同；简洁控制也仅一例改为左侧。Lingshu 的原问与简洁问有所变化，但简洁问有 12/15 回答左侧。侧别正确数的提升仍混有答案倾向，不能自动解读为视觉定位改善。

## 核心正确与完整来源支持分开

| 完整来源支持的角色 | 旧 Base | Qwen | Lingshu |
|---|---:|---:|---:|
| 原目标 | 4 | 2 | 4 |
| 简洁目标 | 6 | 7 | 9 |
| 阴性正向 | 15 | 7 | 2 |
| 阴性反向 | 15 | 9 | 2 |
| 阳性正向 | 0 | 0 | 0 |
| 阳性反向 | 0 | 0 | 2 |

来源审阅保守区分“未获报告支持”和“已经证明医学上错误”：新添正常心影、纵隔或膈肌状态、未报告的积液否定、超出报告的病变位置或范围，都不会自动获得完整来源支持；其中有些是未证实，而不是已证明假。一般性建议或教育性说明本身不作为患者事实错误，但明确不支持的医学解释单列。私有逐项记录保留完整回答与具体理由，没有通过文本长度或字符串完全匹配打分。

Lingshu 部分回答在核心否定后进一步宣称正常健康胸片，或把局灶肺实变扩成双侧弥漫、多肺叶病变；还有回答声称心影正常、无积液，而来源明确写有心影增大和胸腔积液。这类扩写阻止作为已经掌握且可保护的患者事实。

作为描述性敏感性检查，完全忽略扩写、只看核心事实时，Lingshu 有 2 个正负双图、正反两问均正确的配对；但这两个配对的目标侧别两问都正确，因此较强纠错组合仍为 0。Qwen 的核心辨别配对与核心较强组合也均为 0。没有因此修改正式门槛。

## 执行、预算与边界

- 模型前协议及推理代码提交 `ee00b115`，已推送并验证匿名访问后才启动候选。
- 完整复用 V98 已审阅的 15 配对、30 名不同患者、90 问。原来源 18 对中 3 对排除，不补抽、不换事实或患者角色。只用官方 TRAIN，不读取 validation/test 或旧 DEV/CONFIRM。
- 现有权重只读复用，模型版本使用下载回执记录的固定 revision。没有新权重下载或模型副本；只检查必要分片存在及大小，不声称重新验证了逐字节一致性。
- 原生模型类、各自 processor 与 chat template；同一 BF16/SDPA、greedy、1280 图像 token 上限、1024 生成 token 上限。实际每图 1221–1260 视觉 token，180/180 请求各有一次实际视觉模块调用。旧 LLaVA 的视觉处理分辨率不同，因此比较的是可用 Base 系统，不隔离权重与分辨率贡献。
- 新 180/180 输出 EOS、0 截断、0 重试；12,777 forward、180 vision 调用、0 backward、0 更新、0 teacher、0 模型 judge。
- Qwen 模型阶段含加载约 303.91 秒，Lingshu 约 192.96 秒；独立 supervisor 统计整个顺序 GPU 进程链 **511.39 秒（约 8.52 分钟）**，包括进程启动退出开销。低于 1,800 秒 GPU 上限和 1 小时墙钟上限。
- 两次加载后显存读数均为 16,154 MiB，仅是该时点读数，不是全程峰值。实际 worker 与 supervisor 的中性 argv 检查通过，GPU UUID 一致；预算守护正常退出。
- 结束时远端本轮新增占用约 0.31 MB，本机私有证据约 0.50 MB（另有少量源码与报告），均远低于每主机 2 GB 上限；全部三个已登记进程身份确认退出。
- 无训练 checkpoint，私有报告、问题、图片、患者索引、回答和 tokens 不公开。源代码、协议和脱敏聚合公开。

这是有意针对旧模型问题的开发资格筛查，不是独立确认，也不是总体医疗能力排名。没有新增临床专家裁决，预训练曝光未知。正负病例来自不同患者，配对正确亦不等价于只改变单一病变的严格视觉反事实证据。

## 决定

本轮完成但未准入方法迁移。保留两个候选的全部正、负与 UNKNOWN 证据，不将 Lingshu 少量阳性正确或侧别提高写成已建立纠错保护任务集，也不通过继续调当前问法、分辨率或补病例挽救 V100。后继方案依据新的独立假设另立协议，不能追改本轮结果。
