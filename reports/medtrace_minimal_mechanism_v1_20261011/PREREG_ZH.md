# TT 等价表示与源题视觉依赖：最小诊断 v1

授权：用户 2026-10-11 要求先验证第一条机制，并检查源题视觉依赖，再决定算法开发。继承已停止 2×2 的 C 候选，只读复用初始态与终态；旧运行保持停止。

固定数据为已有 8 个 owner 的 native + 4 FIT + 2 GFIT，共 56 条源题。owner 8 使用此前冻结修订版，报告区分前 7 个与第 8 个。不读取 BASIS、HELDOUT、T1G、T2G，不筛选成功子集。

## H1：相同函数的 TT 表示是否改变一次更新

8 owner × BASE/C_FINAL 两态 × 三种表示，共 48 个内存中单步探针。三种表示是原始坐标、三个内部 bond 同时逆序置换、三个内部 bond 同时施加交替对角缩放 [0.5,2]，相邻 core 使用逆缩放。参数仍为 7,168 个 TT88 core 参数。置换是等距对照，缩放是条件数为 4 的非等距变换。

每种表示先验证 TT 函数等价与 native logits 一致；再用全新 Adam 状态，沿用输入组 LR 1e-4、输出组 LR 1e-3、clip 1 和原 RAW 写入规则。目标固定为第一步的 .25 native + .25 FIT1 + .5 GFIT1。不是原优化器轨迹的续跑；C_FINAL 仅提供非零状态。

测量实际线性算子更新的 Frobenius 范数、相对原坐标的范数比与方向余弦，以及全部 7 条源题的有限步 NLL 改变。方向与尺度分开报告；不实现新优化器、不调步长、不训练 LoRA 对照。本轮只能检验坐标敏感性，不能证明其造成泛化失败，也不能证明 Riemannian 优化有效。

## H2：源题预测是否依赖视觉输入

56 条源题 × 2 态 × 原图/固定错配/视觉嵌入置零，共 336 个条件。错配 donor 在预测前固定为下一个图像不同的 owner 的 native 图像，按 owner 循环顺序查找；保留文本、位置和 attention mask，仅替换 576 个视觉嵌入。置零是分布外消融，不是黑图或自然的无图输入。

首答案 token 无答案前缀，主报首 token KL、目标 logprob/竞争 margin、argmax 改变及目标 top1；完整答案 teacher-forced NLL 仅作为辅助。每个 owner/state 的原图 native 重复一次提供数值噪声参照。错配图没有反事实真值，不报告该条件医学正确率；目标 top1 也不等同完整回答正确。按 owner 等权汇总并保留每题、每态结果，不以 token 池化替代 owner 统计。

## 预算、停止与交付

- GPU：pro5000 物理 GPU6，UUID GPU-ffc224df-661c-5aff-e221-ec361bb4e5d6，启动前要求至少 45 GiB 可用。
- 精度：复用 FP16 视觉/prompt prefill，主模型和 expert 为 FP32 MATH SDP，关闭 TF32；与现有冻结输入约定一致。
- 预期 864 个计数后的语言模型 forward、144 backward、48 临时单步；硬上限 900/160/48。预处理 56 次视觉编码单列，不冒充零成本。
- 总上限 1 GPU 小时；本轮新增 Judge 0、自由生成 0、持久 checkpoint 0。额外输出预计低于 10 MiB，磁盘保留 8 GiB。
- 不续跑、重试失败轨迹、增加 seed/强度/题目、调整阈值或自动扩展算法。失败保留回执；旧模型与 checkpoint 全部保留。
- 无预设科学成功门槛；报告连续量与等距对照/重复噪声。只有表示等价检查通过，才解释更新差异。弱视觉敏感不能独立证明数据错误或模型完全不看图。
- 实际完成后发布源代码、匿名数值结果、报告、成本与限制到匹配公开 GitHub 分支；不发布题目、图像、患者信息、原始 logits 或模型权重。
