# 最小验证结论：TT 坐标敏感性成立，视觉问题需要分题型解释

本轮已完整执行：8 个固定 owner × 初始态/C160 终态 × 3 个等价 TT 表示，48 个临时单步；同时覆盖 56 条源题的原图、固定错配图、视觉嵌入置零。所有 16 个 owner/state 单元完成，864 次语言前向、144 次反向、0.240383 GPU 小时，退出码均为 0。新增 checkpoint、自由生成和 Judge 均为 0。旧实验仍停止，原 C 候选保留。

## 1. 当前 TT 更新确实依赖等价表示，且差异不限于步长

把相邻 core 乘以互逆的对角矩阵，TT 表示的函数保持相同，但当前优化规则产生不同的算子更新。三个内部 bond 的缩放均固定为交替 0.5/2，未扫描强度。

| 状态 | 对角变换后/原坐标的更新范数比 | 更新方向余弦 |
|---|---|---|
| 初始态 | 平均 1.9449，范围 1.9344–1.9575 | 平均 0.7533，范围 0.7251–0.7899 |
| C160 终态 | 平均 2.6806，范围 2.3307–3.1196 | 平均 0.6160，范围 0.5754–0.6577 |

8/8 owner 在两种状态下均出现这个现象。等距置换对照的范数比接近 1、方向余弦接近 1；终态最小余弦仍大于 0.999999998。原图重复 logits 完全一致；变换前等价性检查通过，最大 logit 差仅 2.48e-5（置换的浮点运算顺序），对角变换为 0。

这支持一个明确结论：当前固定 core 学习率、clip 和 RAW 写入规则，并不能唯一约束实际算子更新；同一模型函数可以因 TT 坐标不同而走出不同方向。单纯统一学习率或总步长也不能消除方向差异。

它不是新的普遍理论发现，也不是当前泛化失败主因的因果证明。探针使用全新 Adam 状态，C160 只是一个非零起点，不是原训练续跑。初始态对角变换的源损失改善更大，但其实际更新也约大一倍，不能据此称算法更优。终态中，原坐标与对角变换的一步平均源 NLL 都有上升；不将这些临时步作为改进候选。

## 2. 模型存在图像内容依赖，首词指标会漏掉它

| C160 终态上的干预 | 首答案 token 改变 | 任一目标 token 预测改变 | 全目标 token 均为 top1 的题数 | 平均全答案 ΔNLL |
|---|---|---|---|---|
| 原图 | — | — | 53/56 | 0 |
| 固定错配图 | 0/56 | 20/56 | 35/56 | +0.1557 |
| 视觉嵌入置零 | 40/56 | 56/56 | 0/56 | +4.2741 |

换图后首词全部未变，但 20 题的后续 token 预测变化，18 题失去原有的全目标 token top1 一致性；native 的该一致性从 8/8 降到 4/8。因此不能从首词不变推出“模型不看图”。初始态换图也使 33/56 题的某个目标 token 预测改变。所有完整目标指标均为 teacher forcing，**不是自由生成准确率或错配图片的医学正确率**。

视觉依赖在任务间不均。C160 终态 owner1/3/5 的换图平均 ΔNLL 分别约 +0.327/+0.218/+0.672；owner2/4/7/8 的目标 token argmax 全部保持不变，但连续概率仍有变化。没有适用于错配图的反事实标签，不能把这一组直接判为医学失效。

## 3. 一部分源题本就不应依赖具体图片

文字审阅发现，owner8 的 7 题明确问一般知识与影像不能确定个体原因的边界；另有 3 道 GFIT 已在题干给出实体，再问一般功能/治疗类别。至少 10/56 题在文字层面不要求靠具体图片回答，另有一道 GFIT 给出了主要解剖定位线索。详细匿名结构见 [文字审阅](SOURCE_WORDING_AUDIT_ZH.md)。这不是临床标注复核，也没有重划主统计面板。

owner8 换图后 7 题的目标 token 预测均未变，符合其问题设计；置零却令 7/7 首词改变。这提示置零还引入显著分布外扰动，不能把“消融后变化”全部解释成有效视觉推理的证据。

## 下一步开发判断

优先研究 **TT 算子更新对等价表示的一致性**。开发门槛应同时约束方向与尺度，并覆盖 G1=0 的退化初始态及非零态；性能比较需要原 RAW 与匹配实际算子步长的对照，防止把步长差异当作机制收益。本轮尚未实现或验证这种修正。

视觉方向先完善“哪些问题需要图像证据”的定义和有真值的反事实检验。现有结果不支持直接把 56 题统一当作视觉缺陷，再为全部源梯度强加视觉对齐。本轮到此结束，未启动新算法、后续训练、数据改写或监测。
