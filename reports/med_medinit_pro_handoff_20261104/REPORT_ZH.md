# 请 Pro 审阅：MED 初始化的 CE / D-U 是否值得扩展到 150

## 希望审阅的问题

请依据下面的真实开发结果，判断是否值得把 MED 初始化的普通 CE 和 D-U 方案扩展到 150 个专家；如有必要，请给出先扩到有来源许可的 101 个专家、再处理其余 49 个未知来源的合理顺序，以及预登记的对照、数据角色、评价与停止规则。请明确哪些结果能支持决策、哪些不能；不要因为小规模已曝光开发集结果就假定全量结果可复现。

## 现有 MED 与本次方法

MED V133 是当前方法主线；原 MED150 专家库与 R0 路由保留。这里的两臂都是**从每个原 MED 专家终态继续训练**，不是原始 TT 初始化，也不是新建完整 MED：

- **MED-init CE（MCE）**：对既有 native 和四条 FIT 来源输入使用普通交叉熵。
- **MED-init D-U（MDU）**：使用同样的输入和普通交叉熵，再加固定权重的源/FIT 跨视图跨度稳健项。答案 token 按固定位置分为两个连续非空片段；单 token 时为一个片段。每步选 native 加依固定顺序轮换的一条 FIT；对每个片段，按温度 τ=1 对两个视图的片段损失做 log-sum-exp 聚合并取片段平均，稳健项系数 λ=1。对软最大权重先脱离计算图，再使用同参数重算的片段损失反传；详见源码。

两臂都逐专家从同一个经身份绑定的 MED 终态复制初始状态，新建、清零 Adam 优化器；冻结骨干，编辑位置为第21层 MLP down projection，每专家160步，梯度裁剪1.0，使用相同源/FIT、seed、运行与评测合同。原 MED 权重包含既往保护训练的影响；本次继续训练**不读取或重建保护曲率**。因此不能宣称这是一项隔离历史保护机制的实验，亦不保证继续训练会保留全部功能。两臂只是开发方法对照，不直接声称最终投稿方法已确定。

源码：[双臂训练](../../experiments/med_medinit_loss_v1/train.py)、[跨度目标](../../experiments/med_proposition_generalization_v1/robust_objective.py)、[训练工作器](../../experiments/med_medinit_loss_v1/train_worker.py)、[预登记](../med_medinit_loss_v1_20261103/PREREG_ZH.md)。

## 实验支持与结果

固定25个先前已准入、实际可路由的专家；两臂各实际训练25个专家、各4000次参数更新。保持原 R0，在原2148个事件中，每臂对选中这25个专家的392个事件实际生成，余下1756事件经绑定复用原MED输出。以下只比较**共同392事件**，不是完整150专家都经过新训练的结果。题目所属编辑的数量与被选中专家数可以不同。

| 编辑宏平均 | 原 MED | MED-init CE | MED-init D-U | 支持 |
|---|---:|---:|---:|---|
| T0 CORE / FULL | 100% / 100% | 100% / 100% | 100% / 100% | 共同面板 |
| FIT CORE / FULL | 100% / 100% | 100% / 100% | 100% / 100% | 共同面板 |
| T1G CORE / FULL | 80.0000% / 78.3333% | 81.6667% / 78.3333% | 81.6667% / 78.3333% | 81事件、30编辑 |
| T2G CORE / FULL | 75.6667% / 70.6667% | 82.6667% / 77.6667% | 82.6667% / 78.6667% | 99事件、25编辑 |
| T2L CORE / FULL | 97.5000% / 0% | 100% / 0% | 100% / 0% | 32事件、20编辑 |
| T1L CORE / FULL | NA | NA | NA | 无支持 |

相对于原MED，两臂在T1G CORE各修复1、损失0；T2G CORE各修复8、损失1；T2L CORE各修复1、损失0。两臂在这些共同事件的CORE配对无差异，但T2G FULL相差1个百分点；CORE判定相同不说明权重或完整回答相同。T2L FULL全部为0，不能把CORE 100%解释为该项FULL表现也好。

原实验只复用可核实历史评分，故初报有未知且为 INCONCLUSIVE。用户随后明确要求补评：T2 的43个去重载荷最终均有效，T1G 的7个去重载荷均有效；以上各项的两新臂未知均为0。第一次T2补评误选评分器接口，43项已登记但0实际请求，用户授权修正后各实际请求一次；失败及恢复均保留。历史尝试账本并不完整，不能排除更早未留存的重复；原评分与当前评分均为 Astra medium，实际不可变快照未知。原报告不覆盖，最新口径见 [T1G补评与完整表](../med_medinit_t1g_supplement_v1_20261104/REPORT_ZH.md)、[T2补评](../med_medinit_t2_recovery_v1_20261104/REPORT_ZH.md)、[T2首次失败](../med_medinit_t2_supplement_v1_20261104/REPORT_ZH.md) 和各自执行审计。

## 扩展前必须保留的限制

1. **已曝光 DEV、小样本和选择条件。** 共同392事件由已固定的25个可路由专家决定，不能视为独立测试或整个150的代表；不要根据这次结果选专家、改变阈值、超参数或补题。全部角色和分母应提前冻结。
2. **150 不等于已准入150。** 目前此前有训练来源准入的为101个专家（包括新增4），其余49个 VQA-RAD 来源与历史保护角色存在组级关联或身份边界未知。原146 native/FIT复用授权不能自动解除后来的保护角色；没有新的明确来源角色依据前，不可读取其受保护问答或宣称49项已获准。可以考虑预先登记101新专家加49原MED回退的混合库，必须明确覆盖而不是冒称150个新训练。
3. **T1L无支持，T2L支持稀疏。** 当前T1L为NA、T2L仅32事件/20编辑，且FULL为0；不能由此断言所有局部性类别均不下降。原150中新增4的T2L也无合格支持。需事先说明真实支持、数据角色和缺失项。
4. **对照和解释。** 至少保留同输入、同路由、同支持的原MED及两臂；需要论文比较时保留现有BalancEdit等标准配置对照并披露数值精度差异。已有 MED150 与 BalancEdit 的150结果属于不同汇总范围，不能直接与本表25专家子集比较。前次无曲率、原初始化的 D-U 结果或可训练桥结果不能作为该次方法等价证据。
5. **当前用户目标。** 优先兼顾 T2G 与 T2L 绝对水平，参考约89%和90%；不再把T2L相对MED下降5pp作为硬淘汰，也不将7pp设为新硬限。T0/FIT/T1G/T1L不下降仍是要求；缺失支持应标NA而非判通过。新实验要分别给出CORE/FULL、编辑宏平均、配对修复/损失、事件和编辑分母，以及失败/未知。
6. **边界与成本。** 不恢复已停止的第二方向57/59、深层回放或来源教师路线；不得擅自使用仅对旧实验单次授权的受保护曲率。每个新实验先冻结假设、对照、数据角色、预算及停止规则；每台新增实际存储<50GB、总时长≤24小时、独立守卫，并保留唯一30分钟跟进。原MED及M13P保留库不得覆盖。

请 Pro 评估：本结果是否足以支持全量扩展，还是先做101+49回退、哪一臂优先及为何；如何控制开发面板选择偏差、检验 T1L/T2L 缺失支持，并设计能区分初始化和损失贡献的公平比较。请不要将结果相近直接解释为方法等价或保证后续性能。
