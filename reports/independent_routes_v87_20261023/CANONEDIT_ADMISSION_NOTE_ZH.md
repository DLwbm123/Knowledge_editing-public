# CanonEdit迁移的当前实现边界

已读原文Section3–5、Algorithm1、Appendix C Eq34与Table5。它实际需要old/new完整答案序列的log概率差（求和而非平均）、来源rewrite/paraphrase margin、从当前模型优化的隐藏输出残差、key配对低秩基础变化、同一chart上的target/protected Jacobian、α=.04的Gram信赖代价、小规模活动集QP、最多有限次重新线性化，以及完整模型目标/保护预算审核。无合格候选时原模型不变，不能将局部QP可行或零缺口写作自由回答正确。

本VQA来源提供正确参考及同义FIT，不直接提供论文请求三元组中的真实old答案。已冻结当次Base在来源输入上的完整回答可以作为“模型输出替换”对照，但不能冒称旧临床事实或CW/CF证据配对；必须另立这种数据角色，且原始完整序列margin可能与实际greedy答对不同。不得借用已曝光T2G答案构造old/new，或默默改成长度归一化让门槛好看。

TT限制下还需落实低秩chart到全部四核可表达更新的接口，并明确原单层/多层atlas差异、scope mask与原全矩阵作用的差别。直接将早前512-root CE约束QP改名不是该方法的实际迁移；只做候选打分/机制面板也不算完成实际训练与自由回答。下一独立CanonEdit协议必须解决上述接口、来源目标及必要对照后再运行；当前仍待实施，不因其他路线失败而取消，也不以填满空卡为由伪造适用数据或训练。
