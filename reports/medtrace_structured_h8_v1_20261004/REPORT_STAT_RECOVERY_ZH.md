# CPU 汇总文件大小读取修复

首次完整 CPU 汇总已执行消费者与评分绑定检查和指标计算，但在权重存储测量阶段调用 `stat().st_size()` 失败；该成员是整数属性。失败前没有写出公开指标目录，也没有删除权重。

修复只将这一处改为 `stat().st_size`。实际 Tucker checkpoint 的加载、展开和大小读取检查通过：1600 个结构参数展开为73728个推理参数，实际文件19197字节。指标公式、bootstrap次数/seed、数据角色、六臂、训练与生成源码、评分结果和预算均未改变。

原源码、错误日志、失败回执和资源账本私有留存；首次失败 CPU 墙钟上界268.491832秒（包含启动等待）保留，不重置首次时钟。只恢复有限 CPU closeout，不重新训练、生成或评分。报告源码修复提交6ecfae4；原GPU和Qwen运行版本独立保留。
