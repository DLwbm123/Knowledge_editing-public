# 实际预测分布参数统计：接口、存储与复杂度准入审查

## 结论与本轮动作

现有运行时能提供完整logits和所选矩阵的一阶反向传播，离线形成参数统计、释放原记录后只传统计的接口可实现。但**目前没有完成可准入的完整分布保护实现**：已知可直接计算的低秩/对角/因子形式都是附加近似；尚无经界定的覆盖或近似误差条件，且不能把近似成本低当作真实保留机制成立。

显式完整Fisher矩阵超出资源上限；保留旧输入或计算图供在线矩阵乘积又越过source-only边界。这只排除这两条直接路径，不能证明所有压缩表示不可能。小型近似在工程上可能可行，尚不能因而冻结一个新的编辑候选。当前不启动模型、不估计新统计、不派生旧控制器或更多一阶标量锚，不把未知写成失败实验。

本轮阅读本地代码、已核论文分析和一次远端只读配置/计数，并运行无torch/无网络的整数存储算术；模型0、GPU0、新数值实验0、Judge0、只读SSH1次。历史模型、评分、失败和NA均未触碰。SIZES.json与static_sizes.py可复算尺寸；它不是模型数值检查。

## 1. 实际接口与因果位置

|现有代码|已核实的能力|不能据此假定的能力|
|---|---|---|
|llava_runtime.PreparedBatch.forward_kwargs|传inputs_embeds、attention/position、labels，use_cache=False，返回dict|它仍包含历史输入/标签/嵌入，不能作为“参数统计”传入在线编辑器|
|llava_runtime.build_edit_batch|官方模板与视觉展开，返回原/展开labels、attention与输入embeddings；函数本身无历史记录持久赋值|不能把返回的batch、激活或计算图留给在线反复调用；也不能省掉模板/EOS/图像绑定|
|editor.nll|logits[:,:-1]配labels[:,1:]，屏蔽-100后完整mean CE|它提供的是参考mean-NLL，不能直接当分布KL、token竞争保护或模型Fisher|
|editor.editable_fp32|只将选中矩阵/输入转FP32、其余native，原生提交与异常恢复；支持已有一阶梯度路径|不是全网络FP32；没有现成经验证的JVP/HVP、二阶attention反传或functional-call路径|
|anchors3_ops.calibrate|离线逐记录参数梯度，只返回CPU参数矩阵和匿名标量；原数据在函数内消亡|A32的参考loss梯度不能改名为模型分布梯度；新统计需要新实现、独立冻结与恢复准入|

若离线只需要分布，不应让模型隐式计算labels CE后误取其loss；应在保留外部合法位置mask后将forward的labels置None，从返回logits构造完整softmax量。任何新路径都须核同一因果位置、mask、EOS及缩减。逐位置处理可降低额外softmax工作内存，不能用top-k直接替代完整词表而不披露尾部近似。

原校准positions=19237来自attention有效位置，包含prompt/视觉位置，**不是已知的目标预测token数**。不能据此直接宣称有19237个独立损失/竞争观测。补做一次只读配置核验，实际配置vocab_size=32000、max_position_embeddings=32768、hidden=4096/intermediate=14336/32层；配置dtype标签为bfloat16，但历史实际运行已核FP16，不能用配置标签覆盖实际精度。完整展开训练序列最大长度和目标token计数仍UNKNOWN，不把配置位置上限当实际长度。生成max_new_tokens1024或每请求128模型forward也不是训练序列长度/显存界。

若统计仅用参考答案teacher-forcing前缀，测到的是这些前缀上的模型条件分布，不能称W0实际greedy轨迹分布。后者需要独立冻结的新离线完整生成及成本，仍不能将生成文本/前缀带进在线优化。

## 2. 要估计的量与容易出现的错误

对固定合法前缀t，令p_t为W0完整softmax，J_t为logits对选定矩阵参数的Jacobian。局部条件分布KL的二次项为

    F = sum_t w_t J_t^T [diag(p_t)-p_t p_t^T] J_t,
    KL(p_0 || p_(W0+Delta)) = 1/2 Delta^T F Delta + 高阶项。

这里w_t、前缀来源和缩减必须在运行前固定。目标位置平均与整记录平均不同；二次损失按mean缩减与“先平均score梯度再外积”也不同。对完整模型分布，平均score梯度为零；在W0处直接对固定p_0的KL反传一次，梯度同样为零，不能用零梯度外积估曲率。需要正确的Jacobian/HVP构造、模型标签抽样score外积，或显式说明的其它近似。

独立模型标签抽样可以产生无偏的条件模型Fisher估计，但有限样本的低秩估计不保证覆盖未采方向；跨token score相加后取外积还要处理抽样独立性、权重及交叉项。不能不加说明地把A32参考loss梯度、旧F0或一个平均梯度重命名为完整Fisher。

理论导数针对平滑实值计算。现有路径的native激活/输出有FP16 cast，反传使用的代理导数不能视为部署离散舍入映射的精确有限响应。即便新模型Fisher估计正确，有限native位移仍需独立检验，不能用局部残差替代完整生成行为。

## 3. 参数维度、内存和复杂度

所选矩阵为4096×14336，D=58,720,256。以下均是额外表示的字节数，不含模型、反传图、Adam状态、求解/特征分解缓冲与源约束空间。

|表示|存储量|判定|
|---|---:|---|
|完整D×D，FP32|13,792,273,858,822,144，约13.79 PB|显式存储超出每服务器<50GB及可用显存/主存|
|完整D×D，FP64|27,584,547,717,644,288，约27.58 PB|同上|
|只存对称上三角，FP32|6,896,137,046,851,584，约6.90 PB|不能靠对称打包解决|
|参数对角，FP32|234,881,024，约224 MiB|可算规模，不保留参数交叉项；单份已接近旧240MiB根预算，统计仍应仅内存|
|32个完整参数方向，FP32|7,516,192,768，约7.52 GB|A32量级可容纳不等于新分布信息有足够覆盖；秩最多32|
|完整输入/输出Kronecker因子，FP32|889,192,448，约0.889 GB|仅因子静态量可容纳，通常不等于真实Fisher；丢失条件依赖和跨位置耦合|
|同一对因子，FP64|1,778,384,896，约1.778 GB|不含构造与分解工作区，不能由这一个数承诺峰值或运行时|

完整logits额外FP32内存按4×S×V计算；显式每位置Jacobian按4×D×V计算，多位置再乘位置数。V=32000已从实际配置核实，S的实际最大值未核，不能报精确峰值。单位置显式完整Jacobian的FP32存储已为7,516,192,768,000字节（约7.52TB）；若按配置位置上限32768作尺寸场景，单份FP32 logits为4,194,304,000字节，但这不是实测序列或峰值。保留秩r的参数方向需至少相应D×r数组；真实所需秩未知，不能预设32足够，更不能因为D大就称剩余方向安全。

矩阵free的Fv可避免D²存储，但每次需要对相应旧前缀的模型执行导数计算；在线使用这种oracle会保留/重读旧batch或其图，违反边界。离线算后仅传数值参数统计可符合边界，但压缩误差/结构假设必须另证，不存在现成“任意v精确、任意便宜”的接口。

完整特征分解、方向/label枚举与反复VJP/HVP的成本不能从已有单次NLL backward秒数直接推出。14336维因子分解有三次方规模工作及多个平方工作区；新二阶算子和mixed-dtype/hook兼容性也未实测。当前只能给复杂度与尺寸，不能宣称已证明30分钟或24小时内运行完成。

## 4. 严格数据边界

允许的路径：原32隔离训练记录与绑定，在独立离线阶段使用；输出只含参数空间数值统计/匿名元信息；释放记录、图像、标签、嵌入、KV/激活、模型计算图后，在线仅统计+当前源+既有允许因素。

不允许的捷径：把旧batch、logits/缓存回答、token前缀、梯度计算图或闭包oracle改名为统计；在线回放以测KL、重线性化或校验近似；用六题开发面板构造/选择统计。参数统计仍可能编码训练信息，不是隐私保证。

训练参考teacher-forcing与Base实际生成轨迹是两个统计分布。当前32参考未被证明Base全答对；即便离线模型分布可采，也不能冒称保住32条正确知识。独立确认、近边界与连续编辑证据均未补齐。

低维参数更新基可以降低曲率矩阵维度，但固定离线基是否包含有效源写入方向未知；不能从单矩阵存在成功教师推导任意小基也能成功。若先用当前源生成基、再为该基重读旧训练数据做请求专用曲率，这是一条新的数据访问时序，不自动等同原来一次离线校准后在线只读统计；本轮不以阶段改名绕过边界，也不把它算作已兼容方案。

## 5. 准入结果与明确缺口

|路径|接口|source-only|资源/信息判断|本轮决定|
|---|---|---|---|---|
|显式完整参数曲率|需新增实现|仅离线数值矩阵可兼容|直接表示超资源|不冻结|
|在线旧数据Fv/HVP oracle|一阶已有，所需高阶路径未核|不兼容|省存储不能修复数据越界|不冻结|
|对角/低秩/因子/随机估计|理论上可实现，尚未实现验证|严格离线并仅传参数统计可兼容|近似形式、覆盖/误差及有限位移有效性未定；因果对照未成立|不直接启动编辑候选|
|更多参考mean-NLL锚/旧控制器换度量|已有相近代码|部分可兼容|重复已结束代理机制，不回答新问题|拒绝派生|

缺口不是“需要用户再批准一次”，而是尚无符合全部要求的新机制准入方案。不能把“存在可编程近似”视为已经有了机制，也不能要求先证明泛化收益才允许实验；这里未通过的是具体估计对象、可审计的近似/失效诊断、有限资源实现和能区分归因的对照尚未同时固定。

如果未来能提出不同于A32代理精修的具体近似，首先需要独立的统计保真诊断（预先固定、与开发评价隔离的方向/尺度/缩减/误差判据、原生精度与失败保留），而不是直接推出新编辑器。它仍需新协议与硬预算；当前没有默认选定随机方向数、采样数、因子截断或阈值，也没有开始数值或模型调用。没有新机制证据时保持唯一pure-w ACTIVE并静默，不重复本审查、不复活旧实验、不为填时间调用。
