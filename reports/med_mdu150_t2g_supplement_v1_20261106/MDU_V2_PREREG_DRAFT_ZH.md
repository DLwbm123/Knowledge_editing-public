# MDU-v2 分阶段实验预登记底稿

日期 2026-11-27。状态为方案底稿，待阶段 0 准入。已核验的起点是 MDU150 冻结前向及离线诊断。1,276 个同图候选配对尚无完整语义复核，扩充视图、留出参照和新训练均待执行。[冻结项目总结][summary] · [既有数据执行规格][spec]

主线检验小型 TT 专家能否提升**留出问法的读入选择性**，并守住同图独立问题的输出分布。若学习率、视图库、稳健聚合与 KL 有可重复的独立贡献，分别用匹配对照确认。已有回归描述读入与答对、回避和 KL 的关联。旧 MED–C 方向比较和对数斜率用于解释现象，固定强度或保护初始化的因果作用由干预验证。

## 阶段 0 数据、参照及执行冻结

### 0.1 情态间接问法与四组训练视图

| 组别 | 训练构造 | 评价角色 |
|---|---|---|
| 普通改写 | 同义替换或等价语序，保留原问范围与答案形式 | 训练与独立的训练侧验证 |
| 陈述间接 | 以 Please report whether 或 I'd like to know which 为例，保留内嵌的极性或 WH 问题 | 训练与独立的训练侧验证 |
| 情态间接 | 批准如 Would it be possible to say 一类由情态问句引出内嵌问题的构造。模板和源题槽位通过复核才进池 | 至少一个不同情态句式谱系整体留出；Are you able to tell 一类也要先比对官方句框再决定是否准入 |
| 语境 | 增加中性语境或表述形式，保持图像和内嵌问题 | 训练与独立的训练侧验证 |

此外预留一支情境提问语法，与情态留出支系分别报告。官方 Can you determine 等已出现的外层模板及近邻全部单独评测。选学习率、温度和 KL 系数只用单独登记的开发验证数据。首轮以间接问法为主要目标，新增数量提示留到第二轮。原冻结数值扰动组继续照常报告。

情态构造的准入判据是正常语境下要求回答内嵌问题，且原参考仍能完整作答。会改变任务为判断能力、只问能否推断，或需要采用新参考的候选退回。对原问使用受控语义槽，核对病征、属性、部位与侧别、极性、范围、数值和单位。生成前冻结模板谱系、语义槽版本、生成种子和角色。模板槽位不注入答案内容或条目数。

自动初筛后做分层盲审，每个训练族至少 30 条，总量至少 150 条，同时抽检两个留出支系。复核者可见原问、变体和参考，隐藏方法输出。任一族抽检错误率超过 5% 时整族退回重生成，用新抽样复核并保留拒收记录。精确去重、模板谱系去重和跨角色近似句框复核全部完成后才冻结。近似筛查先把原问槽替换成类型标记，比较外层句框，避免把同一原问的必要词汇当成模板泄漏。临床材料仅在项目批准的私有环境中处理。

### 0.2 同图关系审核与负例分配

逐对复核 1,276 个候选，保留独立、相关且一致、相关且冲突、证据不足及理由。先判断正确答案是否依赖编辑事实，再核对同契约 Base 输出和参考。相关且冲突只进入一致性评价。相关且一致独立报告，首轮 KL 训练只用独立题。难负例也从训练侧的独立题抽取。

每条编辑预标整图疾病清单、具体发现或范围未决。独立题按图像与规范化问句共同锁定角色。同一问句在该图所有编辑配对中共用训练或留出角色，重复近义问句同组。保存每条编辑的独立训练和留出负例数，分别报告单边缺失和两边缺失。Base 输出及参考绑定可核验时复用；缺失时按已锁定的贪心解码协议补齐。训练用 Base 贪心前缀，留出负例评估同时测 Base 前缀和参考前缀。Base 答案正误单列。

### 0.3 冻结参照、补充分析及确认队列

- 在相同新面板上先跑冻结 MED 和 MDU150。采集留出间接组投影和 CORE，以及留出独立负例的两种前缀 KL、目标文本精确一致率和投影。保存 MDU150 每位专家四个 FIT 的投影中位数，固定为后续各臂的分母。旧面板间隔 0.174 只作历史参照。
- 在核验独立的留出负例上，用正的 MED→MDU KL 增量拟合对数斜率。增补 Base 原始答案与编辑目标的规范化内容词 Jaccard，保留否定词和数字。以图像分组 bootstrap 比较加入协变量前后的斜率，汇报两套答案前缀、非正增量计数，并在原尺度复核全事件方向。该分析检验关联能否在独立题内复现，归因仍由干预检验。
- 预留未暴露且与开发图像不重叠的 SLAKE 图像组。锁定纳入规则、排序、镜像／衍生图检查、封存清单和替补规则。阶段 5 之前只核验元数据与角色，不运行模型。患者标识可核验时按患者封存，否则论文只主张图像分组独立。
- 阶段 0 出口必须有私有数据标签与分组、正式基线回执、支持量、代码与模型版本、种子和抽样顺序、阈值、参数标定规则、评分合同及实测吞吐。评分优先锁定可追溯快照、提示词和判定协议。供应方只提供模型别名时记录该限制，冻结同一批评分流程并保留盲审核对。未完成资格或预算核对时，具体面板标为待准入。

## 阶段 1 小面板验证视图和输入侧学习率

目标约 30 位专家。按图像分组、编辑范围分层，以 20261127 为抽样种子，选择时只看支持量和角色。要求至少 10 位有冻结 T2L 支持，每位至少有 1 个独立训练负例和 1 个留出负例。全组使用同一 MED 初态、源编辑种子、层位、160 步 Adam、输出侧学习率 $10^{-3}$、等权聚合和独立同图 KL。采样计划在组间对齐，原视图组按相同视图槽位确定性轮换原 FIT，同时报告重复视图数和实际 token 数。

| 组 | 视图 | 输入侧学习率 |
|---|---|---:|
| P1 | 原始 | 0.0001 |
| P2 | 原始 | 0.001 |
| P3 | 扩充 | 0.0001 |
| P4 | 扩充 | 0.001 |

用训练侧验证在同一计算预算下标定一个全组共用的 $\beta$。在开发校准题与共有 MED 初态上，分别计算正例损失和独立 KL 对可训练 TT 因子的梯度范数。以两项范数的样本中位数之比设 $\beta_0$，并落盘两项量级。分母为零时检查前缀、教师分布与梯度绑定。比较 $0.3\beta_0,\beta_0,3\beta_0$，选择让各臂验证负例 KL 不高于冻结 MDU150 的最小公共值。开发校准失败则报告该配方未通过准入。

**对比及判据**

- P4 对 P2 检验相同高学习率下的视图扩充，P4 对 P3 检验相同扩充视图下的学习率。P2 对 P1 及交互项 $(P4-P3)-(P2-P1)$ 为预设辅助对比。主张更高学习率改善读入选择性，需要 P4 对 P3 的间隔增量区间下界大于 0，同时守住 G2 和 G3。
- G1 选择性机制。固定分母的选择性间隔 $\Delta=\operatorname{median}r(\text{留出间接正例})-\operatorname{median}r(\text{留出独立负例})$，P4 对 P2 的图像配对区间下界大于 0，且情态留出中位读入比达到 0.60。逐类报告投影、残差、NLL、回避和 CORE。学习率选择由训练侧验证冻结，留出结果用于检验。
- G2 局部性。留出独立负例的两种前缀 KL 中位数和自由生成目标精确一致率均不高于相同面板上的冻结 MDU150，原冻结 T2L CORE 不降。训练负例与留出负例的绝对投影分别报告，留出负例中位数不升。
- G3 来源保持。T0 与 FIT CORE 保持 100%，原问与 FIT 的绝对投影中位数不降。连续指标为小面板机制读数，CORE 的区间和事件计数同时公开。
- 间隔与增损以图像分组配对 bootstrap 2,000 次，报告区间、图像及编辑支持、类别支撑和缺失。G1 未过时在独立的开发回合尝试 $Q_A$ 的投影对比项。G1 通过但 G2 未过，优先在训练侧调整 KL 或独立难例采样。门控属于单独的机制变更，启用时需要新的等预算对照。修订后的确认使用预留新句型，已曝光的留出结果保留为开发证据。

## 阶段 2 全库方法对照

锁定阶段 1 选定的输入侧学习率和共同 $\beta$。F1–F4 共用扩充视图、答案单元、采样和优化预算。主方法沿用 7,168 个 TT 参数。每步原问加四组各一条，KL 臂另加最多两个独立负例。F0 用与阶段 1 一致的原视图轮换。稳健臂与等权臂共享原问 CE、$\lambda=1$ 和 EOS 规则。

$$
L=\mathrm{CE}_{\mathrm{native}}+\lambda\,\mathcal A(\{\bar\ell_{g,k}\})
    +\beta\,\overline{\mathrm{KL}}_{\mathcal N_{\mathrm{train}}},\qquad
\mathcal A_{\mathrm{robust}}=\tau\log\sum_{g,k}\pi_{g,k}\exp(\bar\ell_{g,k}/\tau),
\quad
\mathcal A_{\mathrm{equal}}=\sum_{g,k}\pi_{g,k}\bar\ell_{g,k}.
$$

$\bar\ell_{g,k}$ 为第 $g$ 组第 $k$ 个答案单元的平均 token NLL。$\pi_{g,k}$ 先按组等权，再在组内对可用答案单元等权。以开发校准题初态的组间损失标准差中位数设 $\tau_0$，候选为 $0.5\tau_0,\tau_0,2\tau_0$，用训练侧验证冻结温度并保存实际组权重。若初态校准损失在所有组退化为同值，先检查视图难度与答案片段绑定。无 KL 的臂固定 $\beta=0$。

| 组 | 视图 | 聚合 | 独立同图 KL |
|---|---|---|---|
| F0 | 原始 | 等权 | 有 |
| F1 | 扩充 | 等权 | 有 |
| F2 | 扩充 | 稳健 | 有 |
| F3 | 扩充 | 等权 | 无 |
| F4 | 扩充 | 稳健 | 无 |

主比较为 F2 对 F1 的留出间接 CORE，图像分组配对 95% 区间下界大于 0，且通过 G2 局部性界限。选择性间隔与各作用范围的配对变化是首要机制读数。次比较为 F1 对 F0、F2 对 F4、F2 对冻结 MDU150。保留官方 T2G 分型、两个留出族、T2L、T0、FIT、T1G、相关题一致性、回避率及目标精确一致率。

前 40 步按问法族累计权重，报告最大权重、情态组权重与 $N_{\rm eff}=1/\sum_g w_g^2$。事先将 $N_{\rm eff}$ 中位数低于 3.5 定为稳健项确实偏权的证据。若未达门槛，结果仍予报告，并将稳健机制列为未被验证。若 F2 无可测独立收益，论文主线保留有证据的视图覆盖、输入侧学习和同图 KL。

150 位进入全库仍取决于独立负例及算力准入。若只有部分专家满足条件，在训练前冻结支持子集，其余位在各臂原样复用同一 MDU150，称为混合库，并单列训练专家支持。完整 150 位方法实验如资源不足保留待执行状态。

## 阶段 3 方法归因与匹配对照

| 实验 | 设置与解释边界 |
|---|---|
| 三起点 | C、M13P、MED 各用阶段 2 同一配方续训。只在三方权重和身份均可核验的原 146 交集上比较；MED 轨迹只在起点、样本、种子与预算逐项相同才复用。实际支持决定分母。 |
| 同层 LoRA | 固定路由、层 21 的 down_proj、监督、步数和预算。秩 4 共 73,728 参数。与 TT 同时报告参数与存储。 |
| 外部方法 | 复用冻结协议一致的 BalancEdit、GRACE 旧结果。MEMIT 和 AlphaEdit 先判断适配缺陷，能按标准修复再比，否则单列局限或移出主比较。WISE 仅在有同契约适配和足够预算时纳入。 |
| 强度校准 | 可选，仅在开发集固定专家与路由、预登记缩放点和必要的 CORE 工作点。目标文本一致率分正例与独立负例报告。 |

## 阶段 4 第二骨干机制复现

首选候选为 Qwen2.5-VL-7B-Instruct。冻结实际模型提交、预处理、模块名、尺寸、相对层深及 TT 参数量，先通过等效重构、零残差与 teacher mask 检查。用该骨干自己 Base 答错的来源题和普通 CE 训练 TT 专家，复现读入投影、首 token 与整答 NLL、间隔、同图 KL 和条件回归。FIT 分母由该骨干单独确定，统计使用图像分组。区分模型间方向复现、具体数值和可训练性。完整定版配方的迁移另行安排。[Qwen2.5-VL-7B-Instruct 官方模型卡][qwen]

## 阶段 5 独立确认

解封阶段 0 已登记图像。按锁定构造器形成编辑、官方式 T2G、两类留出句型、T2L 和独立负例。固定最终方法、输入侧学习率、$\beta$ 与温度规则、残差强度 1、R0、评分和人工复核协议。MDU150 配方、定版方法、BalancEdit 和匹配 LoRA 各按冻结条件跑一次。T2G CORE 按编辑等权，间接组 CORE、独立负例的两个前缀 KL 与目标一致率、T2L CORE 和选择性间隔分开报告。约 200 个事件按方法、类别与当前冻结输出分层盲审。披露 UNKNOWN、缺失和评审一致性，按图像成组报配对区间。

## 算力与阶段退出

历史 MDU49 的 7,840 次更新由两张 GPU 完成，慢分片用时 **3.48 小时**。旧运行每步两次无梯度和两次有梯度前向，扩充组的训练与教师计算量依具体实现而变化。用新配方的小量真实运行测每更新墙钟、训练峰值和新增存储，再锁定本轮规模。下表为同两卡吞吐的训练时间敏感性估算，另留生成、评分和恢复时间。

| 阶段 | 更新量上限 | 与旧单步同速 | 2 倍单步耗时 | 3 倍单步耗时 |
|---|---:|---:|---:|---:|
| 1，4×30×160 | 19,200 | 8.52 小时 | 17.0 小时 | 25.6 小时 |
| 2，5×150×160 | 120,000 | 53.3 小时 | 106.5 小时 | 159.8 小时 |
| 3 三起点新增两臂，146 位上界 | 46,720 | 20.7 小时 | 41.5 小时 | 62.2 小时 |
| 3 同层 LoRA，150 位上界 | 24,000 | 10.7 小时 | 21.3 小时 | 31.9 小时 |

每个实验须满足单次墙钟不超过 24 小时、每台新增实际存储严格小于 50 GB。小面板超预算时，在训练启动前按冻结抽样次序与支持量确定更小面板。阶段 2 按旧吞吐无法在两卡的单次时限内完成，须先验证更高吞吐及可用资源，或预注册规模明确的子集对照。不得用拆段续时回避硬预算。随后按各阶段依赖核验终态、输出、评分、统计与匿名发布。
