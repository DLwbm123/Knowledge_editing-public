# 固定层位权衡的事后诊断

按16个编辑等权，深层相对浅层的 T2G CORE 净变化：4个编辑为正、12个为零；T2L CORE 净变化：4个为负、10个为零、2个为正。仅1个编辑同时出现T2G净增和T2L净降；另外3个T2G净增编辑的T2L净变化为零。净值会掩盖同编辑内部同时发生的修复和损伤，不能解释为这些编辑逐题零损伤。

训练source上的深层/浅层注入响应范数对数比与编辑级T2G净变化的Spearman为−0.438、与T2L净变化为0.522，各n=16。方向并不支持用“深层响应更强导致全部损伤”作简单解释；这只是小样本事后相关，未控制数据和编辑差异，source响应不代表T2L响应，不证明机制或因果。

这两臂均无MED原保护曲率，T2G和T2L变动也可能涉及层位置、优化、数据作用及生成差异；相对于原MED不能将变化全部归因于层位。先有结果后登记本分析，数据已曝光、患者独立及临床真值未知。

只读取获准面板的既有评分及训练回执，无模型调用、训练、生成或新评分。首次CPU执行因环境缺少scipy在读取输入前退出；随后以平均秩的标准公式实现同一固定Spearman统计，成功执行；记录此工程失败。代码和聚合结果不含私有问答或权重。
