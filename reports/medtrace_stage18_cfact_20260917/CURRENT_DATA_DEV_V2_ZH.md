## checkpoint 生命周期

有限 DEV16 的三 C 分支共用每编辑初始化，生成按 C_NO_H → C_EXTRA → C_FACT → BalancEdit 衔接 single 与所有前缀；不等待评分才进行 sequential。写盘预计小于 10 GiB，保留至少 8 GiB 余量。每条 C 的初始化、W0、分支状态最后消费者为本次全前缀生成和机械验收；BE 最后消费者同为 single、全前缀及恢复检查。当前保存以支持在途恢复；生成后核对所有消费者和可独立评分材料完整，再按具体文件清单清理本次已无依赖权重，不删历史数据、不无限归档。没有登记额外权重消费者。
