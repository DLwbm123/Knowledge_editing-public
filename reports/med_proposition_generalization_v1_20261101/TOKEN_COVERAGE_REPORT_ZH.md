# 医学词面词元匹配覆盖

按用户明确的修复后继续指令，在固定16编辑、80条已获准source/FIT训练记录中完成词元级检查。第一次完整检查9个双类别候选全部回退；后经合成提示模板定位到程序错误：真实首答案token可包含答案前空格，旧代码将其排除。修正边界后另行执行，得到9/16编辑可形成两组匹配，7/16缺预设类别；共18组成对跨度，两侧各45个token，3组有交叠、0组完全相同。所有编辑原顺序保留，不按评价结果挑选。

两个统计的时间顺序和错误原因均披露；不能将修正后的结果称为盲态独立确认。规则依然只使用有限词表与来源答案，9个是弱词面匹配，不代表医学命题、实体关系或已验证事实。一般对照允许含医学词，三组交叠也须在解释对照效力时保留。

使用固定记录的官方模型版本与tokenizer文件身份，原对话模板源码提交一致；只读准入训练数据，不读评测QA、图像像素或评分，0模型/训练/生成/Judge；两个完整覆盖检查各在独立父守卫、120秒和单文件10MB限制内结束并退出0，独立私有锁保留。实际训练仍须在真实多模态扩展后逐视图核验目标token和mask，不能将文本层匹配当作训练准入或方法有效结果。
