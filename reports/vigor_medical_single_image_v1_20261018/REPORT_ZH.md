# VIGOR 医学单图编辑器实现交付

按论文独立新增编辑器，复用现有 `EditorRecord`、`PreparedBatch`、图像预处理、多模态展开和原生模型生成接口。没有启动真实模型或实验，没有修改旧方法的损失、优化器或冻结结果。

实现与逐项论文差异见 [README](../../experiments/vigor_medical_single_image_v1/README.md)。主要差异是视频转单图、训练 E profile 选择医学模型固定层、显式固定 Fisher 归一化/阻尼和预算截断解释，以及每次编辑结束后的原生精度写回。作者代码未取得，属于论文重建。

CPU 检查使用 PyTorch 2.6.0、seed42 的微型合成模型，复用了仓库中的真实 `PreparedBatch` 类型。独立 dense KKT 对照、结构保留的零像素对照、训练隔离、五步梯度重算、无更新分支、原生生成和保存重载、更新后失败回滚通过。FP32/FP16/BF16 均通过；原生量化 L2 分别为 0、0.003642254、0.005338210。详见 [CPU_CHECK.json](CPU_CHECK.json)。三个合成样例五步后均未达到 0.01 NLL，不把工程检查当作方法成功。

当前已提供校准、编辑、原生 W 导出/恢复接口及调用示例。没有为未授权实验创建后台执行器或真实运行协议；后续若授权运行，需要先核实训练/评估病例隔离、基础模型与预处理绑定，确定候选层并执行真实校准，再验证实际模型算子和现有生成评估链。不能从本报告推出医学编辑效果、旧知识保持或临床安全结论。

公开交付只包含源码、差异说明、合成检查结果和准备状态；不含模型权重、真实校准 ID、病例数据或论文 PDF。
