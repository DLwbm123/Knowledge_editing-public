# 最近实验结果与机制问题：供 GPT Pro 审阅

整理日期：2026-10-13。范围：近期 TT 三模块固定比较、M13 补充和 M1-GUARD 阶段 A。本文汇总已完成记录，不启动新实验。此前 online fine 2×2 在 N/T/NT 训练前被用户停止，不能将其计划矩阵当作已完成结果。

## 1. 当前结论

**尚未找到同时保住源编辑、跨图泛化和旧知识保护的方案。** M1 的开发集泛化计数较好，但新增损伤更多；M3 大幅减少新增损伤，但泛化下降；M13 组合没有保住 M1 的泛化优势。最新 GUARD 降低了 BASIS 保护代理，却跳过了近一半写入，源进展和实际步幅均未达到冻结门槛，已按协议终止。

这些是原八个 owner、既定种子、已开发暴露数据上的结果，不是独立确认。小分母上的正确数差不能直接解释成可推广优势；减少 Base 原正确题变错，也不等于总准确率上升或医学安全性成立。

## 2. 共同设置与方法含义

- 冻结 Base，TT88 四核共 7168 个可训练参数；原八 owner，其中一例沿用已批准修订版本。
- 每 owner 七条源监督：native、4 FIT、2 GFIT；每步损失权重为 `.25 native + .25 cyclic FIT + .5 cyclic GFIT`。
- 完整比较每臂 160 步，固定种子、数据次序和自然 R0 路由。GUARD 仅做 80 步机制验证。
- C：原 RAW 更新方向和 Adam 组步长参考。D：历史双组源约束保护参考。E：已冻结的历史完整方法参考；E 不等于本轮 M13/M123，详细历史定义沿用原报告。
- M1：确定性 TT canonical 坐标，以两组标量二阶矩替代逐坐标 Adam 历史，无一阶动量；不宣称完整 TT 商流形优化器。
- M2：对七条源题各自的下降半空间投影，再做逐题有限步检查；固定尝试 1、1/2、1/4、1/8，失败则跳步并消耗时钟。
- M3：对实际组合算子 `W = B A` 使用 Base full-vocabulary Fisher sketch 惩罚。61 个 BASIS 问题、1514 个预测位置、每题 32 个 probe，共 1952 个方向；系数由冻结 C 的源改善与算子惩罚定标，没有 heldout 调参。
- M12/M123/M13：对应模块组合。M13 是观察前轮结果后新增的固定补充，不是预先完整 factorial 设计。

M1/M3/M13 的实际算子更新范数匹配 C；M2 的有限检查可进一步缩步或跳步。M13 全轨迹每 owner 平均范数比为 0.999805–1.000117，因此其保护收益不能简单归为整体步长缩小。

## 4. 最新 GUARD：为何终止

设计意图：将 M1 源优化状态与保护纠偏分离，保护梯度不进入两组源 RMS 历史。先形成与 C 步幅匹配的纯 M1 提案，超出固定 `0.1 × C FINAL Fisher penalty` 预算时，固定提案的右规范尾核心，在 512 维根核心空间做最近椭球投影。源提案仍更新全部 7168 参数；这个纠偏是固定尾空间内最小距离解，不是全 7168 维全局投影。

四个固定提案比例各自投影后，检查真实有限源进展与步幅；均失败则跳过。它不强制每条源题逐步下降。八个 owner 各完成 M1REF/GUARD 80 步，在 20/80 节点形成 16 个配对 cell。M1 前缀源曲线一致性、八份 C Fisher 惩罚校验均通过。

| 指标或冻结门槛 | 结果 |
|---|---|
| M1 源进展为正 | 16/16 PASS |
| GUARD 源进展至少保留 M1 的90% | 8/16 PASS，整体门槛 FAIL |
| cell 源进展比率均值 / 最低值 | 78.436% / 40.199% |
| BASIS KL / 原正确 token 丢失不更差 | 各16/16 PASS |
| 平均 BASIS KL | M1 0.00890905 → GUARD 0.00112623 |
| GUARD−M1 KL expert 聚类区间 | [-0.0110193, -0.00466944] |
| GUARD−M1 KL source 聚类区间 | [-0.00889128, -0.00644433] |
| GUARD 接受 / 跳过 | 336 / 304，共640次，跳过47.5% |
| 接受步平均实际算子步幅保留 | 99.765% |
| 包含跳步的总体步幅保留 | 52.376%，低于90%门槛 |
| 每 owner 平均步幅达到90% | 0/8，FAIL |

平均源加权 NLL 改善为 M1 1.60931、GUARD 1.01657。“平均 cell 比率”与“两个均值之比”不是同一统计量。16 个 cell 的原正确 token 丢失累计 407→165，含重复 token 测量，不能解释为独立题目正确率。

因此 GUARD 在这个固定设置下未实现“保留写入强度和源收益的保护纠偏”。接受步接近完整步幅，失败主要表现为大量拒绝写入；这仍不能证明真实全空间不存在可行方向，也不能排除预算、根空间限制或代理误差等因素。

**阶段 A 没有 T1G/T2G/HELDOUT 模型测量，没有生成/Judge。** 不能把 GUARD 的 KL 与上面的语义正确数横向当作同一个指标。协议结论为 `STOP_MECHANISM_GATE_NOT_MET`，未进入条件 81–160 或完整评估。
