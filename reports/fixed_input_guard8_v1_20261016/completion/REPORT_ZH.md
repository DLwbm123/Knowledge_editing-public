# 前8条固定输入保护对照：最终结果

结论：保护臂P改善了旧编辑的T2G泛化保留，但没有改善T0原问题保留；基础保护集仍发生严重损伤，因此不能认定固定输入保护器解决了持续编辑遗忘。此次是8条、单一既定顺序的探索性对照，不是146条验证，也无统计显著性结论。

## 已完成范围

U（无保护）和P（固定16 MiB输入保护、原生FP16修复）各完成160正式槽，全部插入及prefix0/4/8评估和最终原生重载检查通过。保留此前输出、失败、资源消耗和原manifest；按用户2026-10-17授权取消时间与显存准入门，仅补做P尚未执行的两条重载生成，没有重训或重复生成既有评估输出。科学协议和次数上限未变。

独立gpt-6-astra、medium、原有评分提示及隔离边界，764消费者对应526独立输入：127历史有效评分严格全绑定复用、3历史永久缺分保留、396新输入均一次评分且格式有效。最终758/764消费者有效，6缺分仅来自两组Base T2G各3条；所有插入及prefix4/8指标均无缺分。没有重试缺分或另行挑选成功样本。
