# MedTRACE：PR31 后续实验执行任务

## 任务与证据基线

审阅并固定 Knowledge_editing-public 的 PR #31，基线提交为 `0e3abaa9ddae83c431088bae62aaa284b1925670`。同时保留 PR #30 的负结果，不复跑已失败的 H/容量矩阵。

本任务是下一轮实验协议，不是已执行结果。先核对当前仓库、资产和资源授权；不得把此文件中的目标规模当作已存在的数据或自动增加资源授权。主线全程 TT；不使用 FREE、稠密补丁、训练后压缩或扩大 TT rank。原 PR31 TT88 每专家为 7,168 个可训练参数；Base 冻结。

要回答三个问题：

1. 固定专家库的正常路由损失，是否主要来自选错专家而不是专家不会回答？
2. U 的价值能否表现为：不降低冻结 W0 的编辑/泛化能力，同时改善真实的作用域外答案保持？
3. 停止继续压低已经合格的编辑 CE，是否比固定 CE+U 续训更有效？

当前证据不是 U 稳定优于 W0：P2 SINGLE 相对 W0 的 T2G 增量为 +1.74 pp，配对区间跨零。正常 24 专家库 CHECK 的 0/4 是完整 token 序列不一致，不是医学准确率 0%。旧 CHECK 已经被分析，后续参与设计时只能作为 DEV。

## 资源与停止规则

仅使用已经获得授权且经检查空闲的 GPU，至多两个训练进程。新任务累计 GPU 预算硬上限 24 GPU 小时，包括实际 GPU 推理和 Judge 驻留；这是上限，不是必须用满的运行时长。每阶段先按实际吞吐估算是否能在剩余预算内完成，再准入。不得擅自扩展到全部 GPU，不杀死无关任务。

新增 Judge 调用上限 6,000，失败重试也计数；沿用已授权 Judge、固定版本及评分规范，不未经授权把医学数据发送给新服务。现有合格评分按完整身份绑定复用，不将复用算成新调用。

新增 checkpoint 与教师缓存合计不超过 2 GiB，磁盘预留至少 8 GiB；教师全词表 logits 采用有界缓存或重算。保留基线资产只读引用、每个候选的最终 TT 状态、当前一个恢复状态、必要随机状态、冻结路由、配置及审计哈希。不得无限保留中间 checkpoint、优化器副本或全部轨迹 logits。清理仅针对本轮拥有且消费者已结束的临时文件。

## 阶段 A：无需 TT 训练的机制审计

### A1. 评分和生成保持拆分

复用 PR31 的 W0、CE_ONLY、SINGLE160、MULTI160 以及正常/forced 输出。报告 T0/T1G/T2G 编辑宏平均、原始正确观测数和来源组数。seed、专家数、重复 CHECK 观测均不能充当独立来源。

对四个旧 CHECK 来源，盲评全部条件相对 Base 的语义变化，区分：仅措辞不同、语义相同、Base 正确后变错、Base 错误后变正确、共同错误、无法判定。事实判定使用可靠参考和图像证据，不只比较两段文本；存在歧义则保留 NA。完整 token 相等、语义一致、医学正确率、Base-correct 保持率分别报告，不互相替代。

复核所有 OFF 输出是否确实等于同配置 Base，核对 EOS、停止规则、tokenizer、logits processor、图像展开及数值精度。KL 是沿 Base 生成前缀计算的全词表 token 平均；增加首个分歧位置、共同前缀长度、EOS 分歧及相关位置概率/排序诊断。不得因为均值 KL 下降直接宣称生成保护成功。

### A2. 六条 T1G 损失归因

24 专家库正常 T1G 是 87/93，宏平均 93.75%；forced 为 93/93；正常激活为 93/93。逐题记录正常所选专家、所属专家、距离、半径、候选排序、权重哈希、输出与评分。区分错选、作用域重叠、权重装载错误、状态残留、评价绑定错误。另一个专家若也合法覆盖此查询，不强行认定唯一 owner。

对同一查询、同一专家、同一权重，验证 single 与 bank 的 logits/生成一致。当前程序每次选择一个专家，不能把结果解释为多个 TT 残差相加导致的污染。所有 forced/oracle 对照只用于诊断，不能作为方法成绩。

### A3. 库大小与停止点

对相同的最早 8 个编辑和相同 U 面板，评估 8/16/24 专家前缀；另行报告新增编辑，避免评价人群变化混淆规模效应。预先固定原顺序及两个置换顺序，复用同一批专家；不要重训。最终同一专家集合的顺序不变性也应检查。

核对是否保留 P2 native、A2、W0 暖启动节点。W0 的配方为 140+80+320 步；若 A2 状态仍可复用，以 A2 作为额外早停诊断基线。缺失则如实记录，不为此重跑整个暖启动队列，也不把 W0 当成未经编辑的 Base。

输出：`MECHANISM_AUDIT_ZH.md`、匿名逐类归因汇总、路由/加载机械检查及所有缺失记录。

## 阶段 B：冻结 TT 的路由小实验，优先执行

保持 W0、SINGLE160、MULTI160 三套 TT 权重分别完全冻结。比较三个路由条件：

- R0：原冻结路由。
- R_RADIUS：仅在 CAL 上校准全局拒绝强度/半径缩放，不改变候选间排序，作为“少调用即可改善”的必要对照。
- R_SCOPE：使用已有冻结表征和已有 keys，学习少量全局非负分组距离权重，使候选排序可以改变，再校准拒绝阈值；最多 64 个新增共享可训练标量，不增加每专家稠密矩阵或原型向量。具体分组和特征处理在读取评估结果前冻结。若已有表征根本无法区分作用域，报告表示局限，不暗中添加大型路由模型。

路由训练只使用允许的 native/fit 适用域信息及经核实的保护训练样本。仅“不是同一个编辑 ID”不构成负例：多个编辑可能具有相同或兼容知识。不能用正式 T1G/T2G 查询或 CHECK 标签训练路由。若近边界样本按旧定义属于 H，保持 H 标签，披露其仅用于适用域监督，不更名为 U 掩盖新增监督。

CAL 同时评价正例召回、正确专家选择、作用域外误触发和拒绝率；不能只优化 U 的 OFF 比例。T1G/T2G 原资格面板中 Base 错误，拒绝并不等于恢复编辑能力。

最多 3 个预注册 CAL 配置，不追加阈值搜索。9 个“权重×路由”组合只需真实组装专家库并推理，不训练 TT。报告正常路由主结果，forced 为独立诊断，所有训练参数、路由 keys、阈值、持久存储和推理时延分别记账。

若路由调整已经消除真实语义保持损失且不降低编辑泛化，不启动生成轨迹损失分支；优先确认冻结 W0 + 新路由。

## 阶段 C：TT 内部更新消融，最多两条新增主训练分支

固定 R0，以隔离 TT 学习效果。固定 PR31 的 U_FIT 来源、Base 教师、native/fit、数据顺序、优化器、学习率、梯度裁剪、TT rank 和目标层。从同一 W0 出发，预先选择原 P2 前 8 个编辑、两种续训随机种子；不得挑选本轮已经看到的失败案例作为代表性队列。此处两种续训 seed 是优化重复，不是独立 W0 暖启动或独立病例。

四个比较条件：

1. FROZEN_W0：0 个续训步骤，复用。
2. CE_U_MULTI160：PR31 配方，身份完全匹配时复用。
3. U_ONLY160：仅 U 的 Base||student 全词表 KL，不再优化编辑 CE。
4. HOLD_U160：U KL + 编辑保持铰链，不无条件继续压低正确样本 CE。

HOLD_U 每次仍使用 native 与一个按原顺序轮换的 fit 样本。对每个允许的训练样本 b，在 W0 预先缓存相同 token 平均方式的编辑损失 ell_b0，定义：

    L_hold(b, phi) = max(0, ell_b(phi) - ell_b0 - epsilon_b)
    L_total = 0.5 L_hold(native, phi)
              + 0.5 L_hold(fit, phi)
              + 0.01 KL_U(Base || student)

第一版 epsilon_b = 0；不以 T1G/T2G 或 CHECK 调 epsilon。若需要数值容忍，仅由机械重复误差在训练前冻结。这个保持约束不是泛化保证，仍需生成评估。

新增主训练仅 U_ONLY 和 HOLD_U：2 方法×8 编辑×2 续训 seed，共 32 条、每条最多 160 步。中间节点只用于预注册诊断和故障恢复，不在看过 CHECK 后挑最佳 checkpoint。三个 U 训练条件必须匹配来源轮换与 U 监督 token 计量；记录真实 forward/backward、训练 token、非零 U 梯度和函数变化，不复用 PR31 的近似 forward 总数充当精确计量。

每个训练条件至少报告 T0/T1G/T2G、U 的 ON 条件语义保持、Base-correct 保持、KL、完整 token 相等、参数及成本。若 U_ONLY 破坏编辑，作为有价值的负结果保留；若 HOLD_U 不比标准 CE+U 改善目标取舍，停止，不扫描 epsilon、rank、层和更多 loss 系数。

准入条件：已排除明显错选/装载问题，并在 forced 或稳定正常 ON 条件中确认教师前缀 KL 下降仍伴随参考支持的语义保持错误。只有文本措辞不同，不准入。

仅增加 HOLD_U_TRAJ 一条分支，最多 8 编辑×2 seed。U 来源与总训练监督 token 预算保持可比。将 U 前缀分布改为 50% Base 生成前缀、50% 当前 TT 学生生成前缀；每 20 步刷新学生前缀，停止梯度经过生成过程。Base 在同一个学生前缀上提供全词表目标，教师所有编辑 OFF。CAL/CHECK 均不得用于轨迹生成训练。

额外的生成和教师计算独立记账，不把“相同 160 步”称为相同计算量。保留原全 Base 前缀 HOLD_U 对照；不要同时新增 top-k KL、反向 KL、解码技巧和 margin loss。若到预算边界仍无法完成，则跳过此分支并说明，不挤掉核心审计与正式评估。

## 判定与统计

主要目标可以是“相对 W0 保持编辑/泛化，同时提高局部性”，不强求 U 必须提高 T2G。

开发筛选门槛预设为：没有新增 T0 失败，T1G/T2G 编辑宏平均下降均不超过 2 pp；在来源数合格的保护面板上，Base-correct 保持率相对 W0/R0 点估计提升至少 10 pp；改善不是完全由正例拒绝增加导致。门槛只是开发筛选，不是显著性结论；小于要求的来源面板只能作诊断。

正式报告同时给出相对 W0/R0 的保护收益及泛化配对差值、区间和原始分子分母。希望支持非劣效时，需预注册 -2 pp 界限并使用合适的配对分析；样本不足或区间跨界只能 NOT_CONFIRMED。不要把不显著当作相等，也不要把 0 次观察失败直接当作风险为零。

以编辑为主要单位、seed 先在编辑内平均；来源组聚类敏感性分析并列。U 以独立来源为单位，不把 24×4 当成 96 个来源。缺失评分保留缺失界，不能删除分母。KL/完整 token 相等均不能替代医学准确率、作用域正确性或独立 T1L/T2L。
