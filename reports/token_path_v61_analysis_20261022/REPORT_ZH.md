## 1. 完整范围与主要结论

读取全部219个消费者的A/B/C回答、原判理由及生成终止记录。72个消费者至少一个臂的回答文本不同，其中63个至少一个臂的四类标签不同；纯措辞变化不自动算性能变化。完整219题及标签来源在私有ALL_PAIRED_OUTPUTS.json，所有标签变化和A七题的原文见私有CASEBOOK.md。跨角色/重复消费者不是独立病例。

A的正式同图异问7个非正确题分布在5个编辑：E003一题、E005一题、E007两题、E008两题、E010一题。2错误、4不确定、1弃答。观察支持“问题表述变化下的回答完整性、事实选择与生成稳定性有差异”，不足以诊断为统一的医学推理缺陷。

重要更正：正式同图异问40/40参考答案与各自源编辑完全相同；已查题面仍询问同一目标事实。额外40道措辞诊断只是对原题加“Please answer…”等前后缀。两组难度差异可以来自实质改写、否定、问句形式和要求范围；不能据分数差推断正式同图异问要求新事实或新医学关系。两组都属于已曝光开发评价，不因本次分析变成新确认集。

## 4. 评分敏感性：保留标签，但必须披露

1. 同图locality的Base原正确3题全部来自E009。A损失1题、C损失2题均为正确→不确定；没有正确→明确错误。B的表面收益只对应其中一道额外断言减少，不能当稳定保护优势。
2. 有具体校准不一致：一条历史复用CORRECT回答包含参考未给出的“术前”状态，而相近新回答因“术后”额外断言被标UNCERTAIN。二者不是同文本，语义标签复用规则本身未违规，但新旧评分尺度并非完全同质。C另有CORRECT回答附加神经病灶定位，和其他因额外定位降为UNCERTAIN的回答也存在尺度张力。因此保护差异尤其应谨慎，不能强作机制解释。
3. 空回答在E010正式同图异问中复用历史UNCERTAIN，在额外措辞诊断的新盲评中为ABSTAIN。二者都不算正确，不改变正确数，但影响I/U/A构成解释。
4. E008“main cause”问句与三项参考的完整性要求有张力。A的一个UNCERTAIN和C损失的一个UNCERTAIN属于这个范围敏感点；不自动判为知识缺失。

本次没有重新评分、修正旧标签或计算择优“宽松分数”。以上是当前结果的测量限制，不能据此把失败改为通过。

## 6. 当前决策

保留A作为当前写入参照，位置掩码分支仍关闭。现在有证据的研究问题是：同一事实在改写问题下，何时出现拒答、要素缺失、极性替换和答案后失控续写；现有输出无法单独定位训练路径、解码路径或图像利用的因果作用。

历史结构优势可以作为旧多支持设置的开发证据保留，但当前严格native-only结构贡献仍未建立。未来若另获实验授权，最小缺口是固定同一原始编辑信息和完整消费者、显式记录参数和优化预算的一个合法低参数结构对照；这只是缺口说明，本次不登记、不启动、不恢复任何新实验。也不把七题或配对差异转换为训练样本。
