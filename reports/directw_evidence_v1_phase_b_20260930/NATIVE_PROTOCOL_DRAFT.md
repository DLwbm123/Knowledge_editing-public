## Ordered native checks

1. Load the audited native LLaVA-Med class from clean checkpoint and local CLIP. Record all parameter/state keys, actual parameter count, storage identity, bias, hooks and backend. Stop on exact-path/shape/BF16/alias mismatch. Freeze nonselected parameters and disable cache/dropout. Record model and vision full-content bindings, tokenizer/config/processor/native template source digests and dependency versions.
2. Build one original training question/image with native template/tokenizer. Use native `prepare_inputs_labels_for_multimodal` to obtain expanded embeddings, labels and padding. Record raw/expanded lengths, image positions, answer labels, predictor positions `t-1`, full vocabulary, EOS policy (excluded from content score) and physical key dtype. Verify a direct gather/log-softmax calculation against `mean_answer_logprob` over actual expanded labels.
3. Normal Base forward, repeat forward and functional-call parity precede derivatives. Freeze tolerance before results: identical argmax; float-logit max difference <= 1e-3; identical repeat outputs for the stationary-CG implementation. A backend compatibility check is permitted once, independently recorded; no scientific backend use if Base parity exceeds tolerance.
4. Measure ordinary answer-score gradient, anchor KL gradient at Base and one represented small perturbation. All outputs finite, only selected original W participates in parameter gradients; no unauthorized state update. Protection uses fixed, detached full-vocabulary probabilities and cloned prefix/mask. At Base require KL-gradient norm <= 1e-5 times `max(1, answer-gradient norm)`; perturbed gradient must be finite/nonzero. No medical correctness is inferred.
5. Start with deployed BF16 variable and record gradient/tangent/VJP/GGN/dot/norm dtypes. If BF16 numerical qualification fails, a predeclared FP32 editor-coordinate patch may cast the coordinate into original BF16 for every native functional forward, promote logits/probability arithmetic to FP32, and keep solver/dual algebra FP32. This is temporary editor state. Final W is original BF16, and all acceptance uses actual normal-forward deployed W. Finite differences must record epsilon, BF16 represented displacement and quantization floor; a quantization-dominated difference cannot PASS derivative qualification. CG rtol stays `1e-4`, without relaxed convergence. CPU mixed-precision regression is preparatory evidence only.
6. Exact JVP + VJP categorical GGN, repeated operator, two-vector symmetry and PSD probes. Record raw scalar differences, norms, tolerances and failure exceptions. No diagonal/K-FAC/low-rank/LoRA substitution. No PSD/symmetry PASS without actual measurements. GPU/host peaks and times measured separately for forward, backward, JVP, VJP and full GGN.
7. Solve one Q inverse and one-/two-constraint explicit-slack QPs using the existing `cg` and `solve_step`; retain protection's first-order gradient. Stop the mechanical solve if frozen tolerance is not met in the fixed call/iteration budget. Such a capped failure does not establish that a larger run could converge, and cannot authorize one. Log actual GGN calls, KKT, residual and status, never substitute CPU solver evidence.
8. Capture the selected module's actual down-projection input. Require exactly one expected call, final dimension 14336, expanded predictor-mask alignment and hook count restored. Geometry only for W_KEY; no evidence edit without independently qualified pair.
9. Snapshot W, bounded direction, BF16 cast/write, census only-selected change, normal-forward scoring, actual fixed-anchor protection, requested/actual delta and zeroed fraction, then rollback. Verify exact restoration or explicitly reviewed frozen tolerance. One tiny retained mechanical candidate may be exported only under predeclared finite/protection/state conditions, independently of medical score.
10. Reload in a separate editor-free process from clean checkpoint plus original matrix replacement. No editor import, hook, router, adapter or CP/Tucker. Ordinary deterministic free generation <=8 tokens must match edited in-memory output. Restore Base at end and audit. Measure clean reload memory/time and private snapshot bytes.

Pilot projections require a measured exact-GGN runtime: report `948 * seconds_per_GGN` per worst-case QP step, plus measured other costs, one-/20-step edit and eight-/12-edit totals. With no native measurement, costs remain `NOT_MEASURED`; static extrapolation is not substituted. The 948-call estimate is projected only; it does not grant 948 calls in this smoke.
