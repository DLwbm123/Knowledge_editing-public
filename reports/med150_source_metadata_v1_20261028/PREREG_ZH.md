# MED 主线新来源组：元数据可行性预登记

前两次MED150路由开发实验未通过既定保护门槛。下一步需要能同时支持目标编辑和不同谓词保护评测的数据，而不是在已曝光146条或新增4条上继续搜索阈值。本轮只考察已有SLAKE中是否存在未命中已登记来源/保留角色、且可能有至少两个英文OPEN问题的训练图像组；为后续主线机制的目标/保护同图诊断提供可行性依据。**不读取问题、答案、像素、封存内容或任何模型输出，不做模型调用或方法比较。**

冻结以下元数据规则后才枚举：仅取已有SLAKE train，英文OPEN且qid有效的行，按图像组聚合并要求至少2个不同qid。用已有validation和test仅作图像组元数据交叉检查，跨原划分出现的组全部剔除；不使用其问题/答案。保守排除已登记历史来源组、V95全部24保留组、V106已审8组、原回放64组、V111全部15个剩余保留组、原146与新增4来源组的可比身份。每一排除集单独记录数量、联合去重，不把id不匹配等同患者独立或绝对未曝光。

对其余组按来源组数字序固定取前8组，角色标为`TRAIN_DEV_METADATA_CANDIDATE`，仅存组标识、qid池和图像路径元数据于私有目录。少于8如实报告、不从其他来源或其他划分补足；这些候选不属于V95固定8组，也不替换其先前临床片段加权失败样本。该阶段不打开任何候选QA或图像，不能推断问题是否不同谓词、有图像证据、原Base正确或临床有效。候选不进入训练或确认，后续若要读取必须先单独冻结来源审查和角色/模型协议。

使用本项目已存在的角色/曝光元数据快照和原146/4来源元数据；快照不能代表所有历史或模型预训练，别名、跨项目和患者来源未知。若任一必要排除文件缺失或身份格式不明则失败，不降低排除规则。仅一次本机小脚本和远端只读元数据抽取；输出小于20 MB，硬截止30分钟，0模型/0GPU/0图像/0答案/0下载。保护V111全部15个来源组及其原协议，不激活或改变其门槛。T5/PadChest扩展在现存授权中为false，本轮不读取或使用其内容。仅匿名统计和代码公开，逐组身份与文件路径私有。
