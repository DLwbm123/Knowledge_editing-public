# 给Pro的实验交接报告：教师失败诊断、前8编辑四臂结果与下一步判断

更新日期：2026-10-23。V81–V84已完成。V84新增结果为40条实际源轨迹全部正确，错误信号资格门槛未通过；不能据此启动纠错训练。全文只公开实现、脱敏聚合和研究判断，不包含原始医疗图像、逐样本问答、患者身份或服务器私有路径。

## 1. 先给结论，以及这个结论不能外推到哪里

1. **最初的自由生成教师目标确实不可靠。** V81的120条候选只有1条单独满足严格源内审核；40个输入没有任何一组同时满足三个新臂的共同准入，因此依冻结规则在训练前终止。
2. **失败包含可定位的构造问题，不能归咎于医学关系本身。** V82确认事实实际进入提示，没有截断；无条件Base回答不可靠，原自然语言提示还具有很强的提前EOS倾向。旧实现的温度1采样也偏离MixSD官方代码默认的分支内温度0解码。
3. **后来的V83修复了训练目标的事实资格，但没有带来效果提升。** S3医学字段、S2通用编号、S1扁平字段文本三臂完全同分；三个混合臂的T2G都低于原M13P：16/32对23/32。
4. **保护成功无法判断。** 全部51个原保护消费者保留，但原Base正确支持为0；用同一严格标准复核Base后仍为0。因此正确旧事实的保护损伤为NA，而不是“零损伤”。
5. **V83不是原生全词表OPD，也不是原Pro建议或MedKgSD/MixSD的忠实复现。** 它是为避免不合格自由目标而设计的“完整、等价答案支持集上的受限分布监督”。这个替代设计本身有明显识别能力限制，需要Pro优先审查。
6. **V84没有产生可用的训练侧错误轨迹。** 固定温度.7的一次性40源轨迹全部与参考一致，教师对错误的优势为不可检验，不可用“没有错误”冒充教师纠错资格通过。

当前最稳妥结论是：**不推广V83这套固定混合配方；本轮没有医学字段增量证据。不能据此说所有医学关系条件化都没有价值。**

## 2. 原研究问题和Pro建议

目标是提升已有医学知识编辑主线：既让指定源事实被编辑，也让编辑后的模型在原合同泛化问题上正确回答，并检验未编辑事实的保护。

用户转述的Pro建议有两个层级：

- 优先借鉴MixSD的原生分布监督、MedKgSD的医学关系条件化，但只使用已有来源内事实；普通混合监督必须作为对照，验证医学结构是否额外有效。TRSD先作为教师可靠性/校准原则，不一开始全部叠加。
- CW-OPD/CF-OPD证据变化监督必须先有合格真实配对，不使用代理负例代替。

用户授权前8编辑四臂、冻结协议和预算；随后授权自主诊断、设计后继、持续实验，每30分钟统一监测，不逐轮要求审核。科学门槛、隐私、原数据角色和历史停止要求保持。

另一个Pro讨论中的RhoEdit、TT-DPC/BQ-LoRA、Rank-OPD/JB-OPD等已放入条件性后续计划，但本轮并没有把这些机制加进四臂。它们仍需按实际瓶颈准入、核验正文和实现。

## 4. V81：最初的自由混合教师目标为什么没进入训练

### 4.1 当时实际实现

S0原参考CE；S1同事实自然语言条件；S2同事实通用编号；S3同事实医学字段条件。

对同一图像、原问题和同一已生成响应前缀，计算冻结Base的无条件分布p0与条件分布pc，逐token从以下分布抽样：

`p_mix = 0.5*p0 + 0.5*pc`

temperature=1、top-p1，最多256新token到EOS。8×5×3=120条，每条只抽一次，不搜索或失败重采。目标产生后离线NLL训练，因此这一步本身也不是训练时全词表KL或当前学生on-policy蒸馏。

全部条件信息来自原source问题和参考，没有外部KG。原V81的S3还带额外的字段使用指令，提示长度也不同，因此它不是严格的等词等长度格式消融；V81最终没有训练，不能把它当成四臂疗效比较。

### 4.2 固定审核门槛与结果

候选必须完整覆盖源事实，保留关系、侧别、可能性、范围，无额外源外断言，EOS且未触顶。任一新臂在某输入失败，三个新臂在该输入共同回退原参考；不删题、不挑seed、不补抽。

|臂|候选|单独严格合格|完整事实覆盖，含有额外断言者|
|---|---:|---:|---:|
|S1|40|0|5|
|S2|40|0|11|
|S3|40|1|10|

全部120条中18条为空。40输入全部共同回退，非等价可用目标为0，所以训练前科学终止。训练更新、backward与性能评价均为0；不能说“四臂性能持平”。

主要失败：漏掉多项参考事实；错误病种/病因/神经；未经提供的部位、序列、患者史、治疗；把平列病因改成新的因果边；空回答。

这些审核是source-reference一致性检查，不代表已验证临床真值。源外常识即使可能正确，也不能自动当成这条源事实所支持的病例断言。

## 6. V83：为保持事实门槛，监督构造实际改成了什么

### 6.1 完整答案支持集与固定分布

每编辑在任何V83似然或性能结果前，由原训练问答冻结3个完整答案：原参考+2个事实等价表述。24条全部逐条审核；三新臂共享同一支持集，不按分数换句，也不再自由抽取目标。

记候选完整答案为y_j，包含EOS；同一固定Base的平均token log probability为ell_c(y_j)：

`p0(j) = softmax_j(ell_0(y_j))`

`pc(j) = softmax_j(ell_c(y_j))`

`q_c(j) = 0.5*p0(j) + 0.5*pc(j)`

S1/S2/S3的损失为：

`L_c = 0.5*CE(原参考) + 0.5*Σ_j q_c(j)*CE(y_j)`

即候选0权重`.5+.5q0`，另外两个候选各`.5qj`。每条CE是完整答案平均token NLL；native/FIT外层仍`.5/.5`。全部480项序列评分在训练前冻结，160步中不更新教师或q。

### 6.2 必须正视的设计偏离

- 这是长度归一化似然构造的受限能量分布，不是完整词表分布，也不是原生序列概率直接条件化。
- 两个新增答案是source-only等价表述，不是模型自由生成的完整原生轨迹。
- 教师在预先规定的答案前缀上评分，没有当前学生自生成前缀上的动态监督。
- 本轮不含MedKgSD的任务KG、原论文TSE、prior-policy replay，也不含TRSD的动态教师校准。
- short_S1实际是包含entity/relation/values等的**扁平字段文本串**，不是纯自然语言；S2外层为通用编号，S3为医学键字段。S1已经包含医学关系语义，只是组织不同。

**所以，V83更接近“相同正确事实、不同格式教师对三个同义完整答案的风格权重偏好”实验。它可能过度压缩了原本想检验的医学语义监督信号。这个问题是设计限制，不能用最终负结果掩盖。**

更明确地说，若把答案映射为其事实集合g(y)，本轮每个支持集中的3个答案都有相同g(y)。因此任一条件的受限分布在这一事实集合映射下都集中于同一个值；条件之间没有直接的医学决策标签分布差异。它仍可能通过措辞与优化路径影响泛化，但不能据此把格式消融等同于充分验证医学决策监督。

另一个衰减来自损失公式：

`L_c = .5 CE(ref) + .25 E_p0 CE + .25 E_pc CE`

条件教师实际只占总目标的四分之一。已冻结q的S3−S1平均TV=.005238、S3−S2=.006478；最终候选损失权重向量的对应TV再减半，约.002619和.003239。这里不是准确率百分点，而是目标概率质量差异。不能看见这个结果后在本轮内临时增权。

### 6.3 资源公平口径

四臂更新次数、原算子步长和保护规则相同；S1/S2/S3相互使用相同计算口径。但对每个输入准确求3候选期望，使新臂每个更新需要更多NN backward：S0共2560次，S1/S2/S3各7680次。新臂约3倍此项计算量，不应宣传相对S0的同计算预算优势。

## 7. 评价工程故障，如何恢复，为什么保留此次结果

32份训练全部完成后，初次评价在一个S0样本上触发历史tokens不一致。CPU审计发现：原155个single输入中154个路由激活、1个关闭；新入口遗漏原路由，始终挂TT。失败恰发生在唯一关闭输入。

采取的修复仅恢复原输入路由语义：四臂共享已有、只读的原路由绑定；关闭则不挂hook，激活则挂本臂既有冻结专家。不根据答案好坏决定开关，不重设计gate，不改训练或解码。

保留了43份经绑定核验的有效输出，不重复生成；1次不一致和另1次被STOP中断均记账。继续剩余577消费者。原失败输入修复后精确复现；最终全部155个S0 tokens精确匹配历史。8个S0的全部160步源NLL/算子范数也已精确匹配。

原起点、12h墙钟、43,200 GPU秒和640生成上限未重置；最终622次生成尝试对应620成功消费者+2失败。此修复不能包装成“初次运行无故障”。

## 9. 保护证据为什么仍不成立

T1L/T2L共51消费者全部保留。**原冻结Base-correct mask下，51个中支持为0。** 另外对112个唯一Base回答按本轮相同严格标准复核，保护组中正确支持仍为0。

所以：

- 正确旧事实损伤率/保留率为NA，不能写零损伤或保护成功。
- 24/49与0/2只是这些问题上的全部参考准确率，不是条件保护指标。
- T1L/T2L无支持的编辑不能当成成功，也不为得到正结果临时筛别的编辑或把错误Base样本算成保护支持。

该前8编辑四臂可以提供开发性编辑/泛化对比，但无法完成“医学收益且保护保持”的完整论证。

## 11. V84：实际学生轨迹资格诊断及其结果

不是继续调V83权重，也不是已经实现Rank-OPD。它是一个有限的资格诊断：

- 仅原40个训练输入，使用已精确重现M13P的S0。
- 每输入一次实际学生采样，固定temperature=.7、原seed+1009×view、128上限/EOS；40条全部保留，不抽到错误为止。
