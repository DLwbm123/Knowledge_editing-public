# 固定双算子桥接：MED / D-U 同支持机制诊断

用户要求继续研究 T2G 约89%、T2L约90%的目标。前一因子中点诊断在实际运行前发现原 MED 与 D-U 初始 TT 因子坐标不同，按其预登记停止，不再运行。这里另立机制消融：把同一个中间输入上原 MED 和 D-U 两个已有专家的实际残差各乘0.5后相加；保留主干原输出和原 R0/半径。不平均 TT 因子，不训练或读取保护曲率，不修改原专家。原 MED 状态本身受历史保护训练影响，不应称双算子不含该影响。该固定比例是无门控、无参数搜索的工程对照，计算成本约两个TT专家，不作为最终投稿方法，不宣称结构创新。ScopeEdit等已有多分支方法与现有相关工作必须比较；本诊断只回答双算子响应混合是否存在可用的泛化/局部性折中信号。

固定此前已获准的101个编辑使用各自原 MED150 与 D-U 状态；其余49个回退原MED。两端点保持原真实权重、同一输入/模块/精度/生成合同及原路由，状态/编辑/种子逐项绑定原回执；不读取49个未准入训练问答及V95/V106封存原始问答，不读取或重建受保护曲率。已结束的D-U/原D、原MED和BE为历史同支持对照；不利用评测表现挑选编辑、输入或比例，不扫描0.5附近参数，不因为单例效果中断或改变算法。端点作用域、状态及输出复用必须证明一致，否则停止。

原R0 2148个事件中实际路由到101专家的1513个候选查询进行真实生成，其余635在完整输入/路由/状态一致时复用原MED；正式预测前冻结清单，所有预测先冻结再读获准参考并计算评分。训练0次；报告两分支的实际算力与运行差异。新增评分默认0：同合同有效历史判定复用，已知失败不重试，历史尝试不可核实保留UNKNOWN；此前只对D-U补评的授权不转移。分别展示准确的CORE/FULL角色支持、未知边界、已知配对修复损伤、原146/新增4和101/49来源owner分层；T1L 2事件、T2L 31编辑54事件、OFF0均需披露，所有结果为已曝光DEV。

主要科学假设：固定双算子可在原MED和D-U之间找到非退化、同支持的泛化/局部性折中；运行前必须实际核验双算子混合数值，以及0/1端点与各原独立专家的真实层输出一致和同RNG输入契约，失败立即停止，不能因为端点检查成功声称预测效果。严格门槛依旧为T2G比原MED提高、T2L相对原MED最多下降5个百分点，T0/FIT/T1G/T1L不下降；不确定的门槛不视通过。另将用户提出的约89/90作为描述性目标，不以此追改历史门槛。只要双算子有泛化或保护失效、未知过大或无信号如实保留；不能在本DEV继续按结果挑模型、编辑或比例。

首次实际计算开始设置不超过23小时硬截止，所有阶段共享原钟。每台新增存储严格低于50GB，独立守卫/预停/预留余量、不改原状态；因子、路由和评分依赖及真实同支持绑定未齐不能运行。全部预测/评分须有可核验回执，不重试已尝试载荷；结果和失败公开脱敏汇总、代理push、远端和匿名验证。唯一现有心跳持续跟踪，不恢复已停止路线。
