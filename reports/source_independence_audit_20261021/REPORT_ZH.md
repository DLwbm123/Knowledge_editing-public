## 实际核查范围

核对既有来源绑定、图注审查、准入、训练支持和评价清单。既有47条保留项对应47个文章编号，25条训练候选、22条评价候选；其中8条曾入选训练支持。47篇与原六例的文章编号交集为零。这只证明文章级去重，不证明患者独立，也不证明此前未用于模型开发。旧准入明确没有患者身份硬门槛，不能继承为本次病例独立性 PASS。

对7个仅按来源内容发现的候选核查原文/原始图注，并读取其中4张既有裁图；未根据新 Base、训练输出或正确率筛选。其余40条未完成逐篇患者审计，不能声称整个来源池均不可用。部分网页遇到访问验证，随后通过 Europe PMC 官方全文 XML 接口取得5份原文，未将网页访问失败当作证据缺失。另2篇通过 PMC 原文或其全文搜索结果读取。

## 已确认问题与缺口

| 类别 | 已核实事实 | 准入前需要补足 |
|---|---|---|
| 病例单位 | 一个来源实际包含三病例，目标图归属于其中第三例；另一来源是32人队列、图注只指向其中一人 | 固定文章—病例—图—子图映射，不能按文章或图数计患者 |
| 历史暴露 | 一项候选已进入旧训练支持，另有旧评价候选 | 建立历史训练/评价使用表；已暴露条目只作开发或回归，不能包装成全新确认 |
| 参考冲突 | 一项肺部病例的病理图注与正文存在上下叶不一致；CT图注提供较窄的形态证据 | 不使用冲突的病理标签；仅在独立核清后保留范围明确的关系 |
| 子图绑定 | 一张现有骶骨矢状面裁图标为b，而原文图注将该描述归于a、b描述轴位 | 找到原始组合图确认实际裁图来源；未解决前排除 |
| 第二关系 | 多份原文确有位置之外的形态、大小或伴随异常证据 | 必须确认该关系适用于现有具体裁图；全文提及、图注包含、箭头指示三者不能互相替代 |
| 测量与可见性 | 一张肺部裁图仅192×144；另一腹部图的箭头指向腹壁 | 不能从低分辨率裁图独立声称测量正确，或把腹壁箭头当作肝内病灶证据 |
| 跨病例独立性 | 已获得部分单病例叙述及队列图中病例描述 | 与旧六例及历史训练支持核对重复报道、机构/时间/病例特征；公开文献证据的分辨能力应明确保留 |

文字级第二关系支持已经找到，但还没有完成上述联合准入。并非所有候选都被判错，也不要求获取直接个人身份；应以可获得的病例谱系和重复报道证据，给出独立性判断及其边界。无证据时不把文章编号当患者编号。

## 后续准入与对照约束

沿用唯一30分钟监测入口。先补病例/子图/历史暴露证据，再冻结全部来源、两条关系、训练问句和不同表达家族的评价问句；在冻结前不运行 Base。按来源证据选择，不按旧错误筛选，也不把旧评价答案移入训练。病例单位分组，已暴露来源单列为开发/回归，缺失项保留在筛选清单。证据够用后另立有限实验和明确预算，比较匹配的 JOINT 与表达覆盖方案，保持参数量、训练步数、种子、调用和损伤规则一致；机械准入通过后直接运行。此处只是准入约束，尚不是已冻结实验协议，也没有释放 GPU 作业。

公开仅聚合审计和限制；医学裁图、病例标识映射、QA、原始全文副本和逐条证据均留在私有目录。没有改动历史模型、输出或权重。
