# 固定答案选择上限与边界支持审计

本轮完成了用户要求的零模型决策审计。对齐 B（V24）、C160/C_STOP（V25）和 OFF 的全部 216 个编辑×查询消费者、180 个唯一输入，直接沿用冻结四分类；0训练、0生成、0新评分。逐消费者清单私有保存，未恢复任何权重、旧进程、V23 或其余136个编辑。

核心判断：当前问题不只在“何时打开 writer”。固定答案二选一在 T1L 没有新增正确空间；T2G 的 B/C_STOP 互补也仅1题。下一项条件化实验必须验证能否产生更正确的新答案，并且需要先建立合法、独立的边界支持。当前材料尚不满足这一数据准入，不能直接用现有评测答案训练 gate 后声称泛化。

## 3. T1L：同一批错误传播持续存在

|状态|正确 / 明确错误 / 不确定 / 弃答|精确复述源目标|其中明确错误复述|
|---|---|---:|---:|
|B|33 / 26 / 25 / 0|82/84|24|
|C160|32 / 42 / 9 / 1|65/84|24|
|C_STOP|33 / 33 / 18 / 0|75/84|24|

三个状态的24个错误复述消费者是完全相同的一批。B与C_STOP正确集合也逐项相同，均为33个；把三 writer 与 OFF 全部放入候选，正确并集仍只有33/84，余51个消费者没有现成正确答案。84个消费者只有50个唯一输入，重复消费者不能当独立样本。

因此，给这批题选择 OFF 可以减少“源答案复述”这一行为，却不能据此增加正确答案：OFF为72明确错误、12弃答、0正确。需要同时报告 CORRECT、明确错误、U/A转移；只统计复述减少会奖励退回错误或弃答。连续门控或重新训练可以生成候选集合外的答案，未被本次离散选择上限排除，但必须实际评价。

21/84消费者的固定参考与源目标在机械归一后相同，说明 T1L 角色不能直接变成“源答案绝不适用”标签。字符串一致也不能替代完整医学适用性审定。复合答案后续需要明确支持、部分支持、不支持、未知的定义；本轮没有新增任何此类医学标签。

## 4. 边界支持：已有材料不足以直接训练并确认新 gate

已检查原 SUPPORT_FROZEN 和 ROUTE_PLAN_FROZEN：

- 旧支持8条，8条负表达均为 `This is not ` 加原参考的合成否定，不是临床审定的图文边界负例。
- 支持查询 ID 与180评测输入无交集；旧保存的组字符串也无交集。按原路由的统一归组规则（SLAKE原图/派生图归同一 xmlab，VQA-RAD归同一 synpic）复查，8条支持实际为5个来源组，其中1组与10个留出开发输入同组，包含T0一题、T1G一题、T2G四题、额外措辞四题；其中包含1个已知源锚点。6条支持的旧组字符串与该统一规则不同。
- 这暴露的是来源组粒度差异：不能把“删除支持查询/旧组”升级表述为“所有派生图来源组独立”。本次不改写旧冻结结果；V22路由本来是已曝光开发集且源锚点共同已知，V24/V25又是source-only，不能把上述重叠误报为两轮新增训练泄漏。
- 原1800专家×输入关系有127 YES、89 NO、1584 UNKNOWN；这些是benchmark名义角色关系，不是临床唯一合法owner。UNKNOWN不能当负例，NO也不能直接当医学不适用。
- 所检查的支持记录没有临床适用性审定字段，原计划明确 `independent_confirmation=false`。这仅说明这些冻结材料未建立所需证据，不宣称仓库或外部不存在任何可用数据。图像来源组不是患者身份，患者独立性仍未知。

新四臂方案的数据准入结论：**尚未建立**。不从已曝光评测清单反向抽取监督，不打开其余136个编辑补池，不默认20/40划分或2个百分点指标已经冻结。

## 5. 与既有 SOURCE 能力矩阵合看，下一步怎样收紧

旧 SOURCE 完整矩阵中，R0留出开发97/129正确；32个失败中16个有现成正确专家/Base，16个没有。指定 SOURCE 的6个T2G失败，其他专家均不能救回。SIMPLE/CONDITIONAL未取得合格DEV工作点，结果是NA；DEV中Base正确为0，不能声称建立了损伤检测器。这些结论仅适用于旧 SOURCE 库，不能移植为 B/C_STOP 或 BalancEdit 的完整库能力。

下一步的最小科学问题应是：**在相同合法支持与同一稳定 B writer 下，图像条件相对文本条件，能否产生更准确的异问答案，同时减少明确错误的源答案传播？**

先补齐支持来源/曝光历史/派生图归组与适用性标签的准入记录，再锁定 matched-support 的源训练、支持训练、文本条件、图文条件四臂。主要比较图文条件相对文本条件、相对同支持无条件 writer；源训练臂用于分离新增监督的收益。文本条件不得经融合表示间接读取图像；图像置换只改变 gate 的图像证据，保持当前问题和回答用图不变。连续 gate 的幅度需有训练侧预定的常数幅度参照，不能用测试结果选幅度或拿强制g=1单独证明视觉范围。

以上是数据准入后的候选设计约束，**本轮未实现、未准入、未启动四臂或求解器**。当前已完成授权的审计和报告；不以增加rank、继续拉长C、放宽阈值、追加路由扫描替代边界证据。
