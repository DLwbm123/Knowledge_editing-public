# V101：原始显示映射与既有首 token 方向的有限核验

2026-10-24，V100 已完成并关闭之后、读取本轮原始像素统计和方向性 logits 之前冻结。采纳用户给定 Pro 分析的两个具体证据缺口，目标是决定下一步方法主线能力建设的预算去向，不重复图像是否接入模型的 V99 检查。V100 的任务准入失败及全部旧结果不改。

## 范围

只使用 V99 已固定四类各一正一负、共 8 张图像及其 C/N/R 首 token logits、保存的 C 输入张量。C 是现用路径，N/R 为已有原生路径；它们不是新增独立患者。原档、来源记录与模型均只读，不读取任何新患者答案或封存评估集。0 新模型加载、0 forward、0 generation、0 backward、0 参数更新。

## A：原始 PNG 到 RGB

从已有分卷归档按冻结 ImageID 定位唯一成员，检查成员名、报告标识和准备图名的映射与尺寸；仅解码指定 8 个成员，不复制或拼接全量归档。记录模式、dtype、尺寸、最小最大值、0/1/5/50/95/99/100 分位数、有效灰阶数、零值与最大值比例；准备后 RGB 记录同样统计、通道一致性。将固定 `/257` 理论映射的统计与准备图对照，不做全量文件哈希或额外归档复测。

预先将原图已经是 8 位、实际动态范围被 `/257` 压至很少等级、明显反相/截断、维度或绑定不符列为需解释的异常。统计异常本身不授权按答案改善选择变换，修正须有源格式规范或直接工程证据支持。

对照原始图的固定全范围显示、既有 RGB 与反归一化的真实 336×336 模型输入。参考正例原定位框，记录其在输入中的尺寸并做非专家的技术可视检查；不能用肉眼判断升级为临床复核，也不声称缩小后的微小病变一定可辨认。不按模型输出选窗宽、裁剪、增强或逐图分位数。没有明确转换错误就关闭这个修复分支；即使发现错误，也只提出有证据的单一修正并另冻一次验证，不能重写旧数据或结果。

## B：既有首 token 的 Yes/No 方向

只加载旧 tokenizer 与保存的 logits 到 CPU。预先固定规范字符串 `Yes` / `No`，检查无 special token 编码确为各单 token，解码一致，实际回答首 token 对应相同位置；同时记录大小写/前导空格分词差异但不选择更有利变体。若检查失败，标记现有首 token 资料不足，不用任意 token 近似完整答案似然。

若成立，对每条 C/N/R 旧输出计算 `s = log P(Yes)-log P(No)`，即两个首 token logits 的差。每类固定正负图计算 `delta = s(positive)-s(negative)`，同时报告无图 s 与是否仍偏向 No。只报告四对完整方向、幅度与跨路径一致性，不拟合阈值、不增加新评分调用、不把 s 当校准疾病概率，也不把四对开发诊断当泛化结论。

## 预算与后继决定

首次 CPU 执行起至结束最多 1 小时，两侧使用内部硬超时；各主机新增占用硬限 256 MB，预计小于 20 MB，不下载模型、不过夜等待、不创建第二监测。保存最少图表、数字与私有映射；公开代码、技术汇总和决定，不公开原图、患者标识、原始问答或完整 logits。

明确强度/绑定错误：提出单一来源支持修复；无明确错误：关闭转换修复支线。若首 token 正向排序存在，最多支持另立受限读出假设；若方向混杂，则不给阈值调参投入。后继候选能力筛查、独立患者确认、编辑任务资格分开冻结，不能把本轮有限审核当能力通过或方法训练收益。
