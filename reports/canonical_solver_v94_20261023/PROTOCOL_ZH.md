# V94：固定 TT 端点的 canonical 求解器修正配对

在任何 V94 模型调用前冻结。目的为排除已确认的求解缺口，并判断修正是否带来有效非零来源写入及超过匹配 CE 的泛化。它服务于主线机制判断，不将数值修复本身称为医学创新。

## 依据与不变项

真实部署的旧 qp 已在纯 CPU 上复现两种缺口：目标已达标时只惩罚增量而不修复累计保护漂移；半空间最优解再过滤半径会漏掉半径内可行解。V93 来源轨迹四个编辑出现 margin 达标、保护超标、三次零修正后终止；另三个初始 None 的原因尚不能归为半径漏解，一个接受零写入。这些观察不是修复后必有可行解的证据。

V93 保持原代码、协议、时钟和输出。V94只读复用其全部八个 CE、BAL_CE、TT_MARGIN 终态及原冷初始化，不重训端点，不选择编辑或seed。数据仍原8编辑/native+4FIT/原155消费者、原路由。来源参考、旧Base回答和循环其他5来源保护输入不变；不用已曝光T2G训练或选参数。旧答案是模型行为参照，不是临床旧事实。

部署单7168四核TT，固定参数gauge的二维chart与V93相同；不是完整TT空间或原CanonEdit多层线性矩阵复现。固定160步CE/BAL训练的构造成本从V92/V93继承披露，不称修正方法没有端点成本。

## 数值修正

当前累计保护漂移 d=s(z)-s(0)。新局部目标为

`||d+Cδ||²/5 + .04 δᵀMδ`，即二次项 B=CᵀC/5+.04M+1e-10I 和线性项 2δᵀCᵀd/5。

以下约束一并进入CPU求解：

- Aδ≥γ−m(z)，native γ=.25、四FIT γ=.10；
- 修正半径 δᵀMδ≤36；总半径 (z+δ)ᵀM0(z+δ)≤36；
- 累计预测保护 MAE≤1.5、MSE≤2.25。

五维MAE以全部32个符号半空间精确表示。M仍为当前TT切线Frobenius Gram，经均对角归一并加1e-8I；M0为初始Gram。不变更rank、basis、半径、保护门、来源或优化端点。

使用已安装SciPy的CPU double SLSQP，固定零初值、ftol1e-10、最多300数值迭代，不做初值/参数搜索。返回点必须有限、所有线性/二次约束残差≥−1e-6，并用活跃约束非负乘子检查KKT：活跃阈值1e-5，stationarity与complementarity≤1e-5×(1+目标梯度范数)。不依赖单独success布尔值。不能认证则记NO_CERTIFIED_LOCAL_SOLUTION，不宣称数学不可行或全TT无解。CPU反例、合法零解、不可行半径和总半径检查已预先通过。

真实模型最多四次修正，每次均记录目标、累计保护、z、完整局部矩阵、求解证据及提案；保存每次提案TT小状态直到必要诊断闭合。最终仍按原真实非线性margin/MAE/MSE门验收，无合格则零写入。未增加线搜或额外训练。零写入即使概率达标也单独计数，不称有效来源写入。

## 配对、端点资格与输出

首先对CE/BAL两个固定端点逐编辑计算五个来源margin、保护变化、初始总半径，形成同标准资格表；其来源自由回答从V93本次完整冻结输出按准确输入绑定复用，不新增采样。若端点已满足全部资格而旧/新搜索仍失败，明确报告搜索遗漏；端点冲突也不能推断整个空间无解。

每个编辑重算原旧求解链并核对V93状态、坐标、曲线及终态；数值采用原rtol1e-5/atol5e-4，不放宽，失败即STOP。该复算不重新生成旧臂回答。另运行新求解器得到FIXED，之后每编辑native+4FIT各一次greedy，共40次来源资格。单研究助手来源可见全文审核后冻结标签，非独立盲审；五条全合格才在FIXED_SOURCE使用FIXED，否则回退固定CE。回退不保证通过canonical保护门，须分开报告。

最终六臂：Base、CE、BAL_CE、OLD（V93 TT_MARGIN）、FIXED、FIXED_SOURCE。前四臂620条回答从完整V93精确绑定复用，后两臂各155新生成，共930正式消费者。模型和方案在新正式评测前冻结，严格隐藏新臂全文评分后解映射。旧臂控制与当次Base角色不变，不声称继承回答是新增计算。

主要比较FIXED−OLD和FIXED−CE；策略比较FIXED_SOURCE−CE；分解FIXED_SOURCE−FIXED、BAL_CE−CE。报告来源资格通过率、非零候选、零写入、CE回退数、同编辑胜负、EOS/触顶和完整保护分母。Base正确支持0/51则损伤NA。
