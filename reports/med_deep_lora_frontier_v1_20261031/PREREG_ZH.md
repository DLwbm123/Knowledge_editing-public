# 深层 LoRA 泛化与局部性开发实验

状态：准备中，未启动训练。按照用户采用的 Pro 方案，以既有 16 编辑和 508 事件为固定面板，比较原 MED、C21、CDEEP 及同一个新专家终态的四个全局强度 0.25/0.50/0.75/1.00。先完成 16 编辑全部训练和预测冻结，再统一评分；仅当预定筛选通过时固定唯一强度，扩至 150 编辑和 2148 bank 事件。不得按编辑、角色或结果选择强度，不扫描其他配置。

新专家仅使用每个编辑已许可的 source 和四条 FIT；固定深层 down_proj、rank 4、alpha 4、A Kaiming uniform、B 为零、FP32 参数、Adam 1e-4、160 步、裁剪 1、无额外训练数据。每步 source 和轮换 FIT 各占一半。验证训练与生成位置、冻结 Base、状态回载、路由与输入绑定。单编辑先真实训练并检查生成，仅工程通过后继续。训练/生成/评分之前须完成全链依赖及独立时间、存储守卫；不得伪造准入。

阶段 A 的 T2G CORE 宏平均至少 90%，T2L CORE 相对同面板 MED 下降不超过 5 个百分点，T0/FIT/T1G 及有支持 T1L 不下降；T1L 无支持记 NA，FULL、损伤与修复、截断和不确定项完整报告。多个候选通过时依次按 T2G CORE、T2G FULL、T2L CORE 递减及强度递增选唯一候选。没有合格点则停止，不追加配置。阶段 A 2560 次更新、5120 反向及 2032 消费者为上限；阶段 B 仅经筛选通过后新增 21440 更新和 2148 消费者。单实验原始时钟不重置，总历时不超过 24 小时，每服务器新增实际占用严格小于 50 GB。

用户采用 Pro 对本实验的评分修订：已知有效同合同评分精确复用；已知尝试无有效结果及冲突保持 UNKNOWN；历史状态无法查明者登记后本轮最多主动提交一次，不按结果重抽。历史记录不完整，不宣称历史首次或全项目零重复。用户进一步明确同意按默认大模型评分可比较处理，不以不可变快照缺失阻止本次实验；仍记录模型名、合同和配置，快照未知如实披露，不宣称版本逐字节一致。所有冻结分母与未知项保留。

此实验只在已曝光 DEV 上评估，普通 LoRA 和强度缩放仅为性能诊断，不作为已经证明的新机制。原 MED、R0、备份、M13P 和负结果保留；教师、来源回放及第二方向 57/59 继续停止。MedMKEB 数据构建单列，不进入本次训练或面板。
