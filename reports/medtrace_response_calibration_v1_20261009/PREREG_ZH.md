# 固定候选的响应校准：预登记

用户批准继续执行上一轮提出的校准诊断。PR47 保留 NO_LOCAL_SUPPORT。本轮不创建新的优化候选，不改变旧主面板或成功门槛，不根据校准结果选择尺度、精度、种子或题目宣称方法胜出。

## 固定对象与问题

原 8 个 zero-TT88 专家、原 seed；同 61 个已判对 BASIS 回答、31 来源、1514 个实际回答 token 含 EOS；各专家原 native + 4 FIT 编辑输入。所有源题等权、每题内 token 等权。HELDOUT96/主63、CHECK、确认集不进入本轮计算或优化。

1. 原 RAW 与 PR47 BOUNDED 在写入尺度 0、1/4、1/2、1 下，真实 KL 是否按尺度平方变化？
2. 用实际 logits 变化得到的二次型是否解释真实 KL？梯度给出的方向响应是否解释实际 logits 变化？
3. 相同权重数值、输入嵌入与候选，在原 FP16 和 FP32 计算下，上述差距如何变化？

## 候选、精度与导数

旧 PR47 未持久保存候选；仅按原 FP16 路径、原 32 探针与 seed、原约束求解器重建，不重新采样/调参。检查原目标二次型、映射幅度、线性收益六个量，容差 1e-14 + 1e-8*旧值；随后对每个源/编辑输入验证尺度1的原精度 KL、NLL变化、正确token损失与旧结果一致（绝对容差1e-12）。失败保留证据，不隐式重建或更改容差。三份状态 BASE/RAW/BOUNDED 每专家一个临时小包，所有非G1坐标须完全相同。

尺度直接作用于 G1 参数，其他 cores 固定。G1=0 的 BASE 与关闭 hook 的同精度 Base 校验相等，重复前向也须完全一致。每题/精度/方向使用 torch.autograd.functional.jvp 的双反向算法直接计算全词表方向导数，方向固定，不使用随机投影、不构建全 Jacobian。此为浮点自动微分方向导数，不能称有限精度程序的严格数学导数。若后端不支持、非有限或与零状态前向不一致，机械阶段停止；不得暗中切换 attention 后端。

所有多模态输入在原 FP16 路径构造一次并保留冻结嵌入。FP32 对照把同一已加载模型的浮点权重及缓冲、同一嵌入转为FP32，关闭TF32；不重新计算视觉特征，不加载不同精度的原始权重，不重新求解。各精度使用自身 BASE logits 和概率。结束后恢复原参数/缓冲 dtype 与TF32设置、零专家状态；Base不优化且不得产生累积参数梯度。

## 固定观测与解释边界

每个候选尺度记录真实全词表KL、编辑NLL变化/正确token损失、实际logit二次型 Qobs=0.5*E_p[(Δz−E_pΔz)^2]、方向导数二次型 Qjvp、同度量下的响应误差、logit RMS和变化比例。保留原 sketch 预测供原精度下比较；FP32的概率/Jacobian也可能改变，不能把跨精度差值全部称作随机估计误差。

报告全部12个精度×方向×非零尺度面板与8专家面板，不设新方法成功检验、不做显著性追逐、不选尺度。KL与Qobs接近而Qjvp不接近，定位到参数→logits预测；Qobs本身不接近KL则保留分布二次近似误差。FP32接近且FP16不接近支持计算精度解释，但不证明每个算子的单独因果。FP32小尺度更接近才支持进一步研究有限步局部性。即使源题校准/保护改善，也不构成留出泛化或医学正确率证据。
