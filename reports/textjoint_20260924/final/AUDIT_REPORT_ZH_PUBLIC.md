# MedTRACE 文本泛化与保持联合实验：结项核验

本轮在 my-gpu 的 A100 GPU 2、3 上完成六臂 DEV12、阶段诊断、B0/P 的 single 与真实专家库 sequential 配对、BalancEdit 对照、第二种子和逆序对照。最终状态为 **COMPLETE_EXPLORATORY**，没有可宣称通过工程约束并经独立确认的候选。P 只是后续研究的开发集参考，不能称为已验证改进。

## 配置和数据边界

本轮使用 L30 `model.layers.30.mlp.down_proj`、rank 4、float16、`lambda_U=0.01`，固定生成与 Judge 协议。Stage17 L21 与旧服务器 Blackwell 结果没有并入本轮 A100 配对。原始墙钟与 16 GPU 驻留小时、6000 Judge 项上限没有因迁移重置。只使用 GPU 2、3；00:00 UTC 后没有启动新训练。

DEV48 来自已暴露的 Stage17 面板，实际六臂筛选使用其中相同的前 12 个编辑；**没有独立 CONFIRM**。这 12 个编辑对应 12 条 native target、48 条 P_fit 语义改写、原 U_fit 每编辑 1 条，以及 199 条评测记录（T0 12、T1G 48、T1L 86、T2G 48、T2L 5）。评测探针仅用于评测。U 扩展实际每编辑只有 4 或 5 条独立问题（各 6 个编辑）；每编辑来自 3 个来源，4 条多样样本均取得，但事实相近的困难样本只取得 0 或 1 条，未达到目标 8 条。U 的实际模态为图像加文本，不能把重复样本算作 8 条。

Base 掩码在 A100 上重新生成并冻结。Fix 仅使用冻结 Base 原错误项，Retention 仅使用 Base 原正确项；以下分数都是同轮 edit-macro。文本保持的有效分母很小：T1L 为 **0/0（不可评估）**，T2L 只有 **3 个问题、1 个来源组**。不能把模型总体准确率或输出 token 一致性代替这两个指标。

## 阶段、路由和训练诊断

阶段诊断覆盖 12 个编辑中的同一组小探针。Base OFF、native CP、A2、CP_W0、低秩转换、continuation 均有记录。以诊断探针的原始 Judge 正确数看，T2L 在 Base OFF 为 1/2，native CP 1/2，A2 2/2，CP_W0 1/2，转换后 1/2，continuation 2/2；这只是两个探针，且有效 Base 正确项更少，**不能可靠定位普遍的文本保持下降阶段**。各可强制开启的阶段中，同探针的 FORCED_ON 与真实路由均为 43/43 输出 token 相同、43/43 路由激活并指向关联专家，因此没有触发额外固定 writer 路由验证臂。FORCED_ON 只作诊断，没有计入主方法成绩。

逐编辑训练曲线保存在私有运行目录；脱敏的逐臂、逐阶段、逐步中位数见 `CURVES_AGGREGATE.csv`，每行同时给出有效编辑数。举例，B0 的 C_NO_H 阶段 12 个编辑的拟合 CE 中位数从 0.0067 降至 0.0002；E 的 CP_W0 末步 U 梯度中位数为 0.0028，EU 为 0.0055，说明早期 U 项确实进入优化。**loss 下降不是性能提升证据**：E 和 U 的评测负结果正说明需要区分两者。U-KL 实现按冻结、全部专家关闭的 Base teacher，在 Base 前缀上计算 full-vocabulary token-mean KL(Base||student)，并对 U 数量取平均；本轮接口与 GPU canary 已通过，实际 U 数不足 8 的限制如上。

## 锁定候选后的配对结果

P 作为探索性参考，在正序 sequential 的最终前缀相对同轮 B0：T0 均 12/12，T1G 均 43/45；T2G 从 42/46（91.67%）到 43/46（93.75%），仍是 **+2.08 pp**；T2L 均为 3/3。第二种子 single 和 sequential 的 P 相对各自 B0 也各多修正 1 个 T2G 项（45/46→46/46，+2.08 pp），T2L 仍是 3/3。逆序 sequential 再现正序的 T2G +2.08 pp、T2L 0 pp。这些运行共享同一已暴露的 12 编辑 DEV 集，不是独立确认。

标准 BalancEdit 对照的最终 single/sequential T2G 为 46/46，相对 B0 +8.33 pp，但 T2L 为 2/3，相对 B0 −33.33 pp；它也没有形成联合改善。以上 single 与 sequential 均使用各自真实专家库前缀生成，不能将 single 输出拼成 sequential 成绩。

DEV36/48 未扩展：在决策时保守 Judge 需求分别为 23,102/41,438 项，超过剩余 5,425 项；故保持已配对的 12 编辑规模，没有用不同样本量横比。无 H 支持，本轮不宣称验证 H。
