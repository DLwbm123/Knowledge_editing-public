# TT 三模块固定比较：运行前协议

用户于 2026-10-11 授权实现三个模块并实验，随后将设备改为 pro5000 的物理 GPU 2、3、4。本轮只检验下面的固定组合；旧 online2x2 的 STOP、保留权重和暂停监测状态不变。

## 研究问题与固定比较

沿用原八个 owner、原种子、已批准的每例七个源问题、修订 owner8，以及 160 步时钟。全部 7168 个原生 TT 参数可训练，Base 冻结。每步主损失仍为 `.25 native + .25 cyclic FIT + .5 cyclic GFIT`。不增加问题、种子、步数、rank 或路由器。

| 臂 | 实际变更 |
|---|---|
| C | 重建原 RAW 方向、Adam 组步长的 160 步参考 |
| M1 | 每步处于确定性 TT canonical 坐标；用两个标量二阶矩替代逐坐标 Adam 历史 |
| M2 | 对七个单独问题的下降半空间投影实际提案，并逐题验证有限步长 |
| M3 | 用 Base full-vocabulary Fisher sketch 惩罚实际组合算子 `W=B A` |
| M12 | M1 + M2 |
| M123 | M1 + M2 + M3，主要待检验方法 |

主要比较为 **M123 对已冻结的上一轮 E**，不是只与较弱的 C 比较。全部报告 C–M1、C–M2、C–M3、M1–M12、M12–M123、C–M123、D–M3、D–M123、E–M123；不挑选最佳臂。该六臂设计检验单模块及指定组合，不估计完整八臂 factorial 的全部交互。

## 三个模块的精确定义

M1 从右向左消去三个非根 core 的 gauge，用行空间投影的确定性 pivot 构建 frame，将变换传到左侧。非根矩阵必须满行秩；根 G1 允许为零。不宣称这是适用于零根退化点的完整 TT quotient/Riemannian Adam。优化器没有一阶动量，仅保存 G1/G2、G3/G4 两组的标量平方梯度均值；beta2=.999、eps=1e-8，基础学习率分别 1e-3、1e-4。没有无法正确搬运的逐坐标历史。提出一步后重新 canonicalize；检查组合算子的变化未被舍入显著改变。

M2 使用七行各自的负 NLL 梯度，不先合并成两个组。将已实现的优化器提案转换到固定学习率坐标，对七个闭半空间做欧氏最小距离投影；枚举至多 128 个 active set 并检查 KKT。重复、零梯度及相互冲突目标在 CPU 检查中覆盖。投影后先匹配 C 当步组合算子的 Frobenius 变化范数，再依次检查比例 1、1/2、1/4、1/8；七题 NLL 均不增加超过 1e-6 才接受。否则不写入，但优化器时钟和预算仍消耗。报告缩步、跳步和实际范数比，不能把缩小写入解释为方向本身更好。

M3 只在未编辑 Base 上对已批准、与 heldout 源组分离的 61 个 BASIS 问题建立一次 Fisher sketch。每题 32 个 full-vocabulary Rademacher probe，种子 `20261009 + BASIS序号`；总 1952 个方向、1514 个回答预测位置。保留每个位置的归一化层输入 X 和输出方向 Y，用 `sum_s <Y_s^T X, W>²` 对实际有限组合算子 W 求导，不用单个 core 的欧氏距离，也不优化 BASIS 标签 CE。首个真实 probe 检查 TT pullback 与模型 autograd 一致。系数固定为 `0.1 × C 的加权源 CE 改善 / C 的算子惩罚`，只用源侧参考定标；无 lambda 网格、heldout 选择或中途刷新。该 Base 线性化 sketch 不保证真实有限步响应不变。

所有新臂在非零方向时匹配 C 对应步的 `||W_after-W_before||F`，沿提案方向先做尺度归一化，再复用原有最多 32 次二分、归一化后倍率不超过 16 的求解器。容差 `1e-10 + .001×target`；重新 canonicalize 后容差 `.002×target`。M2 的有限检查可进一步缩小写入。零方向单独记录。M1 不含 indexed momentum；其他臂沿用原 Adam/RAW 时钟，实际写入过滤后不伪造其历史。

## 顺序、冻结与判定

1. 三个参考 worker 分担 3/3/2 个 owner；八份 C 最终 TT tensor、56 个源输出的完整输入绑定/回答/tokens 必须与保留参考精确相同。失败则停在新臂之前。
2. 在 GPU2 建立一次算子 Fisher；三个训练 worker 分担 3/3/2 个 owner。每个 owner 跑全部五个新臂，只轮换执行先后。
3. 全部 48 个候选冻结后才生成新臂源/原事件/heldout 输出。对每个臂进行保存加载精确检查、原生逐前缀检查及固定八专家自然 R0 查询。原路由必须精确复现。
4. C 的非源输出及自然输出按完整身份复用，D/E 只读复用。每个臂 939 个 forced-owner 和 219 个 natural 消费者，总 6948。最多实际新增生成 5846，最多新增 Judge 尝试 5790。
5. Judge 沿用隔离的 gpt-6-astra medium、四 worker、50 条一批、每个完整 payload 一次。仅完整输入/模型/输出文本和 tokens/评分协议完全相同才继承历史评分；永久缺失保持缺失。历史已授权的 40 条恢复例外按原记录识别，不产生新重试。

正向结论必须同时满足：完整语义证据；M123 各 owner 的 native/FIT/GFIT、T1G/T2G 不低于 E；Base 正确题的新损伤总数严格少于 E 且无 owner 更差；原 63 题固定 504 个 forced 单元的 expert-cluster 与 source-cluster 配对区间下界都大于零；natural 的 native/T1G/T2G 不低于 E 且损伤不更大。否则明确报告不保留编辑/泛化或无联合收益。原七例和修订 owner8 分开报告。

这些数据都已有开发暴露。即使所有门槛通过，也只能称更强的开发信号，不能称独立确认、医学有效性或 146 编辑验证。

## 预算、停止与生命周期

固定 48×160=7680 次提案，其中 C 重建 1280、五个新臂 6400；神经网络反传 40352 次，另有组合算子反传 2560 次；非生成前向上限 170000。正常路径 11 个 GPU 进程会话：3 reference、1 Fisher、3 train、3 evaluate、1 route。

本轮硬上限 **24 GPU-process-hours**，包含加载、失败、参考重建、训练、生成；不是 24 小时墙钟。每个 GPU worker 启动前须有 45 GiB 空闲显存，不修改同卡已有任务。私有生成权重/缓存上限 2 GiB，磁盘保留至少 8 GiB。Fisher 因子约 0.82 GiB，原子保存与小型候选/恢复状态计入上限。

成本继承：主链 103.35403146465619 GPU 小时、13480 次 Judge；独立 common146 链另有 3346 次 Judge，含失败尝试。本轮账本合并为 16826 次历史 Judge，新上限 5790，故累计上限 22616；独立链不会重复加入 GPU 成本。

每 20 步保存本次活动恢复点。最后消费者完成前保留；失败或预算耗尽时保留未完成状态，不自动重启/延长/补种子。Fisher 在所有训练及源侧最终惩罚统计结束后删除。48 份本次候选在所有强制/自然生成、保存加载和持久评分绑定完成后按明确路径删除；评分本身不再需要权重。删除无保留副本，重建需要重训。原 online2x2 的用户保留权重和恢复文件完全受保护。

采用已有后台依赖链和有限评分 worker；没有新持续监测或自动下一轮实验。实际完成后的公共交付包括代码、匿名汇总、报告、成本与失败记录；患者数据、原始问答、tokens、权重及私有运行材料不发布。
