## 结论

本次覆盖全部 28 个 new/01、6 个 resolved/10，共 34 个任务，实际来自 22 个患者组、22 个影像对、44 张影像。**未发现元数据指针对调或将随访图误用作本任务训练图的机械错误，但发现一条实质性的比较对象问题，以及若干二值标签和问题语义风险。不能把“代码按源表转换正确”当成“34 条时序标签均已临床验证”。**

最重要的一条：某个结节消退任务的双语来源句明确描述“先前 CT 可见的结节在当前检查未显示”，本地却将它转换成“自动链接的既往胸片有结节→当前胸片无结节”。**这段来源证据没有支持那张既往胸片应答 Yes，也不能把跨模态的未显示直接视为病征消退。** 该任务已经进入修正版 159 例，并占当前四个已准入变化任务中的一个；它的随访 Base 评分原本为 UNKNOWN。现有冻结实验和标签均未追改，这条被单独标记为后续干净诊断的资格待定项，不能默认视为有效变化证据。

## 逐条阅读发现的语义问题

### 1. 一条 CT 比较被当成绑定胸片间的消退

这是本次最明确的问题。来源句的比较对象是先前 CT，数据结构中的 previous 指针却指向源数据链接的胸片。两个事实可以同时成立，但**不能直接推出结节在那张胸片上也存在**。因此，问题发生在“将进展文字机械应用到自动链接的影像对”这一推断，而不是本地把影像 ID 抄错。

已确认：原句明确提及 CT；当前任务绑定的是胸片存在性问答；旧构造没有核查进展描述是否专门针对这张 previous 图。未确认：该既往胸片实际有没有结节、CT 与胸片的具体对应关系、当前未显示是否等于真实消退。不能据此简单把某个参考答案从 Yes 改为 No。

建议后续独立诊断先将其标为比较对象未验证；待原始比较检查或影像专家证据补齐后才重新判资格。当前159分母与结果保持原样，报告此污染风险，不事后删例改善分数。

### 2. 三条不确定描述被压成确定 Yes

涉及“疑似／提示小浸润”“不能排除肿瘤来源病变”“可疑假结节浸润”三类源描述。构造器使用结构化 finding 标签及 progression，生成无条件的病征存在性 Yes，未保留原来的不确定程度。

这不等于这三条实际病征必然不存在；更准确的结论是**参考答案确定性强于 finding 文字本身**。三条目前均属既往 Base 资格 UNKNOWN，没有进入159队列。其资格也不应仅靠恢复一遍旧问题的评分就被认为标签已验证。

### 3. 一条目标标签与匹配句不充分对应

一个 new finding 句描述局部假结节样高密度，却同时带有骨折骨痂和假结节两个标签；同一当前报告另外还有描述骨痂的句子。本地遵循了源标签，没有抄错，但仅凭这个 new 句，不能证明广义的“骨折骨痂”在既往整张胸片上完全不存在。

该任务目前资格 UNKNOWN。它同时表现出“源标签可能来自上下文”及“局部新病灶被泛化为整类病征从无到有”两个风险；不能直接反转标签，也不能把问题归结为本地字段解析错误。

### 4. 普遍存在局部 finding 与整类病征的范围差异

29/34 条源 finding 有 location 槽位，而问题只使用病征名称，未携带原 location 限制。例如，一个局部新病灶不能单凭“new”证明同类病征在既往其他部位均不存在；某一侧病灶／器械消退也不能直接推出整张图上所有同类病灶／器械均不存在。部分解剖含义可能已经包含在病征名称中，因此该29条统计不是“29条全部错误”，也不是“29条问题完全没有解剖信息”。

本次没有找到更多可据此确认的相反标签，但这种构造不保留病灶与部位范围，是需要明确披露的系统性风险。后续若改成部位限定问题，就已经改变问题合同，需独立版本及重新验证，不能替换已完成问答。

### 5. progression 标注不总能从一句文字独立重建

28 个 new 任务中，8 条目标英文句显式包含 new/newly/appearance；其余20条没有这些直接词语。部分任务有相邻句、与既往状态的隐式对照，或可阅读的正常既往报告支持，不能仅凭缺词宣布其 progression 错误。其余任务在现有材料下仍主要依赖源结构化 progression，缺少独立既往 finding 证据。

英文与西班牙文已逐条核对，没有发现本地翻译替换导致 new/resolved 翻转。上述 CT 比较与不确定性在两种语言中均存在，不能通过换读英语或西班牙语消除。

因此，之前“资格恢复后理论上4–25个变化任务”的说法只是按现有标签和评分状态的算术上限，**不是经本次语义审查确认的4–25条干净变化证据**。至少需要单独处理CT比较任务，并为其他有疑点任务保留标签审阅状态。

这些问题也不能解释全部99%左右的高分：源池中绝大多数随访参考仍为Yes。核查找到真实的有效性风险，但没有证明只修这几条就能恢复方法区分度。高分、恒答控制与缺失资格仍需按[偏斜报告](../med_t5_bias_pro_review_20261108/REPORT_ZH.md)解释。
