# 问答接口不兼容保护：开发期有限修正

用户要求先解决当前知识保持不足。本轮修正基于已查看的 DEV 错误，不能称为独立预注册或语义保护证明。

## 证据与固定规则

原 T2L 面板只有 54 次观测、52 条不同查询，来自 31 个编辑单位和 29 个来源组。0.02 分差条件下，21 条不同查询由是非问题被专家改为疾病列表、治疗/预防/病因等开放回答。部分错误由回退到 R0 引入。所有 52 条 T2L 查询均为明确的是非题；T0/T1G/T2G 中没有本规则识别的明确是非题。这一题型分离在执行前已知，必须披露。

主规则 TYPE_GUARD_002：先运行已固定的 0.02 分差路由，再只依据查询问题和所选专家的原编辑问题，识别明确的 polar/open 类型冲突；冲突则 OFF，使用 Base。不读取当前查询的答案、Base 是否答对、任务标签、影像来源或 Judge 结果来决定 ON/OFF。没有新阈值，没有语义监督训练。

保守英文句式解析：直接 WH 问句为 open；直接助动词疑问句在无 WH 嵌套/选择词 or 时为 polar；“Can/Could/Would/Will/May/Might you …”间接请求、选择题、嵌套歧义和未识别句式为 unknown。unknown 保留原路由。原编辑问题出现在原任务信息内，不使用评价参考答案。解析器也处理常见疑问否定和训练包装前缀。

这是答案接口保护，不是语义无关性判定。同一个事实可以在开放问答和是非题之间迁移；该规则可能误拒绝这种真正需要编辑的查询，当前数据不能验证此风险。因此即便历史 T2L 达到满分，也不能宣布一般知识保持已解决。四条自然 CHECK 单独报告，不混进 T2L。

## 固定实验与复用

1513 输入，四条件：原 R0、无分差模态候选排序、0.02 分差、TYPE_GUARD_002。冻结 146 个 TT88 专家、所有任务过滤与分母；报告全部 20 面板、15 个配对比较、CHECK 和路由 OFF 数量。

所需 OFF 输出已在此前七条件运行中生成；仅按 effective_expert=None 查找，不依据回答或评分选择。检查完整查询/解码绑定，并对普通查询核对原 Base 文本与 token 序列；CHECK 核对已保存的 Base token 一致性和零 KL。保留所有历史评分，包括 MISSING，不重试、不重新判分。两个旧路由及 0.02 条件的全部 15 面板须精确复现。

新训练、生成、Judge 和 GPU 成本均为零；只做 CPU 回放。保留历史累计成本、权重和输出；无新 checkpoint、无删除。CP 继续取消，不追加新数据、模型、语义分类器或阈值搜索。公开仅源码、聚合结果、限制和完成回执。
