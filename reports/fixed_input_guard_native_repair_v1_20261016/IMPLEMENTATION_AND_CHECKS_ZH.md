# FP16/BF16 原生写回修复：CPU 检查结果

状态：FULL_SHAPE_NATIVE_CPU_PASS。固定一般子空间合成检查中的FP16/BF16非零写回通过；没有启动模型实验，没有更换原生权重dtype，没有增加推理参数或持久补偿矩阵。真实模型执行器尚未接线。

## 最小改动

改动 experiments/fixed_input_guard_v1/guard.py 的原生write路径，新增短的repair_native函数；现有cpu_check.py更新预期，新增native_check.py。旧HE/HM执行器未修改。之前报告及失败结果保持原样；本报告替代上一版本“低精度一般子空间不可用”的工程状态，但不替代其科学证据边界。

最终投影判据完全不变：

||Δ_actual Q||_F ≤ 1e−7 + 1e−6 ||Δ_actual||_F。

Δ_actual由copy_写入原始FP16/BF16张量后，重新读取与before相减得到；CPU测试另行独立复算，不只信任write返回的回执。FP64仅用于临时数值计算，与此前证书计算一致；没有把实际W改为FP32或FP64。

## 两组坐标补偿

先投影原优化器方向D，按原生dtype舍入候选。只有舍入后残差超限才进入修复。每个输出行选择候选中绝对值最小的640个坐标，固定分成128个精细补偿坐标和512个粗补偿坐标：

1. 在尚未提交的候选中将精细坐标暂置零，显式计入这一步的投影残差。
2. 在粗组上求最小范数残差补偿，每次都量化回原生dtype；固定最多4次，仅保留残差下降的候选。
3. 在接近零的精细组上补偿剩余残差，同样固定最多4次并量化。该组值较小，通常能利用更细的原生浮点间距。
4. 真正写回W后重读、认证；不通过就恢复before。还新增更严格的方向保真门：||Δ_actual−D_projected||/||D_projected|| ≤ 5%。它不是放宽投影容差，而是防止放大或扭曲更新来满足相对残差条件。

局部补偿使用96×96矩阵伪逆，数值rank截止为相对1e−10；奇异/不充分的坐标组仍必须通过最终完整Q认证，不能靠伪逆丢弃约束。宽度小于640时不进入修复，保留原拒绝路径。矩阵每次仅分块处理32行，所有坐标选择和补偿系数为当前写入的临时变量。

这是有界数值修复器，不保证任意权重、任意小更新都存在可接受解。缺少小幅值坐标、更新太小或修复偏差过大时，仍拒绝。它也不保证H/HE目标改善；后续真实执行器仍须重新检查原编辑成功门。

## 固定存储

持久状态模式和张量形状完全未变：12,845,096字节，约12.25 MiB；序列化12,847,116字节，低于16 MiB。四次完整写回前后逐张量检查保护状态未变化。2,000次摘要更新的状态与checkpoint大小保持不变；未增加历史列表、梯度历史、误差反馈缓存或永久补偿参数。

16 MiB只指单份持久保护状态，不包括模型、当前权重/梯度、候选和FP64临时计算。回归CPU进程的峰值RSS约2.91 GiB，包含检查夹具和完整矩阵副本，不能当成部署峰值。临时开销按模型尺寸和固定块尺寸有界，不随历史编辑数量增长。

## 开发中失败与边界

第一版单坐标修正对权重尺度0.02、更新比例0.05的完整BF16检查失败：相对残差1.3865e−6，超出原门，按预期回滚。失败回执保存在CPU_FAILURE_1.txt。小型成对坐标修正也未解决该数值停滞，因此最终实现删除该搜索，采用上述更短的两组补偿法；没有改容差或删除失败夹具。四个原有完整形状夹具在最终实现中全部通过。

这些结果解决的是所测一般子空间下的低精度数值写回，不是连续知识编辑效果证明。没有真实模型、GPU、Judge、远程安装、实验或监测。后续若获授权，先接原生模型/优化器事务、源成功检查及重载准入，再考虑此前提出的前8条两臂最小对照；本轮没有启动它，也没有新增启动权限。
