# MedTRACE text generalization and retention experiment

The my-gpu campaign finished as **exploratory**. Six arms were screened on the same 12 edits from an exposed Stage17 DEV48 panel. P improved paired T2G edit-macro by 2.08 percentage points over the same-round B0, while T2L did not improve; T1L had no Base-correct retention denominator. There was no independent confirmation set. See the [Chinese audit report](../../reports/textjoint_20260924/final/AUDIT_REPORT_ZH_PUBLIC.md), [aggregate results](../../reports/textjoint_20260924/final/RESULTS_PUBLIC.json), [aggregate training curves](../../reports/textjoint_20260924/final/CURVES_AGGREGATE.csv), [public config lock](../../reports/textjoint_20260924/final/CONFIG_PUBLIC.json), and [final receipt](../../reports/textjoint_20260924/final/FINAL.json).

The locked review base is `c26e046b3ec661be42f865e6727d7a638a320f31`; the execution source overlay was based on `7a9b1f22dc410dd8322b5813aaee935c93c38a79`. The actual my-gpu Python import precedence was `source_patch`, then the FreshStart `source` overlay, then the run root. `mygpu/worker_v3.py` and `mygpu/orchestrator.py` represent the executed two-GPU worker and queue. `mygpu/source_patch/freshstart/runtime.py` holds the two-distinct-GPU session guard. `mygpu/controller_v2.py` has only its run-root default sanitized; `mygpu/metrics.py` is byte-identical to the run copy. `supports.py` and `overlay/scripts/medtrace/` contain the support-selection and training hooks. The source depends on the existing FreshStart overlay, pretrained model, and private task/Judge inputs; this is a source-only release, not a standalone data package.

For public release, only machine-specific run-root defaults, GPU UUIDs, and the neutral worker launcher were replaced by `RUN_ROOT`, `GPU2_UUID`, `GPU3_UUID`, and a `python -c` entry. Scientific computations and frozen selection rules were not changed. The private executed files are bound by SHA-256: `worker_v3.py` `76742ac878fc66a6a0d64c8f3a1b72d72963161a54805612cf519d9086681d85`, `orchestrator.py` `b6f82d9c6c9c2d7fe5faa1d7bb0de9b03d41223e09b197e24e83fb45f36870ff`, `controller_v2.py` `cb12631d6d2e3f4cc8d4dcb370a067a93e0d20e6eba03561eb2c156dc1f31096`, and `source_patch/freshstart/runtime.py` `06009fa1e91c3fdcdbf17fc9805e27211d1b886dfb7c0cc7bbeb12dc4702c71a`. The public copies therefore are **not byte-identical** to the private executed copies.

Only code, configuration, and aggregate evidence are published. `export_public_results.py` strips intermediate sequential prefixes from the runtime `RESULTS.json`, because those prefixes can reveal one-edit outcomes. **Do not publish the runtime table directly.** Private questions/images, per-sample generations and Judge scores, keys, credentials, and checkpoint weights remain off GitHub. The retained private P expert bank is identified by hash in the audit report, but is not part of this repository.
