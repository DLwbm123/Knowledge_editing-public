# 冻结读入、写出与同图局部性诊断

对既有 150 条编辑固定 Base、MED、MDU 终态及评测时选中的 R0 专家。沿用冻结的资格和类型，保留原问 150、FIT 600、T2G 571、T2L 54 共 1,375 个事件。T2G 与 T2L 使用历史 CORE 的参考答案，错答类别仅用于分层。MED 与 MDU 都启用同一个选中专家，各自与关闭专家的 Base 在相同答案前缀上比较。原 R0 错路由另列。冻结数据、路径、逐事件结果与权重留在私有运行目录。

记录最后提示 token 的读入子空间投影、TT 残差范数、首 token 和平均答案 NLL。留存含 EOS 的 CE 复核历史原问和 FIT1 首步。对 T2L 计算 Base 到编辑模型在同一答案前缀上的全词表 KL。报告间接提问参考有效子集及历史回避、修复和均正确的分层，报告同编辑同选中专家的 FIT 比率。配对差异按编辑聚合，编辑等权 bootstrap 2,000 次。保护曲率比与同图 KL 变化按实际专家聚合，仅做描述性相关分析。

本阶段上限 4,125 次解码前向、两小时，训练、生成、评分和新增 checkpoint 均为零。预处理沿用 FP16，解码沿用 FP32，首先核对精确提示 token、原图及原训练首步 CE。若前向显示间接提问相对同编辑 FIT 的读入投影缺口，并在历史回避子集上表现更弱，再登记并单独比较读入侧学习率。若读入接近但答案 NLL 改善偏弱，优先比较问法族稳健聚合和同图 KL，固定 TT 参数化与原输入侧学习率。这些读数用于发展方法，确认集另行冻结。

复现时将冻结运行目录配置为历史输出目录的子目录，并按原输入绑定提供专家库、纸面协议运行时、原图及私有面板。原图已迁移时，将 `FROZEN_IMAGE_ROOT` 设置为迁移后的 DataP 根目录；前向仍校验对应记录的原图散列。聚合脚本读取完成回执与数值记录，输出汇总而无需题干或模型原回答。

## MDU-v2 后续试验的准入

冻结诊断使用已曝光的 M3Bench 开发队列。四臂续训须另外登记数据来源和角色。先用图像散列把同图的全部编辑与问答绑定到一个分组。已有视图库和固定评测题保留原角色。从原始来源问答制作训练视图，每条新问法需保留原提问的实体、属性、否定和数量约束。间接句式为首要覆盖对象。语义变化题保留在专门的挑战集。按句式谱系及规范化问句去重，预留未参与训练的句型子族。独立确认还要求源图像与开发图像分离。

同图候选优先来自已有公开数据集的原始参考，按图像内容标识匹配。排除冻结评测问句、原问、FIT、规范化参考与编辑目标完全一致以及同问参考冲突的条目。通过下述依赖关系复核后才锁定角色。首轮以独立题为 KL 训练与留出负例。历史 T2L 保留原资格与原对照。

首轮从同一 MED 初态使用相同 TT 层位、参数量、采样次序、Adam 步数和正例答案单元。四臂分别使用等权聚合、稳健聚合、等权加同图 KL、稳健加同图 KL。通过基本、间接、数量和语境变化等族的训练侧损失差标定稳健温度，记录有效权重和局部性项的量级。语义单元只有可靠切分时使用，其他答案用整答单元。主要方法差异以同 KL 设置的配对比较衡量。视图库覆盖及输入侧学习率另做独立的匹配比较。具体面板规模、冻结配置、局部性界限和硬预算必须在收到冻结前向读数并通过训练数据准入后锁定。

## 训练前数据执行规格

### 同答案视图库

候选从原问及其已有参考构造，记录图像组、原问标识、改写族、模板谱系和必须保持的问答语义。核验实体、部位和侧别、所问属性、极性和不确定性、数量与单位、问题指向的范围及回答形式。只有原参考仍足以完整回答新问法时才入池。数值阈值、极性或所指病征发生变化的候选另列为挑战题。模板内的语义槽从原问提取，问法中不写入参考答案、暗示病征存在或泄露条目总数。

| 问法族 | 训练构造 | 拒收条件 |
|---|---|---|
| 同义改写 | 保持原问逻辑结构，允许替换问句动词和连接词，例如把 “shown” 换成 “visible”。 | 换词改变可见性、确定程度、所问部位或答案类型。 |
| 间接提问 | 把原问谓词放进陈述请求，例如 “Please report whether {原命题}” 或 “I'd like to know which {原对象限定}”。肯定、否定及 WH 问句分别用对应插槽。 | 外层句式将任务变为是否可判断，只要求是／否可判断，或改变内嵌问题。 |
| 数量约束 | 仅在原问已明确数量、范围或单位时做等价表述，例如同一数量要求的数字与拼写形式。 | 引入新的阈值、单位、答案长度或计数要求。 |
| 语境／干扰语 | 增加与诊断无关的中性图像语境，例如请求依据给定图像作答，保留原问。 | 语境增加诊断先验、引入其他检查信息或缩小图像范围。 |

间接问法先按句式谱系划分训练与留出。训练侧可用陈述请求或意图陈述，留出侧单独保留与影像记录相关的情境提问语法。仅包含原问的主语、谓词和原有属性，是否／WH 必须保持。实际模板编号和分组在生成前冻结。官方 T2G 的已知外层句式及其近邻只用于单独报告。另划训练侧验证数据做温度标定和学习率选择，正式留出句型用于参数定版后的评价。先做 Unicode NFKC、大小写及标点空白规范化的精确去重，再将语义槽替换成类型标记，按模板谱系和句框词序去重，复核跨划分的近似句框。来源图像上的留出句型测试与另外保留的独立图像队列分别登记与报告。

### 同图候选的关系与作用范围

复核时先看原图标识、编辑问题与目标答案、候选题与参考。用问题的反事实依赖判断独立性。如果编辑所写入的事实发生变化，该候选题的正确答案是否可能随之改变。然后对相关题核对同契约 Base 输出的语义极性。正式 CORE 资格使用对应实验的接受账本，旧字符串匹配结果另存。缺少同契约 Base 输出、参考不完整、所问类别歧义或解释冲突时记为待定。单个开放疾病清单未列名的情况，不能据此推断疾病不存在。

| 关系标签 | 判据 | 首轮去向 |
|---|---|---|
| 独立 | 编辑事实对候选答案无语义依赖，参考可信。 | 划入 KL 训练或留出负例。训练侧可在此类内挖读入较高的困难负例。 |
| 相关且一致 | 编辑目标能核验候选答案，同契约 Base 输出与该答案一致。 | 单独报告一致性与 KL 诊断，首轮不用于 KL 训练。 |
| 相关且冲突 | 编辑目标能核验候选答案，同契约 Base 输出却与其冲突。 | 记录一致性／迁移评估；排除 Base KL 训练。 |
| 证据不足 | 语义关系、参考或 Base 输出有无法消解的缺失与歧义。 | 记录原因和支持量，保留待复核资格。 |

对每条编辑预先记录作用范围。整图疾病清单以完整图像为范围、回答为疾病集合。具体发现类包括某个发现的有无、部位或属性，以及明确指定的单一病征。范围无法可靠确定的条目单列。选择性间隔与其配对变化须为两类分别给出事件、编辑、图像分母与区间。

关系标签锁定后，同一图上的独立候选按规范化问句划分训练与留出，同一问句的所有编辑配对共享角色。训练难例只能在训练侧采样；留出侧构成、旧基线分母和各臂配对关系固定。核验既有 Base 输出与输入绑定，缺少时需在新训练前以已锁定的 Base 贪心协议补齐。保留 Base 正误分层。用 Base 贪心输出作 KL 训练共同前缀，评价同时给出该前缀与核验参考前缀下的 KL。

准入交付以每条原问和候选的来源、图像组、语义标签、判定理由、角色、答案前缀绑定及各类支持量为准。保留关系待定、无独立训练负例或无留出负例的编辑计数。新增题目登记入扩展面板，冻结官方 T2G/T2L 的原资格和历史分数保持可复算。现有 1,276 对只是机器初筛库存，未通过逐对复核或训练准入。
